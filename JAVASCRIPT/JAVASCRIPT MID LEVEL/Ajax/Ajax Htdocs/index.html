DIAPOSITIVA 2 · FUNDAMENTOS

Peticiones POST con XMLHttpRequest en htdocs

Cuando trabajas con archivos locales o backend PHP/Apache en XAMPP (htdocs), servir el proyecto por http://localhost/... evita bloqueos CORS.

  • Paso 1: Captura el evento submit del formulario y llama a e.preventDefault().
  • Paso 2: Configura xhr.setRequestHeader('Content-Type', 'application/json').
  • Paso 3: Envía el objeto serializado con xhr.send(JSON.stringify(datos)).
📦 Analogía del paquete etiquetado: setRequestHeader pega la etiqueta "esto es JSON" y JSON.stringify empaca el objeto en texto plano para viajar por la red.
DIAPOSITIVA 3 · SINTAXIS Y PROPIEDADES

Sintaxis POST JSON con XHR

const xhr = new XMLHttpRequest();
xhr.open('POST', 'https://reqres.in/api/users');
xhr.setRequestHeader('Content-Type', 'application/json');
xhr.onload = () => console.log(xhr.status, JSON.parse(xhr.responseText));
xhr.send(JSON.stringify({ name: 'Ada', job: 'Programadora' }));

e.preventDefault()Evita que el formulario recargue la página

http://localhost/...Origen HTTP válido para evitar errores CORS de file://
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Consejos y Errores Comunes

✅ Verifica el rango 2xx: Comprueba xhr.status >= 200 && xhr.status < 300 porque un POST exitoso suele devolver 201 Created.
⚠️ Orden obligatorio: xhr.setRequestHeader() debe llamarse SIEMPRE después de xhr.open() y antes de xhr.send().
Seguridad del navegador

Por qué AJAX requiere servidor HTTP (htdocs)

Abrir un archivo con doble clic usa el protocolo file://. Por política de seguridad (Same-Origin Policy), los navegadores bloquean peticiones AJAX/Fetch locales sobre file://.

Colocar el proyecto en htdocs (XAMPP/Apache) o usar Live Server sirve los archivos bajo http://localhost.

Origen = Protocolo + Dominio + Puerto

Same-Origin Policy (SOP) explicada

Dos URLs comparten el mismo origen únicamente si coinciden los tres componentes:

  • http://localhost:80/api.json vs http://localhost:80/index.html → Mismo origen.
  • http://localhost:3000 vs http://localhost:80 → Origen distinto (cambia el puerto).
  • https:// vs http:// → Origen distinto (cambia el protocolo).
Intercambio entre orígenes

Entendiendo CORS en el servidor

Cuando tu frontend en localhost:5500 pide datos a localhost:80, el servidor debe autorizarlo mediante cabeceras HTTP:

Access-Control-Allow-Origin: http://localhost:5500
Access-Control-Allow-Methods: GET, POST, OPTIONS
Access-Control-Allow-Headers: Content-Type, Authorization
Formato de intercambio

JSON válido vs objetos JavaScript

Un archivo .json en tu carpeta htdocs debe cumplir reglas estrictas para que JSON.parse() no lance SyntaxError:

  • Todas las claves y strings deben usar comillas dobles ("clave").
  • No se permiten comas finales (trailing commas) ni comentarios //.
Tip de depuración

Caché del navegador durante pruebas locales

Al editar un archivo datos.json en htdocs, el navegador puede devolver la versión en caché.

En DevTools → pestaña Network, marca Disable cache mientras tengas las herramientas de desarrollo abiertas para ver cambios al instante.

Integración htdocs

FormData y envío hacia PHP/Backend local

Con FormData puedes enviar campos y archivos a un script en Apache/PHP sin construir cabeceras multipart/form-data a mano:

const form = new FormData(document.querySelector('#miForm'));
xhr.open('POST', 'procesar.php');
xhr.send(form);
