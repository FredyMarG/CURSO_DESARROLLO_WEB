DIAPOSITIVA 2 · FUNDAMENTOS

Peticiones POST con XMLHttpRequest en htdocs

Cuando trabajas con archivos locales o backend PHP/Apache en XAMPP (htdocs), servir el proyecto por http://localhost/... evita bloqueos CORS.

  • Paso 1: Captura el evento submit del formulario y llama a e.preventDefault().
  • Paso 2: Configura xhr.setRequestHeader('Content-Type', 'application/json').
  • Paso 3: Envía el objeto serializado con xhr.send(JSON.stringify(datos)).
📦 Analogía del paquete etiquetado: setRequestHeader pega la etiqueta "esto es JSON" y JSON.stringify empaca el objeto en texto plano para viajar por la red.
DIAPOSITIVA 3 · SINTAXIS Y PROPIEDADES

Sintaxis POST JSON con XHR

const xhr = new XMLHttpRequest();
xhr.open('POST', 'https://reqres.in/api/users');
xhr.setRequestHeader('Content-Type', 'application/json');
xhr.onload = () => console.log(xhr.status, JSON.parse(xhr.responseText));
xhr.send(JSON.stringify({ name: 'Ada', job: 'Programadora' }));
Elemento / APIDescripción
e.preventDefault()Evita que el formulario recargue la página
setRequestHeader()Declara el tipo MIME enviado antes de send()
JSON.stringify(obj)Convierte el objeto JS en cadena JSON válida
http://localhost/...Origen HTTP válido para evitar errores CORS de file://
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Consejos y Errores Comunes

✅ Verifica el rango 2xx: Comprueba xhr.status >= 200 && xhr.status < 300 porque un POST exitoso suele devolver 201 Created.
⚠️ Orden obligatorio: xhr.setRequestHeader() debe llamarse SIEMPRE después de xhr.open() y antes de xhr.send().
