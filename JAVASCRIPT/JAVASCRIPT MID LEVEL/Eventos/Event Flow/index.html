DIAPOSITIVA 2 · FUNDAMENTOS

¿Qué es el Event Flow?

Cuando haces clic en un botón dentro de un <div>, el evento no ocurre solo en ese botón: viaja a través de toda la jerarquía de ancestros en 3 fases.

  • 1. Fase Capturing (Captura): desciende desde window → document → html → body → padre → hijo.
  • 2. Fase Target (Objetivo): alcanza el elemento exacto donde ocurrió la interacción (e.target).
  • 3. Fase Bubbling (Burbujeo): asciende de regreso desde el hijo hacia sus ancestros (comportamiento por defecto).
🌊 Analogía de la piedra en el estanque: Primero la piedra cae hasta el fondo (Capturing), toca la base (Target) y luego las ondas suben hasta la superficie (Bubbling).
DIAPOSITIVA 3 · SINTAXIS Y PROPIEDADES

Sintaxis: { capture } y stopPropagation()

// Por defecto (capture: false) escucha en Bubbling
padre.addEventListener('click', (e) => {
  console.log('Padre en Bubbling. Target real:', e.target);
});

// Con { capture: true } escucha antes, al descender
abuelo.addEventListener('click', () => {
  console.log('Abuelo en Capturing');
}, { capture: true });

// Detener la propagación hacia otros ancestros
hijo.addEventListener('click', (e) => {
  e.stopPropagation();
});
Elemento / APIDescripción
e.targetElemento real donde se originó el clic
e.currentTargetElemento que tiene adjunto el listener actual
{ capture: true }Ejecuta el listener en la fase de descenso
e.stopPropagation()Frena el viaje del evento a los demás niveles
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Consejos y Errores Comunes

✅ Delegación de eventos: Gracias al Bubbling puedes poner un único addEventListener en un contenedor padre para manejar clics de decenas de botones hijos.
⚠️ Cuidado con stopPropagation(): Abusar de e.stopPropagation() puede romper analíticas globales, menús desplegables que cierran al hacer clic fuera o atajos de teclado.
