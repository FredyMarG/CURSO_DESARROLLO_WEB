DIAPOSITIVA 2 · FUNDAMENTOS

¿Qué es un Event Handler Moderno?

Un Event Handler es la función que responde a un evento. Aunque existen atributos HTML (onclick="...") y propiedades (btn.onclick = fn), el estándar profesional es addEventListener:

  • Múltiples listeners: permite adjuntar varios callbacks al mismo evento sin sobrescribirlos.
  • { once: true }: ejecuta el listener una sola vez y lo elimina automáticamente.
  • { signal } con AbortController: cancela uno o varios listeners con una sola llamada a controller.abort().
  • CustomEvent: permite emitir eventos de dominio propios con datos en e.detail.
📻 Analogía del interruptor maestro: AbortController actúa como un disyuntor eléctrico: cuando llamas a abort(), desconecta de golpe todos los listeners enlazados a esa señal.
DIAPOSITIVA 3 · SINTAXIS Y PROPIEDADES

Sintaxis de { once }, AbortController y CustomEvent

// 1. Listener de un solo uso
btn.addEventListener('click', () => console.log('Solo una vez'), { once: true });

// 2. Limpieza moderna con AbortController
const controller = new AbortController();
btn.addEventListener('click', manejarClic, { signal: controller.signal });
controller.abort(); // Remueve el listener sin necesitar referencia a la función

// 3. Evento personalizado con payload
document.dispatchEvent(new CustomEvent('pedido:creado', { detail: { id: 402 } }));
Elemento / APIDescripción
{ once: true }Auto-remueve el listener tras la primera ejecución
{ signal }Vincula el listener a un AbortController para limpiarlo
new CustomEvent(nombre, { detail })Crea un evento personalizado con datos en e.detail
removeEventListenerForma clásica (requiere guardar la referencia exacta de la función)
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Consejos y Errores Comunes

✅ Usa AbortController en componentes: Cuando desmontas un modal o vista dinámica, pasa el mismo signal a todos sus listeners y llámalo con controller.abort() para evitar fugas de memoria.
⚠️ Trampa de removeEventListener: Si pasas una función flecha anónima a addEventListener, luego NO podrás eliminarla con removeEventListener; para eso usa { signal }.
Concepto clave · Opciones

addEventListener y opciones avanzadas

El tercer parámetro de addEventListener(tipo, fn, opciones) controla el ciclo de vida y el rendimiento del listener.

once: true

Ejecuta el handler una única vez y se auto-elimina automáticamente. Ideal para intros, modales de bienvenida o pagos.

passive: true

Promete al navegador que no llamarás preventDefault(), eliminando bloqueos en eventos de scroll y touchmove.

Limpieza de memoria

removeEventListener y referencias

Para desconectar un listener con removeEventListener debes pasar exactamente la misma referencia de función; una función anónima nueva nunca coincidirá.

function onClick(e) { console.log(e.target); }
btn.addEventListener('click', onClick);
// Limpieza efectiva:
btn.removeEventListener('click', onClick);

En aplicaciones SPA también puedes pasar { signal: controller.signal } con AbortController para cancelar varios listeners a la vez.

Anatomía del evento

El objeto Event (e) en profundidad

Cada disparo entrega un objeto Event con metadatos esenciales sobre el origen y el estado de la interacción.

  • e.target vs e.currentTarget: target es el elemento exacto que originó el clic; currentTarget es el elemento que tiene el listener.
  • e.timeStamp y e.isTrusted: isTrusted es true solo si lo disparó el usuario real, no dispatchEvent().
  • e.preventDefault(): Cancela la acción nativa (enviar form, seguir enlace) sin detener la propagación.
Comunicación desacoplada

Eventos personalizados (CustomEvent)

CustomEvent permite emitir eventos propios con datos en la propiedad detail para comunicar módulos sin acoplarlos.

const ev = new CustomEvent('carrito:actualizado', {
  detail: { totalItems: 3, subtotal: 49.90 },
  bubbles: true
});
document.dispatchEvent(ev);
Trampas comunes

Contexto this y funciones flecha

Dentro de una función tradicional usada como handler, this apunta a e.currentTarget. En una arrow function, this se hereda del ámbito léxico.

Recomendación práctica: usa siempre e.currentTarget en lugar de this para que tu código funcione igual con arrow functions o funciones nombradas.
Optimización

Patrones de rendimiento: Debounce y Throttle

Eventos frecuentes como scroll, resize o input pueden dispararse decenas de veces por segundo.

Debounce

Espera a que el usuario deje de interactuar durante N ms antes de ejecutar (ideal para búsquedas en vivo).

Throttle

Garantiza una ejecución máxima cada N ms mientras dura el evento (ideal para barra de progreso de scroll).
