DIAPOSITIVA 2 · FUNDAMENTOS

¿Cómo funcionan los Eventos de Teclado?

El estándar moderno utiliza principalmente keydown y keyup (ya que keypress está obsoleto):

  • keydown: se dispara al presionar la tecla (se repite si la mantienes pulsada).
  • keyup: se dispara al soltar la tecla; útil para validar tras terminar el pulso.
  • e.key vs e.code: e.key devuelve el carácter/significado (ej. "A", "Enter"); e.code devuelve la tecla física del teclado (ej. "KeyA").
🎹 Analogía del piano: keydown es bajar la tecla, keyup es soltarla; e.code es la posición física de la tecla y e.key la nota resultante.
DIAPOSITIVA 3 · SINTAXIS Y PROPIEDADES

Sintaxis de Atajos con Teclas Modificadoras

document.addEventListener('keydown', (e) => {
  // Atajo moderno: Ctrl + K (o Cmd + K en Mac)
  if ((e.ctrlKey || e.metaKey) && e.key.toLowerCase() === 'k') {
    e.preventDefault(); // Evita abrir la barra de búsqueda del navegador
    console.log('Abrir buscador rápido');
  }

  // Ignorar repeticiones continuas al mantener pulsada la tecla
  if (e.repeat) return;
});
Elemento / APIDescripción
e.keyValor lógico/carácter de la tecla (ej. "Enter", "a")
e.codeCódigo físico independiente del idioma del teclado (ej. "KeyQ")
e.ctrlKey / shiftKey / altKeyBooleanos que indican si el modificador está pulsado
e.repeattrue si la tecla se mantiene presionada continuamente
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Consejos y Errores Comunes

✅ Usa e.key y e.code: Nunca uses el obsoleto e.keyCode o e.which; e.key es legible y estándar en todos los navegadores.
⚠️ No uses keypress: El evento keypress está deprecado y no detecta teclas especiales como Escape, flechas o modificadores.
Orden de disparo

Ciclo keydown → keypress (obsoleto) → keyup

Cuando presionas una tecla física ocurren dos eventos vigentes:

  • keydown: Se dispara al presionar la tecla y se repite mientras la mantengas pulsada (e.repeat === true).
  • keyup: Se dispara una sola vez al soltar la tecla.
  • keypress: Está obsoleto (deprecated); no detecta teclas como Escape, flechas ni Backspace.
Distribución de teclado

e.key vs e.code: significado vs tecla física

Elegir entre e.key y e.code depende de si haces un atajo de texto o un control de videojuego:

e.key

Devuelve el carácter producido (ej. "a", "A", "Enter", "Escape"). Respeta idioma y Shift.

e.code

Devuelve la posición física en el teclado (ej. "KeyW", "Space"). Ideal para controles WASD.

Productividad

Atajos de teclado globales (Ctrl/Cmd + K)

Combina e.ctrlKey || e.metaKey para soportar tanto Windows/Linux como macOS en paletas de comandos o guardado rápido.

document.addEventListener('keydown', (e) => {
  if ((e.ctrlKey || e.metaKey) && e.key.toLowerCase() === 'k') {
    e.preventDefault();
    abrirBuscador();
  }
});
Evitar disparos duplicados

e.repeat y control de pulsación continua

Si mantienes pulsada una tecla, keydown dispara múltiples veces con e.repeat === true.

Para acciones únicas (como saltar o enviar un mensaje), añade if (e.repeat) return; al inicio del handler.

Internacionalización

Composición IME y e.isComposing

Al escribir acentos muertos o caracteres CJK (japonés, chino, coreano), el usuario confirma la palabra pulsando Enter dentro de una sesión IME.

input.addEventListener('keydown', (e) => {
  if (e.isComposing || e.keyCode === 229) return;
  if (e.key === 'Enter') enviarMensaje();
});
Inclusión

Accesibilidad por teclado (Tab, Enter, Escape)

  • Nunca pongas listeners solo en <div> con click; usa <button> nativo para heredar Enter y Space gratis.
  • Cierra siempre modales y menús al pulsar Escape y devuelve el foco al elemento disparador.
