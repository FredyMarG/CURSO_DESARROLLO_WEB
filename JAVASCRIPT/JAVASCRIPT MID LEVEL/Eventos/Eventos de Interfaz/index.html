DIAPOSITIVA 2 · FUNDAMENTOS

¿Qué son los Eventos de Interfaz?

Son eventos disparados por el navegador ante cambios en la ventana, el scroll, el foco o la carga de recursos:

  • resize: se dispara cuando cambia el tamaño del viewport (window.innerWidth).
  • scroll: ocurre al desplazarse por la página o un contenedor con overflow.
  • select: se activa cuando el usuario selecciona texto dentro de un <input> o <textarea>.
  • error / load: permiten detectar si una imagen o script cargó bien o falló para aplicar un fallback.
🎛️ Analogía del tablero de un auto: No los dispara un clic directo, sino el entorno cambiando: la velocidad (scroll), el tamaño de pantalla (resize) o una alerta de falla (error).
DIAPOSITIVA 3 · SINTAXIS Y PROPIEDADES

Sintaxis y Listeners Pasivos

// Scroll fluido sin bloquear el hilo de renderizado
scrollBox.addEventListener('scroll', () => {
  console.log('scrollTop:', scrollBox.scrollTop);
}, { passive: true });

// Capturar texto seleccionado en un input
input.addEventListener('select', (e) => {
  const texto = e.target.value.slice(e.target.selectionStart, e.target.selectionEnd);
  console.log('Seleccionado:', texto);
});

// Fallback elegante si falla una imagen
img.addEventListener('error', () => {
  img.src = 'fallback.png';
});
Elemento / APIDescripción
selectSelección de texto en input/textarea (selectionStart/End)
resizeCambio de dimensiones de window
scrollDesplazamiento vertical u horizontal (usar { passive: true })
errorFallo al cargar imagen, iframe o recurso externo
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Consejos y Errores Comunes

✅ Rendimiento en scroll/touch: Usa siempre { passive: true } cuando no vayas a llamar a e.preventDefault(); así el navegador desplaza a 60 FPS sin esperar a tu JavaScript.
⚠️ Cuidado con resize y scroll: Pueden dispararse decenas de veces por segundo. Evita operaciones pesadas en el DOM dentro de estos listeners o usa debounce.
