DIAPOSITIVA 2 · FUNDAMENTOS

¿Qué son los Eventos de Mouse?

Permiten detectar cualquier acción física del puntero sobre un elemento HTML:

  • click y dblclick: clic simple y doble clic izquierdo.
  • contextmenu: clic derecho; con e.preventDefault() puedes reemplazar el menú del navegador por uno propio.
  • mouseenter / mouseleave: entrada y salida del cursor sin burbujear en hijos (más predecible que mouseover/mouseout).
  • mousemove: movimiento continuo del cursor, útil para lienzos, tooltips o arrastre.
🖱️ Analogía del puntero láser: mouseenter avisa cuando el láser entra al lienzo, mousemove reporta su posición X/Y exacta y click confirma la acción.
DIAPOSITIVA 3 · SINTAXIS Y PROPIEDADES

Sintaxis y Coordenadas del MouseEvent

pad.addEventListener('mousemove', (e) => {
  // Coordenadas relativas al viewport vs al elemento
  console.log('Viewport:', e.clientX, e.clientY);
  console.log('Elemento:', e.offsetX, e.offsetY);
});

pad.addEventListener('contextmenu', (e) => {
  e.preventDefault(); // Evita el menú contextual por defecto
  console.log('Clic derecho interceptado');
});
Elemento / APIDescripción
e.clientX / clientYPosición del cursor respecto al viewport visible
e.offsetX / offsetYPosición relativa al borde interno del elemento
e.buttonBotón pulsado (0=izq, 1=rueda, 2=der)
mouseenter / mouseleaveEntrar/salir sin dispararse falsamente en elementos hijos
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Consejos y Errores Comunes

✅ Prefiere mouseenter/mouseleave: A diferencia de mouseover, no se disparan de nuevo cada vez que el puntero pasa sobre un hijo interno.
⚠️ Accesibilidad: No dependas únicamente de hover o mouseenter para acciones críticas; en pantallas táctiles y navegación con teclado no hay cursor flotante.
Comparativa clave

mouseover/mouseout vs mouseenter/mouseleave

Elegir mal el par de eventos provoca parpadeos continuos al pasar el cursor sobre hijos internos.

mouseover / mouseout

Burbujean y se re-disparan cada vez que el puntero entra o sale de un elemento hijo.

mouseenter / mouseleave

No burbujean y solo se disparan al cruzar el borde exterior del elemento observado.

Geometría del evento

Coordenadas del puntero en pantalla

El objeto MouseEvent expone cuatro sistemas de coordenadas según tu necesidad:

  • e.clientX / clientY: relativas al viewport visible (ignora el scroll).
  • e.pageX / pageY: relativas al documento completo (incluye scroll).
  • e.offsetX / offsetY: relativas al borde interno del e.target.
  • e.screenX / screenY: relativas al monitor físico.
Detección de clics

Botones del ratón y dblclick

La propiedad e.button identifica qué botón físico se presionó durante mousedown o mouseup:

// 0: Principal (izquierdo) | 1: Rueda | 2: Secundario (derecho)
zona.addEventListener('mousedown', (e) => {
  if (e.button === 1) e.preventDefault(); // Evita autoscroll
});
Interacción avanzada

contextmenu y menús contextuales propios

El evento contextmenu se dispara al hacer clic derecho (o tecla de menú). Llamar a e.preventDefault() bloquea el menú nativo para mostrar uno personalizado.

Recuerda mantener opciones accesibles por teclado si reemplazas el menú contextual en un área crítica.
Atajos combinados

Modificadores simultáneos (Ctrl, Shift, Alt)

Todo MouseEvent incluye booleanos para saber si el usuario mantenía pulsadas teclas modificadoras al hacer clic:

item.addEventListener('click', (e) => {
  if (e.ctrlKey || e.metaKey) alternarSeleccionMultiple(item);
  else if (e.shiftKey) seleccionarRangoHasta(item);
});
Mouse + Touch + Stylus

Pointer Events: el estándar moderno unificado

Los eventos pointerdown, pointermove y pointerup unifican ratón, pantallas táctiles y lápiz óptico bajo una sola API.

Además incorporan e.pointerType ("mouse", "touch", "pen") y setPointerCapture() para arrastrar sin perder el puntero.
