¿Qué es Async y Await?

🎯 Propósito en JavaScript moderno

Escribe código asíncrono que se lee de arriba hacia abajo como si fuera síncrono usando Promesas.

🧠 Modelo mental: await pausa únicamente la ejecución de esa función async hasta que la Promesa se resuelve, sin congelar la página.
DIAPOSITIVA 3 · SINTAXIS Y USO

Sintaxis async / await

async function cargarUsuario() {
  try {
    const res = await fetch("/api/user");
    return await res.json();
  } catch (e) { console.error(e); }
}
DOCUMENTACIÓN OFICIAL · ASYNC Y AWAIT.md

¿Qué ocurre al colocar async?

Esta función automáticamente devuelve una Promise.

async function hola(){

    return "Hola";
}

console.log(hola());

Resultado:

Promise { "Hola" }

Aunque retornes un string.

Internamente JavaScript hace algo parecido a:

return Promise.resolve("Hola");

¿Qué es await?

await significa literalmente

Espera aquí.

Solo puede usarse dentro de funciones async.

Ejemplo

const promesa = Promise.resolve("Hola");

async function ejemplo(){

    const mensaje = await promesa;

    console.log(mensaje);

}

Salida

Hola

¿Cómo funciona internamente?

Supongamos

async function obtenerDatos(){

    const datos = await fetch(url);

    console.log(datos);

}

JavaScript hace aproximadamente esto:

Llamar fetch
↓

Esperar respuesta

↓

Cuando llegue

↓

Continuar ejecutando

Mientras tanto el resto del programa sigue funcionando.

Ejemplo sencillo

function esperar(){

    return new Promise(resolve=>{

        setTimeout(()=>{

            resolve("Terminó");

        },3000);

    });

}

Ahora usamos async.
