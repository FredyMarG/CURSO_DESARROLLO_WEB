DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Objeto Window?

🎯 Propósito en JavaScript moderno

Controla la ventana del navegador, pestañas emergentes, diálogos nativos y dimensiones globales.

🧠 Modelo mental: window es el objeto raíz del navegador: cualquier variable o función global vive dentro de él.

🌎 ¿QUÉ ES EL OBJETO window?

El objeto window es el objeto principal del navegador.

Representa toda la ventana del navegador donde se ejecuta JavaScript.

TODO en el navegador vive dentro de window.

🔥 IMPORTANTE

Cuando escribes:

alert("Hola")

REALMENTE estás escribiendo:

window.alert("Hola")

El navegador permite omitir window.
