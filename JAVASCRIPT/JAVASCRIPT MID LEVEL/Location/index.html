¿Qué es Objeto Location?

🎯 Propósito en JavaScript moderno

Lee y modifica la URL actual, parámetros de consulta, protocolo y recarga o redirige páginas.

🧠 Modelo mental: location es la barra de direcciones del navegador convertida en un objeto manipulable por JS.

🌍 ¿QUÉ ES LOCATION?

location es un objeto que contiene información sobre la URL actual del navegador.

Permite:

✅ leer URLs

✅ redireccionar páginas

✅ detectar rutas

✅ obtener dominio

✅ conocer protocolo

✅ navegar entre páginas
