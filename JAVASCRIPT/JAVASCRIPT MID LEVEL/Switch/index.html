DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Sentencia Switch?

🎯 Propósito en JavaScript moderno

Evalúa múltiples casos exactos de forma limpia en lugar de encadenar muchos if / else if.

🧠 Modelo mental: switch funciona como un selector de canales: salta al case que coincide y se detiene con break.
DIAPOSITIVA 3 · SINTAXIS Y USO

Estructura de switch

switch (rol) {
  case "admin": accesoTotal(); break;
  case "editor": editarContenido(); break;
  default: soloLectura();
}
