# 1️⃣ createElement()

⚠️ IMPORTANTE:

El método correcto es:

document.createElement()

❌ Mucha gente escribe:

createElements()

Pero:

❌ NO EXISTE

Porque JavaScript crea:

1 elemento a la vez

📖 ¿Qué hace?

Crea elementos HTML desde JavaScript.

# 🧠 SINTAXIS

const elemento = document.createElement("etiqueta")

# 📦 EJEMPLO SIMPLE

const caja = document.createElement("div")

# 📊 ¿QUÉ PASÓ?

ANTES:
❌ No existe div

DESPUÉS:
✅ JavaScript creó un div

# ⚠️ IMPORTANTE

El elemento existe:

✅ En memoria

Pero todavía:

❌ NO aparece en pantalla

# 🧠 ANALOGÍA PARA NIÑOS

Es como construir un juguete:

🧱 createElement()
= construir la pieza

📺 appendChild()
= ponerla en pantalla

# 🟢 CREAR UN BOTÓN

const boton = document.createElement("button")

# 🟢 CREAR UN PÁRRAFO

const parrafo = document.createElement("p")

# 🟢 CREAR UNA IMAGEN

const imagen = document.createElement("img")

# 🟢 CREAR INPUT

const input = document.createElement("input")

# 🎨 MODIFICAR EL ELEMENTO CREADO

Una vez creado podemos:

✅ Cambiar texto

✅ Cambiar color

✅ Agregar clases

✅ Agregar atributos

# ✏️ AGREGAR TEXTO

const titulo = document.createElement("h1")

titulo.textContent = "Hola Mundo"

# 🎨 CAMBIAR ESTILOS

titulo.style.color = "blue"

# 🏷️ AGREGAR CLASES

titulo.classList.add("grande")

# 📌 AGREGAR ATRIBUTOS

imagen.setAttribute("src", "foto.png")

# 2️⃣ createTextNode()

📖 ¿Qué hace?

Crea nodos de texto.

# 🧠 ¿Qué es un nodo de texto?

Es texto puro.

Ejemplo:

<p>Hola</p>

Aquí:

📄 p → nodo elemento
📝 Hola → nodo texto

# 🟢 EJEMPLO

const texto = document.createTextNode("Hola Fredy")

# 🧠 ¿POR QUÉ EXISTE?

Porque en el DOM:

TODO ES UN NODO

Incluso el texto.

# 🧩 UNIR TEXTO CON ELEMENTOS

const boton = document.createElement("button")

const texto = document.createTextNode("Enviar")

boton.appendChild(texto)

# 📊 REPRESENTACIÓN

🔘 button vacío
        ↓
📝 "Enviar"
        ↓
🔘 Enviar

# ⚠️ HOY EN DÍA

Normalmente usamos:

textContent

Porque es más simple.

# 3️⃣ appendChild()

📖 ¿Qué hace?

Agrega un hijo dentro de otro elemento.

# 🧠 EJEMPLO VISUAL

📦 div
└── 🔘 button

El botón es hijo del div.

# 🟢 EJEMPLO

const div = document.createElement("div")

const boton = document.createElement("button")

boton.textContent = "Click"

div.appendChild(boton)

# 📊 RESULTADO

<div>
  <button>Click</button>
</div>

# ⚠️ IMPORTANTE

appendChild():

✅ Agrega

✅ Mueve

✅ Reorganiza elementos

# 🧠 DATO IMPORTANTE

Un elemento NO puede existir en dos lugares.

# ❌ Esto NO duplica

padre1.appendChild(hijo)
padre2.appendChild(hijo)

# 📊 RESULTADO

❌ Sale de padre1
✅ Va a padre2

# 4️⃣ append()

Parecido a appendChild().

Pero:

✅ Puede agregar texto

✅ Puede agregar varios elementos

# 🟢 EJEMPLO

div.append("Hola")

# 🟢 VARIOS ELEMENTOS

div.append(boton, parrafo)

# ⚠️ DIFERENCIA

appendChildappend
Solo 1 nodoVarios
Solo nodosTexto y nodos
Más antiguoMás moderno

# 7️⃣ cloneNode()

Clona elementos.

# 🟢 EJEMPLO

const copia = elemento.cloneNode(true)

# 🧠 ¿Qué significa true?

true = copiar hijos también
false = copiar solo el elemento

# 📊 REPRESENTACIÓN

📄 Original
        ↓
📄 Copia exacta

# 🟢 EJEMPLO

# 📊 RESULTADO

# 9️⃣ replaceWith()

Reemplaza elementos.

# 🟢 EJEMPLO

# 📊 REPRESENTACIÓN

ANTES:
🔴 Viejo

DESPUÉS:
🟢 Nuevo

const tarjeta = document.createElement("div")

const nombre = document.createElement("h2")
