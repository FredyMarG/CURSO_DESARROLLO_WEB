Interfaz 1

1. `NavigatorID`: Identificación del Navegador y Plataforma

Agrupa propiedades históricas y modernas sobre el agente de usuario, motor y sistema operativo.

🪪

Propiedades Principales

userAgent Cadena con navegador, versión y sistema operativo.
platform Sistema base (ej. "Win32", "MacIntel", "Linux x86_64").
appName / product Propiedades legacy que devuelven "Netscape" y "Gecko" por compatibilidad.
🛡️

Privacidad Moderna

Para evitar el rastreo por huella digital (fingerprinting), los navegadores reducen la entropía de userAgent y promueven la API estructurada navigator.userAgentData.

console.log("User Agent:", navigator.userAgent);
console.log("Plataforma:", navigator.platform);
Interfaces 2 y 6

2. `NavigatorLanguage` (i18n) y `NavigatorCookies`

Adapta el idioma de tu interfaz automáticamente y verifica si las cookies están habilitadas en la sesión.

🌐

NavigatorLanguage

  • navigator.language: Idioma principal en formato BCP 47 (ej. "es-CO", "en-US").
  • navigator.languages: Arreglo de solo lectura ordenado por prioridad del usuario.
console.log(navigator.language);
console.log(navigator.languages);
🍪

NavigatorCookies

Expone la propiedad booleana navigator.cookieEnabled para confirmar si el navegador permite escribir y leer cookies.

if (!navigator.cookieEnabled) {
  alert("Habilita las cookies para iniciar sesión.");
}
Interfaz 3

3. `NavigatorOnLine`: Estado de Conexión a la Red

Combina la propiedad booleana navigator.onLine con los eventos online y offline en window.

Detección Reactiva de Conectividad conexion.js 
console.log("¿Conectado ahora?", navigator.onLine);

window.addEventListener("online", () => {
    console.log("🟢 Conexión restablecida. Sincronizando datos...");
});

window.addEventListener("offline", () => {
    console.log("🔴 Sin conexión. Activando modo offline.");
});
⚠️ Advertencia técnica: navigator.onLine === true confirma conexión con un router o red local, pero no garantiza acceso real a internet. Combínalo siempre con try / catch en tus peticiones fetch().
Interfaces 7 y 8

4. `NavigatorConcurrentHardware` y `NavigatorPlugins`

Dimensiona procesos paralelos según la potencia del procesador y consulta el soporte nativo de PDF.

⚡

Concurrencia (CPU)

navigator.hardwareConcurrency devuelve el número de procesadores lógicos disponibles.

const nucleos = navigator.hardwareConcurrency || 4;
const poolWorkers = Math.max(1, nucleos - 1);
📄

Plugins y Visor PDF

navigator.pdfViewerEnabled indica si el navegador renderiza PDFs de forma nativa; plugins y mimeTypes son colecciones heredadas.

if (navigator.pdfViewerEnabled) {
  console.log("Soporta PDF integrado.");
}
Interfaces 4 y 5

5. `NavigatorStorageUtils` y `NavigatorContentUtils`

Consulta la cuota de almacenamiento local disponible y registra manejadores para protocolos personalizados.

💾

Storage API (`navigator.storage`)

  • estimate(): Retorna promesa con usage y quota en bytes.
  • persist(): Solicita almacenamiento persistente para evitar borrado automático.
const { usage, quota } = await navigator.storage.estimate();
🔗

Protocolos (`registerProtocolHandler`)

Permite registrar tu aplicación web para abrir enlaces con esquemas como mailto: o personalizados web+ (requiere HTTPS).

navigator.registerProtocolHandler(
  "web+factura",
  "https://miapp.com/ver?url=%s"
);
Interfaz 9

6. `NavigatorUserMedia` (`navigator.mediaDevices`)

Solicita acceso a cámara web o micrófono mediante Promesas en contextos seguros (HTTPS o localhost).

Captura Moderna con getUserMedia() camara.js 
const iniciarCamara = async () => {
    try {
        const stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: false });
        document.getElementById("camara").srcObject = stream;
    } catch (error) {
        console.error("Permiso denegado:", error.message);
    }
};
💡 Limpieza obligatoria: Al cerrar la vista previa, ejecuta stream.getTracks().forEach(t => t.stop()) para apagar la luz física de la cámara.

7. Analogías y Buenas Prácticas

Usa Feature Detection en lugar de inspeccionar cadenas de texto frágiles.

🛂

El Pasaporte y el Tablero del Vehículo

Navigator es como tu pasaporte internacional (idioma, permisos, tránsito) combinado con el tablero del auto: te indica cuántos cilindros tiene el motor (hardwareConcurrency) y si hay señal activa (onLine).

🛡️

Feature Detection vs User-Agent Sniffing

Nunca escribas if (navigator.userAgent.includes("Chrome")). Verifica siempre si la característica existe: if ("mediaDevices" in navigator) y asigna valores de respaldo a propiedades opcionales.

9. Proyecto Integrador: Reporte del Entorno del Cliente

Recopila de forma segura todas las capacidades clave del navegador en una función asíncrona reutilizable.

Diagnóstico Completo diagnostico.js 
const generarReporteNavigator = async () => {
    const { usage, quota } = navigator.storage?.estimate
        ? await navigator.storage.estimate()
        : { usage: 0, quota: 0 };

    return {
        idioma: navigator.language,
        enLinea: navigator.onLine,
        nucleosCPU: navigator.hardwareConcurrency || "Desconocido",
        cookies: navigator.cookieEnabled,
        visorPDF: navigator.pdfViewerEnabled,
        usadoMB: (usage / 1e6).toFixed(2),
        cuotaGB: (quota / 1e9).toFixed(2)
    };
};

11. Clipboard, Web Share, Permissions y Cheatsheet

Explora las APIs modernas adicionales de window.navigator y consulta su tabla de referencia rápida.

Clipboard & Web Share

await navigator.clipboard.writeText('Hola');
await navigator.share({ title: 'Web', url });

Copia al portapapeles de forma asíncrona y abre el menú compartir nativo.

🔐

Permissions & Connection

await navigator.permissions.query({ name: 'notifications' });
navigator.connection?.effectiveType; // '4g'

Consulta permisos sin diálogos intrusivos y adapta calidad según la red.

🧭

Client Hints & sendBeacon

navigator.userAgentData?.mobile
navigator.sendBeacon('/analytics', blob)

Reemplaza el antiguo userAgent y envía telemetría confiable al salir de la página.
