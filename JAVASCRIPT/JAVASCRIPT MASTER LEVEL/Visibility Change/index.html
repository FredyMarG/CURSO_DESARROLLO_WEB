Sintaxis Fundamental

2. Cómo escuchar el evento `visibilitychange`

El evento se registra directamente en document y su estado actualizado se consulta dentro del callback.

Implementación Estándar visibility.js 
// Registramos el escuchador siempre sobre el objeto document
document.addEventListener("visibilitychange", () => {
    if (document.visibilityState === "visible") {
        console.log("👁️ El usuario regresó a la pestaña.");
    } else {
        console.log("🙈 El usuario ocultó o abandonó la pestaña.");
    }
});
💡 Dato clave del parámetro evento (e): El objeto e recibido por la función no contiene el nuevo estado; debes leer siempre document.visibilityState o document.hidden dentro del manejador.
Propiedades de Solo Lectura

3. `document.visibilityState` vs `document.hidden`

La API ofrece dos propiedades en document para consultar el estado exacto en cualquier momento.

📝

document.visibilityState (Recomendada)

Devuelve una cadena de texto descriptiva con el estado actual:

  • "visible": La pestaña está en primer plano y es al menos parcialmente visible.
  • "hidden": El contenido no es visible (otra pestaña, ventana minimizada o pantalla bloqueada).
🔘

document.hidden (Booleana)

Devuelve un booleano directo ideal para validaciones cortas:

document.addEventListener("visibilitychange", () => {
  if (document.hidden) {
    console.log("Pausando procesos...");
  } else {
    console.log("Reanudando...");
  }
});

1. La Luz del Refrigerador

La página web es el interior de un refrigerador. Mientras la puerta está abierta ("visible"), la luz se enciende y todo funciona a plena vista. En el instante en que cierras la puerta ("hidden"), el interruptor apaga la luz para no desperdiciar energía hasta que vuelvas a abrirla.

2. El Marcador de un Libro

Cuando estás leyendo y alguien te interrumpe, colocas un separador en la página (visibilityState === "hidden") y detienes tu lectura. Al volver a abrirlo (visibilityState === "visible"), retomas exactamente desde donde lo dejaste sin perder ningún párrafo.

6. Diagrama del Ciclo de Visibilidad

Secuencia exacta de eventos cuando el usuario alterna entre la pestaña activa y el segundo plano.

Usuario en Pestaña Activa (visibilityState === "visible")
Cambia de Pestaña / Minimiza

Estado pasa a "hidden"

  • Se dispara visibilitychange en document.
  • document.hidden se vuelve true.
  • Pausamos videos, animaciones e intervalos.
Regresa a la Pestaña

Estado vuelve a "visible"

  • Se dispara nuevamente visibilitychange.
  • document.hidden regresa a false.
  • Reanudamos procesos solo si fueron pausados por el sistema.

7. Buenas Prácticas y Errores Comunes

Evita los errores más habituales al gestionar reproducción automática, intervalos y eventos de foco.

✅ Buena Práctica 1

Respetar la Intención del Usuario

❌ Reanudar siempre video.play() al volver
✔️ Solo si pausadoAutomaticamente === true

Si el usuario pausó el video manualmente antes de irse, no lo reproduzcas automáticamente al volver.

✅ Buena Práctica 2

Registrar en document

❌ window.onvisibilitychange (Inconsistente)
✔️ document.addEventListener("visibilitychange", fn)

Garantiza compatibilidad completa tanto en navegadores de escritorio como en dispositivos móviles.

❌ Error Común 1

Confundir con window.onblur

❌ window.addEventListener("blur", pausar)
✔️ document.addEventListener("visibilitychange", ...)

blur se dispara aunque la página siga visible en pantalla dividida o al abrir DevTools.

❌ Error Común 2

Audio Automático sin Interacción

❌ video.play() en pestaña abierta en segundo plano
✔️ Usar .catch() o esperar interacción previa

Los navegadores bloquean el sonido automático si la página cargó en segundo plano sin clic previo.

9. Proyecto Integrador: Reproductor de Video Inteligente

Implementación completa que pausa al ocultar la pestaña y reanuda al volver usando la bandera pausadoAutomaticamente.

Reproductor con Control de Estado player.js 
const video = document.getElementById("video-principal");
let pausadoAutomaticamente = false;

document.addEventListener("visibilitychange", () => {
    if (document.visibilityState === "hidden" && !video.paused) {
        video.pause();
        pausadoAutomaticamente = true;
        document.title = "⏸️ Video en pausa - Vuelve pronto";
    } else if (document.visibilityState === "visible" && pausadoAutomaticamente) {
        video.play();
        pausadoAutomaticamente = false;
        document.title = "▶️ Reproduciendo tutorial";
    }
});
