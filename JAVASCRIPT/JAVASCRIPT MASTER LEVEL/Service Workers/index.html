Fundamentos

1. ¿Qué es un Service Worker y la interfaz `ServiceWorker`?

Es un trabajador especializado que actúa como intermediario programable entre tu web y la red.

🧩

Sin Acceso al DOM

No existen document, window ni localStorage; usa self.

⚡

Orientado a Eventos

Duerme para ahorrar RAM y despierta ante install, activate, fetch, message y push.

🔒

HTTPS Obligatorio

Por seguridad solo funciona bajo HTTPS o en localhost / 127.0.0.1.

♾️

Persistencia

Sigue registrado en el navegador incluso después de cerrar la pestaña.

Service Worker Lifecycle

2. Ciclo de Vida: Registro → Instalación → Activación

Estados internos: "parsed" → "installing" → "installed" → "activating" → "activated".

1️⃣

Registro (register)

main.js indica la ruta de sw.js. El navegador lo descarga y analiza en segundo plano.

2️⃣

Instalación (install)

Se dispara una vez (o si sw.js cambia 1 byte). Usa event.waitUntil() para precargar el App Shell.

3️⃣

Activación (activate)

Elimina cachés de versiones anteriores (caches.delete()) y toma el control con clients.claim().

Inicialización

3. Registro con `navigator.serviceWorker.register()`

Devuelve una Promesa con un objeto ServiceWorkerRegistration y define el alcance (scope) de rutas controladas.

Registro Seguro en main.js main.js 
if ("serviceWorker" in navigator) {
    window.addEventListener("load", async () => {
        const registro = await navigator.serviceWorker.register("./sw.js", { scope: "./" });
        console.log("SW registrado. Scope:", registro.scope);
    });
}
Mensajería Bidireccional

4. Comunicación con `postMessage()` y `message`

Intercambia comandos y estados entre la página y el Service Worker aislado.

Desde la Página (main.js)

Enviar y Escuchar

navigator.serviceWorker.controller?.postMessage({ tipo: "OBTENER_VERSION" });
navigator.serviceWorker.addEventListener("message", e => {
  console.log("Del SW:", e.data);
});
Desde el Worker (sw.js)

Responder con event.source

self.addEventListener("message", (event) => {
  event.source.postMessage({ version: "v1" });
});
Proxy de Red

5. Interceptación `fetch` y Soporte *Offline*

Usa event.respondWith() para servir recursos desde caché y mostrar offline.html si falla la red.

Estrategia Cache-First en sw.js sw.js 
self.addEventListener("fetch", (event) => {
    if (event.request.method !== "GET") return;
    event.respondWith(
        caches.match(event.request).then((res) => res || fetch(event.request))
    );
});
Control Avanzado

6. Actualización Inmediata y Eventos en Segundo Plano

Acelera el relevo de versiones y habilita capacidades nativas de PWA.

⚡

`skipWaiting()` y `clients.claim()`

self.skipWaiting() salta la fase de espera al instalar; self.clients.claim() toma el control inmediato de pestañas abiertas.

📲

Eventos `push` y `sync`

push recibe notificaciones con la web cerrada; sync reintenta envíos pendientes cuando vuelve el internet.

Comprensión & Calidad

7. Analogías y Buenas Prácticas

Evita los errores más frecuentes al desplegar Service Workers en producción.

🛎️

El Recepcionista y Relevo de Guardia

El recepcionista revisa primero su armario (Caché) antes de llamar afuera (Red). El guardia nuevo aprende las reglas (install) antes de relevar al anterior (activate).

🛡️

Reglas de Oro

Versiona la caché (v1, v2), envuelve todo en event.waitUntil(), NO caches sw.js y nunca uses localStorage o document dentro del SW.

9. Proyecto Integrador: Sitio Web con Soporte *Offline*

Combinación completa de install, activate y fetch con respaldo HTML.

Ciclo Completo en sw.js sw.js 
self.addEventListener("install", e => e.waitUntil(caches.open("v1").then(c => c.addAll(["./", "./index.html"]))));
self.addEventListener("activate", e => e.waitUntil(caches.keys().then(ks => Promise.all(ks.map(k => k !== "v1" ? caches.delete(k) : null)))));

10. Ejercicios Prácticos y Solucionario

Practica registro seguro, precarga en install y mensajería PING / PONG.

Nivel 1 & Nivel 2

Registro y Precarga

navigator.serviceWorker.register("./sw.js");
self.addEventListener("install", e => {
  e.waitUntil(caches.open("v1").then(c => c.addAll(["./"])));
});
Nivel 3: PING / PONG

Comunicación con event.source

self.addEventListener("message", e => {
  if (e.data?.tipo === "PING") e.source.postMessage({ respuesta: "PONG" });
});

11. Resumen Técnico y Hoja de Trucos

Referencia rápida para implementar Service Workers confiables en producción.

🚀

register()

Registra sw.js desde la página en HTTPS o localhost.

📦

install + waitUntil()

Abre la caché y descarga el App Shell antes de finalizar.

🧹

activate + delete()

Borra versiones antiguas y toma el control con clients.claim().

🌐

fetch + respondWith()

Sirve caché al instante y habilita funcionamiento sin internet.
