Módulo 07 · Bucles For y Etiquetas

for Clásico, for...of, for...in y Labels

Compara cómo recorren arrays y objetos las distintas variantes de for, y prueba el control de bucles anidados mediante etiquetas (label).

1. Bucle for Clásico (Tabla dinámica)

Ideal cuando sabes exactamente cuántas iteraciones necesitas o requieres un paso personalizado.

for (let i = 1; i <= 5; i++) { ... }
Pulsa el botón para generar la tabla.

2. for...of (Valores) vs for...in (Claves)

for...of recorre valores de iterables (Arrays, Strings). for...in recorre claves enumerables (incluyendo propiedades extra si se usa en un array).

for (const [i, v] of animales.entries()) { ... }
Compara las salidas sobre ["gato", "perro", "loro"].

3. Bucles Anidados con label

Busca un nombre dentro de una matriz bidimensional y detén ambos bucles al instante con break externo;.

externo: for (...) { for (...) { if (match) break externo; } }
Prueba buscar "josefa", "marcelo" o "ana".
