Módulo 06 · Iteración Condicional

Bucles while, do...while y Control de Flujo

Comprende cuándo la condición se evalúa antes o después de ejecutar el bloque, y cómo detener o saltar iteraciones con break y continue.

1. while vs do...while

Prueba un límite inicial de 0: while no se ejecuta ninguna vez; do...while se ejecuta al menos 1 vez.

while (i < limite) { ... }
do { ... } while (i < limite);
Prueba con límite = 0 o límite = 4.

2. break (Detener) y continue (Saltar)

Recorremos números del 1 al 10. Configura un número para saltar (continue) y otro para detener todo (break).

if (i === skip) continue;
if (i === stop) break;
Pulsa "Ejecutar Secuencia".
