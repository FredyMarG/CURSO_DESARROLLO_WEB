Concatenación y Template Literals

Compara el operador +, .concat(), Array.join() y los modernos Template Literals, además de cómo prevenir vulnerabilidades XSS al mostrar texto en el DOM.

1. Constructor de Template Literals

Edita los campos para ver cómo se construye el mismo mensaje con +, .concat() y backticks `${}`.

`Hola, soy ${nombre} y domino ${lenguaje}.`
Presiona "Generar Comparación" para ver los 3 métodos.

2. Coerción de Tipos con +

JavaScript evalúa de izquierda a derecha. Un solo string convierte el resto de la suma en concatenación si no usas paréntesis.

"Total: " + 5 + 3   // "Total: 53"
"Total: " + (5 + 3) // "Total: 8"
Elige una expresión para evaluar su resultado y tipo.

3. Inserción Segura (textContent)

Nunca insertes texto de usuario con innerHTML. Usa textContent para que etiquetas maliciosas se muestren como texto inofensivo.

nodo.textContent = `Comentario: ${entrada}`;
El texto se renderizará de forma segura aquí.
