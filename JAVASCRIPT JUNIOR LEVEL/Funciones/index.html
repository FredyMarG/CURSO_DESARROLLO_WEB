Módulo 10 · Modularidad y Scope

Funciones, Callbacks y Closures

Explora funciones declaradas vs flecha, parámetros por defecto y Rest (...args), callbacks, closures con estado privado y listeners de un solo uso.

1. Parámetros por Defecto & Arrow Functions

Si dejas el nombre vacío, la función usa el valor por defecto "Invitado".

const saludar = (nombre = "Invitado") => `¡Hola, ${nombre}!`;
Pulsa el botón para invocar la función.

2. Parámetros Rest (...nums) & Callbacks

Ingresa números separados por coma y elige qué operación callback aplicar sobre ellos.

const operar = (cb, ...nums) => cb(nums);
Elige un callback para procesar los números.

3. Closures (Estado Privado)

Cada contador recuerda su propia variable cuenta interna gracias a su closure léxico.

function crearContador() {
  let cuenta = 0;
  return () => ++cuenta;
}
Cuenta actual: 0

4. Evento Único (removeEventListener)

El botón inferior ejecuta su saludo solo en el primer clic y luego se auto-elimina con removeEventListener.

btn.addEventListener("click", saludarUnaVez);
Haz clic en el botón (1ª vez saluda y se desuscribe).
