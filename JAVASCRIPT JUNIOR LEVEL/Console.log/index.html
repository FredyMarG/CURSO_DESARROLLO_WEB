Módulo 09 · Depuración y DevTools

API console en JavaScript

Dispara cada método de depuración y observa el resultado en el panel inferior y en la consola real del navegador (F12 / Ctrl + Shift + I).

1. Niveles de Registro y assert

Diferencia mensajes informativos, advertencias, errores y aserciones condicionales.

console.assert(stock > 0, "Sin stock disponible");
Pulsa un botón para emitir un registro.

2. table, group y Estilos %c

Visualiza arrays de objetos como tabla, agrupa trazas y aplica CSS en DevTools con %c.

console.table(usuarios, ["nombre", "rol"]);
Mira la tabla formateada aquí y en DevTools.

3. Rendimiento (time), count y trace

Mide cuánto tarda un algoritmo en milisegundos, cuenta invocaciones e imprime el stack trace.

console.time("bucle"); /* ... */ console.timeEnd("bucle");
Ejecuta un benchmark o contador en vivo.
