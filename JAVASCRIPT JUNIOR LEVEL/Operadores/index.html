Módulo 02 · Operadores ES2020+

Operadores Aritméticos, Lógicos y Modernos

Experimenta con asignación compuesta, igualdad estricta (===), Nullish Coalescing (??), Optional Chaining (?.) y asignación lógica.

1. Asignación Compuesta

Aplica operadores sobre una variable de estado (valor = 10 inicialmente) y observa cómo muta paso a paso.

let valor = 10; valor += 5; // 15
Valor actual: 10

2. Igualdad Débil (==) vs Estricta (===)

== convierte tipos automáticamente (coerción). === exige que valor y tipo coincidan.

5 == "5"  // true (⚠️ coerción)
5 === "5" // false (✅ estricto)
Elige un par y presiona "Comparar".

3. OR (||) vs Nullish Coalescing (??)

|| reemplaza cualquier valor falsy (0, "", false). ?? solo actúa ante null o undefined.

valor || 100  // vs  valor ?? 100
Comprueba por qué ?? es vital para valores como 0.

4. Optional Chaining (?.)

Evita el clásico TypeError al leer propiedades anidadas que podrían no existir en una respuesta de API.

const ciudad = user.perfil?.direccion?.ciudad ?? "Sin ciudad";
Prueba ambos objetos para ver cómo ?. protege tu app.
