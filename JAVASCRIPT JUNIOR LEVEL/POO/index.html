Programación Orientada a Objetos (POO)

Crea instancias con class y new, extiende comportamiento con extends y super(), encapsula datos con campos privados (#) y usa métodos static.

1. Clases, Herencia (extends) & instanceof

Instancia un Perro (subclase de Animal) y observa cómo hereda propiedades y sobrescribe métodos.

class Perro extends Animal { constructor(n, r) { super(n); } }
Pulsa "Instanciar Perro" para crear el objeto.

2. Encapsulamiento Real (#saldo) y Getters

#saldo es privado: solo puede modificarse mediante depositar() o retirar() validados.

class Cuenta { #saldo = 100; get saldo() { return this.#saldo; } }
Saldo inicial: $100

3. Métodos Estáticos (static)

Los métodos estáticos se llaman directo en la clase (sin usar new).

Validador.esNombreValido("Sofía") // true
Prueba nombres cortos (< 3 letras) vs válidos.
