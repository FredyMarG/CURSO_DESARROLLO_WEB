Variables, Scope y Tipos de Datos

Prueba en vivo const, let, var, la Temporal Dead Zone (TDZ), el operador typeof y la diferencia entre copia por valor y por referencia.

1. Inspector de Tipos (typeof)

Elige un valor o escribe uno personalizado para inspeccionar su tipo real y sus casos especiales (null, NaN, Array).

typeof valor; Array.isArray(valor); Number.isNaN(valor);
Selecciona un valor y presiona "Inspeccionar Tipo".

2. Conversión Segura de Entradas

Los inputs del DOM (como prompt()) siempre devuelven texto (string). Conviértelos con Number() antes de operar.

const num = Number(entrada);
if (!Number.isNaN(num)) resultado = num ** 2;

3. Scope (var vs let/const) & TDZ

let y const respetan bloques {} y entran en la Temporal Dead Zone antes de declararse. var se filtra fuera del bloque.

if (true) { var a = 1; let b = 2; }
// 'a' existe aquí; 'b' lanza ReferenceError
Presiona un botón para ver el comportamiento del motor JS.

4. Primitivos (Valor) vs Objetos (Referencia)

Copiar un objeto con = comparte la misma dirección en memoria. Usa structuredClone() para una copia independiente.

const copia = structuredClone(original);
Compara cómo reacciona el objeto original en ambos casos.
