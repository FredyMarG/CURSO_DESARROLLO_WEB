Arrays y Métodos Funcionales

Manipula colecciones en vivo: métodos mutables (push, pop, shift), transformación funcional (map, filter, reduce) e inmutabilidad ES2023 (toSorted, toReversed, with).

1. Métodos Mutables (Pila y Cola)

Agrega o quita elementos del array frutas y observa cómo cambia su contenido y longitud.

frutas.push("Mango"); frutas.at(-1); // último

2. Pipeline Funcional (filter → map → reduce)

Procesa el array de precios [40, 120, 85, 210, 30] sin mutar el original.

precios.filter(p => p >= min).map(p => p * 0.9)
Presiona el botón para ver cada etapa del pipeline.

3. Métodos Inmutables ES2023

.toSorted(), .toReversed() y .with() devuelven una copia nueva dejando el array original [30, 5, 100, 20] intacto.

const ordenados = nums.toSorted((a, b) => a - b);
Original: [30, 5, 100, 20]
