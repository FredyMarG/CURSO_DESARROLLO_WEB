Estructuras Condicionales

Prueba en tiempo real if / else if / else, switch, el operador ternario, valores Truthy / Falsy y cláusulas de guarda (Early Return).

1. Saludo por Hora (if / else if)

Ajusta la hora del día (0–23) para ver qué rama del bloque condicional se ejecuta.

if (hora < 12) ... else if (hora <= 18) ... else ...
Ajusta la hora y presiona "Evaluar Hora".

2. Sentencia switch vs Diccionario

switch compara con igualdad estricta (===). Un objeto diccionario suele ser una alternativa más limpia para mapeos simples.

switch (rol) { case "admin": ... break; default: ... }
Selecciona un rol para evaluar sus permisos.

3. Laboratorio Truthy vs Falsy

En JS solo 6 valores (false, 0, "", null, undefined, NaN) son falsy. ¡Incluso [] y {} son truthy!

if (valor) { /* truthy */ } else { /* falsy */ }
Prueba qué valores entran al if y cuáles al else.

4. Cláusulas de Guarda (Early Return)

Valida errores o requisitos al principio y retorna temprano para evitar anidar múltiples if.

if (edad < 18) return "Denegado: menor de edad";
if (!tieneEntrada) return "Denegado: falta entrada";
Pulsa "Validar Acceso" para probar las guardas.
