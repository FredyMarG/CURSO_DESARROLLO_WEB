Matemáticas, Aleatorios y Precisión Numérica

Compara métodos de redondeo (incluso con negativos), genera números aleatorios en rango o UUIDs seguros con crypto, y entiende la precisión flotante IEEE 754.

1. Redondeo: round, floor, ceil, trunc

Prueba un número negativo como -4.2 para ver la diferencia entre Math.floor() y Math.trunc().

Math.floor(-4.2) // -5 | Math.trunc(-4.2) // -4
Pulsa "Calcular Redondeos".

2. Aleatorios en Rango y crypto.randomUUID()

Usa Math.random() para juegos/simulaciones y crypto.randomUUID() para identificadores únicos seguros.

Math.floor(Math.random() * (max - min + 1)) + min
Genera un número en rango o un UUID v4.

3. Precisión Flotante (0.1 + 0.2)

El estándar binario IEEE 754 hace que 0.1 + 0.2 !== 0.3. En dinero, opera en centavos enteros o compara con Number.EPSILON.

Math.abs((0.1 + 0.2) - 0.3) < Number.EPSILON
Pulsa para inspeccionar la precisión flotante.
