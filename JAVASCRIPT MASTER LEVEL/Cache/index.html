Almacenamiento de Red:
Cache API (caches)

Intercepta, guarda, consulta y versiona respuestas HTTP completas de forma 100% asíncrona para construir aplicaciones web ultrarrápidas y funcionales sin conexión.

📴

Modo Offline (PWA)

Guarda el App Shell (HTML, CSS, JS, iconos) para cargar sin internet.

⚡

Carga Instantánea

Sirve recursos desde el disco en milisegundos reduciendo latencia y datos móviles.

🔄

Control de Versiones

Actualiza tu web limpiando almacenes obsoletos con caches.delete().

🔒

Asíncrono & Seguro

Basado en Promesas, funciona en window y Service Workers bajo HTTPS/localhost.

Arquitectura de Almacenamiento

1. ¿Qué es la Cache API y en qué supera a `localStorage`?

Diseñada específicamente para almacenar respuestas de red completas, sin bloquear el hilo principal.

⚠️ localStorage

Solo Texto Síncrono (~5 MB)

  • ❌ Bloquea el hilo principal al leer/escribir.
  • ❌ Solo acepta cadenas de texto (Strings).
  • ❌ No disponible dentro de Service Workers.
✅ Cache API (caches)

Pares Request / Response Asíncronos

  • ✔️ 100% asíncrona basada en Promesas.
  • ✔️ Guarda binarios, imágenes, fuentes, HTML y JSON.
  • ✔️ Capacidad de cientos de MB según cuota del disco.
Gestión de Almacenes

2. Apertura de Almacenes con `caches.open()`

Si el almacén indicado no existe, el navegador lo crea automáticamente de forma persistente.

Apertura con Versión cache.js 
const iniciarCache = async () => {
    const cache = await caches.open("archivos.estaticos");
    console.log("Caché abierta y lista:", cache);
};
Escritura en Caché

3. Almacenar Recursos: `add()`, `addAll()` y `put()`

Tres métodos especializados según si deseas descargar automáticamente o guardar una respuesta manual.

📄

cache.add(url)

await cache.add("/style.css");

Ejecuta fetch() automáticamente y guarda la respuesta. Si falla la red, rechaza la promesa.

📦

cache.addAll(urls)

await cache.addAll(["/", "/app.js"]);

Descarga todo en paralelo. Es atómico: si falla un archivo, no guarda ninguno.

✍️

cache.put(req, res)

await cache.put(url, res.clone());

Guarda manualmente un par Request/Response ya obtenido (o creado con new Response()).

Lectura de Caché

4. Consultar Información: `match()`, `matchAll()` y `keys()`

Recupera una respuesta puntual, múltiples coincidencias en arreglo o inspecciona todas las llaves guardadas.

🔍

match(request)

await caches.match("/api/saludo");

Devuelve la primera Response que coincida o undefined si no existe.

📚

matchAll(req, opts)

await cache.matchAll("/api", { ignoreSearch: true });

Devuelve un Array con todas las respuestas coincidentes (ej. distintos query params).

🗝️

keys()

await cache.keys(); // Requests
await caches.keys(); // Nombres

Lista las peticiones dentro de un almacén o los nombres de todos los almacenes.

Limpieza & Versionado

5. Eliminar Información: `cache.delete()` y `caches.delete()`

Mantén el almacenamiento limpio eliminando archivos puntuales o versiones antiguas completas.

🗑️

Borrar 1 Recurso: `cache.delete()`

const cache = await caches.open("archivos.estaticos");
const ok = await cache.delete("/api/saludo");
💥

Borrar Almacén: `caches.delete()`

const nombres = await caches.keys();
await Promise.all(nombres.map(n => n !== "v2" ? caches.delete(n) : null));
Patrones PWA

6. Estrategias Profesionales de Caché

Elige la estrategia adecuada según la frecuencia con que cambian tus recursos.

⚡

Cache-First

Responde desde caché primero; solo va a la red si no existe. Ideal para CSS, fuentes, iconos y App Shell.

🌐

Network-First

Intenta descargar datos frescos; si falla (offline), usa la copia en caché. Ideal para noticias o feeds.

🔄

Stale-While-Revalidate

Sirve caché al instante en 0 ms y descarga en segundo plano una versión nueva para la próxima visita.

Comprensión & Calidad

7. Analogías y Buenas Prácticas

Evita los errores clásicos con Response.clone(), métodos POST y rutas rotas en addAll().

🥫

La Despensa y Cajas de Mudanza

Ir al súper cada vez es fetch(); guardar básicos en la despensa es cache.addAll(). Cada versión de tu app es una caja sellada ("app-v1") que desechas completa con caches.delete().

🛡️

Reglas de Oro

Usa res.clone() antes de cache.put() (un Response stream solo se lee una vez). Almacena únicamente peticiones GET (POST lanza TypeError).

10. Ejercicios Prácticos y Solucionario

Domina la apertura, lectura JSON desde caché y limpieza de versiones antiguas.

Nivel 1 & Nivel 2

put() y match() con JSON

const c = await caches.open("archivos.estaticos");
await c.put("/api/user", new Response(JSON.stringify({ nombre: "Ana" })));
const res = await caches.match("/api/user");
console.log(await res.json());
Nivel 3: Purgar Versiones

Limpiar Cachés Obsoletas

const limpiar = async (actual) => {
  const keys = await caches.keys();
  await Promise.all(keys.map(k => k !== actual ? caches.delete(k) : null));
};
