Fundamento 01

Introducción a la API de Drag & Drop y el Atributo draggable

La API de Drag & Drop de HTML5 proporciona soporte nativo para arrastrar elementos y transferir datos entre componentes sin calcular coordenadas manualmente:

Configuración Inicial Obligatoria

Adiós al Cálculo Manual: Antes de HTML5 era necesario escuchar mousedown, mousemove y calcular manualmente clientX y clientY. Hoy el navegador expone un ecosistema nativo completo.

El interruptor draggable="true": Por defecto, solo las imágenes (<img>) y los enlaces (<a href="...">) son arrastrables. Para cualquier <div> personalizado es obligatorio declarar draggable="true".

💡 Prueba en Vivo: Arrastra el círculo amarillo de la derecha y suéltalo dentro del cuadrado gris para disparar los eventos reales en pantalla.

Enfoque Antiguo (Coordenadas)

  • Cálculo manual de clientX y clientY.
  • Posicionamiento absoluto forzado en CSS.
  • Sin soporte nativo para transferir archivos del SO.

API Nativa Drag & Drop

  • 7 eventos especializados de objeto y zona.
  • Transporte de datos integrado en dataTransfer.
  • Soporte directo con draggable="true".
circulo_y_cuadrado_drag_drop.js 
"use strict";
const circulo = document.querySelector(".circulo");
const cuadrado = document.querySelector(".cuadrado");

circulo.addEventListener("dragstart", e => {
    e.dataTransfer.setData("text-plain", e.target.className);
});
cuadrado.addEventListener("dragover", e => e.preventDefault());
cuadrado.addEventListener("drop", e => {
    console.log("Drop:", e.dataTransfer.getData("text-plain"));
});

Fundamento 02

El Ciclo de Vida: 3 Eventos del Objeto vs. 4 Eventos de Zona

El ciclo de arrastre se divide arquitectónicamente en dos frentes: el elemento que se mueve (emisor) y el contenedor que lo recibe (receptor):

1. El Elemento Arrastrado

Eventos del Objeto (3)

Configurados sobre .circulo o .textura
  • 1. dragstart: Se dispara en el milisegundo exacto en que inicia el arrastre. Único lugar para setData().
  • 2. drag: Se ejecuta en bucle continuo a alta frecuencia mientras el cursor desplaza el objeto.
  • 3. dragend: Se activa al soltar el botón o cancelar con Esc. Ideal para restaurar estilos/opacidad.
⚡
Regla de Inicialización: La carga útil en e.dataTransfer.setData() solo puede escribirse dentro de dragstart.
Viaje DOM
➔
Emisor a Receptor
2. El Contenedor Receptor

Eventos de Zona (4)

Configurados sobre .cuadrado o .drop-zone
  • 1. dragenter: El cursor entra por primera vez en los límites de la zona (ilumina la interfaz).
  • 2. dragover (o dragmove): Flota dentro de la zona. Obligatorio ejecutar e.preventDefault().
  • 3. dragleave: El cursor sale de la zona sin soltar el objeto (limpia el resaltado).
  • 4. drop: Se suelta el objeto en la zona habilitada y se lee getData().
🔓
Desbloqueo de Recepción: Por defecto, el navegador prohíbe soltar elementos en un div; e.preventDefault() en dragover lo desbloquea.

Evento Objetivo (Target) Frecuencia de Disparo Responsabilidad Principal en Producción
dragstart Objeto 1 sola vez (al iniciar) Cargar datos con e.dataTransfer.setData() y bajar opacidad (classList.add).
drag Objeto Continua (cada pocos ms) Monitorear desplazamiento o actualizar coordenadas en tiempo real.
dragend Objeto 1 sola vez (al finalizar) Restaurar opacidad a 1 y limpiar clases del objeto arrastrado.
dragenter / dragleave Zona Al entrar / salir del borde Agregar o quitar la clase visual .zona-activa en el contenedor receptor.
dragover (dragmove) Zona Continua sobre la zona Invocar obligatoriamente e.preventDefault() para habilitar el drop.
drop Zona 1 sola vez (al soltar) Ejecutar e.preventDefault(), extraer carga con getData() y procesar cambios.

Arquitectura del Ciclo

Diagrama de Flujo del Arrastre, Desbloqueo de Zona y Seguridad

Explora paso a paso el árbol de decisiones que ejecuta el navegador desde que el usuario hace clic sobre el objeto hasta que lo libera en la zona de destino:

5.1 Diagrama de Flujo del Ciclo de Arrastre

¿Entra en Zona de Destino? ¿Se suelta el objeto o sale de la zona?

1. Origen: Objeto con draggable="true" dispara dragstart (define carga con setData()) y entra en el ciclo drag.
2. Zona: Si entra a la zona dispara dragenter y dragover (con e.preventDefault()). Si sale sin soltar dispara dragleave; si suelta dispara drop (lee getData()) y cierra con dragend.

5.2 ¿Por qué es obligatorio e.preventDefault() en dragover y drop?

Anulando la restricción nativa del navegador en contenedores genéricos

Por diseño estándar de HTML5, casi ningún elemento del DOM permite que le suelten objetos encima (muestra el cursor de prohibido 🚫). Invocar e.preventDefault() en dragover le indica al navegador que esa zona acepta entregas, y en drop evita que el navegador abra imágenes o enlaces arrastrados como una nueva pestaña.

Haz clic para comparar el estado del cursor y del evento drop con y sin preventDefault...
5.3 Aislamiento de Seguridad en Eventos Intermedios

¿Por qué getData() solo entrega los datos en el evento drop?

Por razones estrictas de seguridad del navegador, el contenido guardado en dataTransfer permanece en modo protegido durante los eventos intermedios (drag, dragenter, dragover, dragleave). Esto impide que zonas publicitarias o elementos ajenos por los que pase el ratón espíen lo que el usuario está arrastrando antes de soltarlo.

Estándares de la Industria

Buenas Prácticas y Errores Comunes en Drag & Drop

Domina las reglas técnicas para evitar bloqueos silenciosos al implementar interfaces arrastrables:

❌ ERROR: LEER FUERA DE DROP

Invocar getData() en dragover o dragenter

En los eventos intermedios como dragover o dragenter, el contenedor dataTransfer está bloqueado contra lectura por seguridad y devolverá "".

zona.addEventListener("dragover", e => e.dataTransfer.getData("text/plain")); // ❌ ""
❌ ERROR: ZONA BLOQUEADA 🚫

Olvidar e.preventDefault() en dragover

Si no cancelas el comportamiento por defecto en dragover, el puntero mostrará el icono de bloqueo y el evento drop jamás se ejecutará al soltar el clic.

zona.addEventListener("dragover", e => console.log("Over")); // ❌ Drop nunca ocurre
✅ BUENA PRÁCTICA: DESBLOQUEO

Cancelar siempre dragover y drop

Invoca siempre e.preventDefault() tanto en dragover (para habilitar la recepción) como en drop (para evitar aperturas accidentales de archivos/URLs).

lienzo.addEventListener("dragover", e => e.preventDefault()); // ✅ Habilitado
✅ BUENA PRÁCTICA: ARQUITECTURA CSS

Usar classList en lugar de estilos inline

Gestiona el feedback visual en dragstart/dragend y dragenter/dragleave añadiendo y removiendo clases CSS con classList.

lienzo.addEventListener("dragenter", ({ target }) => target.classList.add("zona-activa")); // ✅
Proyecto Integrador de Producción

Implementando un Texturizador Interactivo con dataTransfer

Observa cómo combinamos draggable="true", atributos data-url y desestructuración de parámetros ({ dataTransfer, target }) para aplicar texturas en vivo:

1. Código Moderno con Desestructuración ES6+

En cada miniatura guardamos su ID y su patrón CSS (target.dataset.url) durante dragstart, y lo aplicamos al fondo del lienzo en drop: 

const texturas = document.querySelectorAll(".textura");
const lienzo = document.getElementById("canvas-destino");

texturas.forEach(textura => {
  textura.addEventListener("dragstart", ({ dataTransfer, target }) => {
    dataTransfer.setData("text/plain", target.id);
    dataTransfer.setData("text/url-pattern", target.dataset.url);
    target.classList.add("arrastrando");
  });
  textura.addEventListener("dragend", ({ target }) =>
    target.classList.remove("arrastrando"));
});

lienzo.addEventListener("dragover", e => e.preventDefault());
lienzo.addEventListener("drop", e => {
  e.preventDefault();
  const patron = e.dataTransfer.getData("text/url-pattern");
  if (patron) lienzo.style.background = patron;
});

Cheat Sheet & Solucionario

Resumen Maestro y Retos Prácticos Paso a Paso

Consolida tu dominio de la API nativa de Drag & Drop con estos 3 retos progresivos:

Nivel 1 — Junior

Control del Objeto Emisor (.circulo)

Configura los eventos dragstart y dragend sobre un elemento arrastrable para reducir su opacidad a "0.5" al iniciar el arrastre, guardar su clase o ID en dataTransfer y restaurar su opacidad a "1" al finalizar. 

circulo.addEventListener("dragstart", (e) => {
    circulo.style.opacity = "0.5";
    e.dataTransfer.setData("text/plain", e.target.className);
});

circulo.addEventListener("dragend", () => {
    circulo.style.opacity = "1";
});
Nivel 2 — Semi Senior

Zona Receptora Habilitada (.cuadrado)

Programa los 4 eventos de la zona receptora (dragenter, dragover, dragleave y drop) alternando la clase "zona-activa", desbloqueando la recepción con e.preventDefault() y leyendo getData() al soltar. 

cuadrado.addEventListener("dragenter", ({ target }) => target.classList.add("zona-activa"));
cuadrado.addEventListener("dragleave", ({ target }) => target.classList.remove("zona-activa"));
cuadrado.addEventListener("dragover", (e) => e.preventDefault());

cuadrado.addEventListener("drop", (e) => {
    e.preventDefault();
    const claseOrigen = e.dataTransfer.getData("text/plain");
    cuadrado.classList.remove("zona-activa");
    console.log("Elemento recibido:", claseOrigen);
});
Nivel 3 — Producción

Proyecto Integrador: El Texturizador

Implementa el motor del Texturizador usando desestructuración en los parámetros del evento ({ dataTransfer, target }) para transportar target.dataset.url bajo el formato "text/url-pattern" y aplicarlo a backgroundImage en el evento drop. 

texturas.forEach(textura => {
    textura.addEventListener("dragstart", ({ dataTransfer, target }) => {
        dataTransfer.setData("text/plain", target.id);
        dataTransfer.setData("text/url-pattern", target.dataset.url);
        target.classList.add("arrastrando");
    });
    textura.addEventListener("dragend", ({ target }) => target.classList.remove("arrastrando"));
});

lienzo.addEventListener("dragover", (e) => e.preventDefault());
lienzo.addEventListener("drop", (e) => {
    e.preventDefault();
    const { dataTransfer, target } = e;
    const rutaImagen = dataTransfer.getData("text/url-pattern");
    if (rutaImagen) target.style.backgroundImage = rutaImagen;
    target.classList.remove("zona-activa");
});
1️⃣

Atributo draggable

Declara siempre draggable="true" en HTML para habilitar el arrastre en cualquier nodo del DOM.

2️⃣

Dos Frentes de Eventos

Controla el objeto emisor (dragstart, drag, dragend) y la zona receptora (dragenter, dragover, dragleave, drop).

3️⃣

e.preventDefault()

Invócalo obligatoriamente en dragover para desbloquear la zona y permitir que ocurra el evento drop.

4️⃣

Motor dataTransfer

Guarda datos en dragstart con setData(formato, valor) y extráelos en drop con getData(formato).

5️⃣

Clases CSS Limpias

Usa classList.add() y remove() para resaltar zonas activas y recuerda que getData() está aislado fuera de drop.
