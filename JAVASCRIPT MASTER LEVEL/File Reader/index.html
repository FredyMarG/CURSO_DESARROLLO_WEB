Fundamento 01

Lectura de Contenido Textual con readAsText()

Lee archivos basados en texto plano directamente a una cadena string legible en JavaScript:

Sintaxis & Parámetros

reader.readAsText(blob[, encoding]) inicia la lectura asíncrona del archivo especificado. Cuando la operación concluye, el resultado se expone en reader.result.

  • blob: Un objeto File o Blob obtenido de un <input type="file"> o evento drop.
  • encoding: Codificación de caracteres (por defecto "UTF-8").
  • Formatos ideales: .txt, .json, .csv, .md, .xml, código fuente.

Enfoque Tradicional

  • Subir archivo al servidor por POST/FormData.
  • Esperar respuesta por red.
  • Mayor latencia y consumo de ancho de banda.

FileReader API

  • Lectura 100% en memoria en el cliente.
  • Respuesta instantánea y offline.
  • Máxima privacidad y seguridad.
lector_texto_interactivo.js 
const reader = new FileReader();
reader.addEventListener("load", () => {
  console.log("Contenido:", reader.result);
});
reader.readAsText(archivo, "UTF-8");

Fundamento 02

Codificación en Data URL con readAsDataURL()

Convierte archivos binarios (imágenes, audios o documentos) en URIs Base64 autocontenidas:

Esquema Data URI

reader.readAsDataURL(blob) lee los bytes crudos del archivo y genera una cadena con el siguiente formato:

data:[<mediatype>][;base64],<datos-codificados>

Ventaja inmediata: Puede asignarse de forma directa al atributo src de un elemento <img>, <video> o como fondo CSS sin necesidad de subir la imagen a ningún servidor.

💡
¿Sabías que? Base64 incrementa el peso del archivo aproximadamente un 33% respecto a sus bytes binarios originales.
previsualizador_imagen.js 
const reader = new FileReader();
reader.addEventListener("load", () => {
  imgPreview.src = reader.result; // Base64 Data URL
});
reader.readAsDataURL(archivoImagen);

Caso Práctico 01

Carga de Múltiples Archivos (Multi-File Loader) & Galería Dinámica

Aprende a procesar colecciones completas de archivos seleccionados mediante <input multiple> o Drag & Drop en paralelo:

Procesamiento Paralelo de FileList

Al añadir el atributo multiple a un <input type="file"> o recibir varios archivos por Drag & Drop, el navegador entrega un FileList.

  1. Convertir la colección con Array.from(e.target.files).
  2. Detectar el tipo MIME:
    • image/* ➔ leer con readAsDataURL() (miniaturas).
    • text/*, .json, .csv ➔ leer con readAsText().
    • Binarios ➔ leer con readAsArrayBuffer().
  3. Instanciar un nuevo FileReader para CADA archivo (evita la excepción InvalidStateError).
  4. Renderizar tarjetas interactivas con tamaño, estado y previsualización.
carga_multiples_archivos.js 
// Procesar múltiples archivos de cualquier tipo
Array.from(archivos).forEach(archivo => {
  const lector = new FileReader();
  if (archivo.type.startsWith("image/")) {
    lector.addEventListener("load", () => mostrarMiniatura(lector.result));
    lector.readAsDataURL(archivo);
  } else {
    lector.addEventListener("load", () => mostrarTexto(lector.result));
    lector.readAsText(archivo, "UTF-8");
  }
});

Caso Práctico 02

Integración de FileReader con la API de Drag & Drop

Permite a los usuarios arrastrar archivos directamente desde su escritorio a la aplicación:

e.dataTransfer.files

Al arrastrar archivos desde el explorador del sistema operativo, el navegador expone los archivos en e.dataTransfer.files.

⚠️ Regla de Oro: Es indispensable llamar a e.preventDefault() en los eventos dragover y drop, de lo contrario el navegador intentará abrir el archivo en la pestaña actual.

Arquitectura & Eventos

El Ciclo de Vida de Eventos de FileReader

Comprende la secuencia cronológica y los estados asíncronos del proceso de lectura:

Evento Momento de Disparo Propiedades Clave Uso Recomendado
loadstart Comienza la lectura del archivo. e.loaded = 0 Mostrar spinners, modales o inicializar barras de progreso.
progress Durante la lectura continua de bytes. e.lengthComputable, e.loaded, e.total Calcular porcentaje: (loaded / total) * 100.
load Lectura finalizada con éxito. reader.result disponible Renderizar texto o asignar Base64 a la imagen.
error Ocurre un error de lectura o permisos. reader.error Mostrar mensaje de error al usuario y loguear fallo.
abort Se cancela la operación con reader.abort(). Lectura interrumpida Botones de "Cancelar carga" en archivos pesados.
loadend Conclusión definitiva (éxito, error o aborto). Ciclo cerrado Ocultar loaders, resetear botones y liberar memoria.
Laboratorio 03

Monitoreo de Progreso en Tiempo Real con progress y loadend

Simula o experimenta con la lectura de archivos de gran tamaño calculando el avance de bytes:

Fórmula de Progreso 
reader.addEventListener("progress", (e) => {
  if (e.lengthComputable) {
    const porcentaje = Math.round((e.loaded / e.total) * 100);
    barra.style.width = porcentaje + "%";
  }
});

Cheat Sheet & Solucionario

Resumen Maestro y Retos Prácticos Paso a Paso

Asegura tu comprensión resolviendo los 3 retos de aplicación real de la FileReader API:

Nivel 1 — Junior

Reto 1: Lector y Validador JSON Seguro con try / catch

▼

Enunciado: Crea una función que reciba un archivo .json, lo lea con readAsText() y parsee el contenido con JSON.parse() dentro de un bloque seguro para alertar al usuario si la sintaxis del archivo está corrompida.

Nivel 2 — Semi Senior

Reto 2: Zona Drag & Drop con Discriminación de Tipo MIME

▼

Enunciado: Construye una zona de arrastre que examine archivo.type: si es una imagen, léela con readAsDataURL() e insértala en una galería; si es texto o código, léela con readAsText() y muéstrala en un bloque <pre>.

Nivel 3 — Producción

Reto 3: Lector Pesado con Barra de Progreso y Cancelación (abort)

▼

Enunciado: Implementa una clase FileUploaderManager que gestione la lectura de archivos con cálculo porcentual en el evento progress y permita al usuario abortar la operación en cualquier momento llamando a reader.abort().
