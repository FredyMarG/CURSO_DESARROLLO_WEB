Fundamento 01

Introducción al Objeto window.history, back() y forward()

El objeto global history permite interactuar directamente con la pila de navegación de la sesión activa:

La Pila de Navegación (Stack)

La Memoria de la Pestaña: Cada pestaña del navegador mantiene una pila ordenada con las páginas visitadas durante esa sesión.

Navegación Unitaria: history.back() retrocede una entrada (flecha Atrás). history.forward() avanza una entrada (flecha Adelante). Si no hay páginas en esa dirección, la instrucción se ignora silenciosamente sin arrojar error.

💡 Simulación en Vivo: Usa los botones de navegación del simulador inferior para interactuar con la pila virtual.

Navegación Tradicional

  • Enlaces <a href="..."> convencionales.
  • Provoca recarga completa (Full Page Reload).
  • Destruye el estado en memoria de JavaScript.

History API en SPAs

  • Modifica la URL sin recargar la página.
  • Conserva variables, estados y componentes en RAM.
  • Control bidireccional con eventos de navegación.
navegacion_basica_history.js 
"use strict";
// Retrocede una página en la pila:
history.back();

// Avanza una página en la pila:
history.forward();

// Inspecciona el total de entradas:
console.log("Entradas en historial:", history.length);

Fundamento 02

Inspección de Pila con history.length y Saltos con history.go()

Aprende a consultar la profundidad del historial y realizar saltos relativos de varias páginas:

Métrica de Pila

history.length

Profundidad total de la sesión activa
  • Propiedad de solo lectura: Indica cuántas páginas hay en la sesión actual.
  • Inicia en 1 o 2: Al abrir una pestaña nueva y entrar al primer sitio.
  • Privacidad estricta: Por seguridad, JavaScript no puede leer las URLs de las otras páginas del historial.
🛡️
Aislamiento de Privacidad: Solo conoces el conteo de páginas, nunca los dominios visitados por el usuario.
Salto

Delta Relativo
Navegación Relativa

history.go(delta)

Saltos hacia adelante, atrás o recarga
  • go(-1): Equivalente exacto a history.back().
  • go(1): Equivalente exacto a history.forward().
  • go(-2) o go(3): Salta dos páginas atrás o tres adelante.
  • go(0) o go(): Recarga la página actual (location.reload()).
⚡
Fuera de Límites: Si pasas go(-99) y no hay tantas páginas, se ignora silenciosamente.
history.go(-2) ➔ Salta 2 páginas atrás | history.go(0) ➔ Recarga la página

Invocación Delta Equivalente Estándar Efecto en la Pila
history.go(-1) -1 history.back() Retrocede a la entrada inmediatamente anterior.
history.go(1) +1 history.forward() Avanza a la entrada inmediatamente siguiente.
history.go(-2) -2 Pulsar "Atrás" dos veces seguidas Salta 2 páginas atrás en una sola operación.
history.go(0) 0 location.reload() Recarga el documento actual conservando la posición.

Ciclo Reactivo

El Objeto history.state y el Evento Global popstate

Aprende cómo viajar en el tiempo recuperando la información guardada en cada entrada del historial:

5.1 La propiedad history.state

Acceso directo al estado serializado de la página actual

Devuelve el objeto serializable asociado con la entrada sobre la que está situado el navegador. Si el usuario entró directamente a la URL o no se asoció estado, devuelve null.

5.2 El evento window.onpopstate

Se dispara únicamente cuando el usuario navega en la pila

Se gatilla en window al presionar los botones Atrás / Adelante del navegador o ejecutar history.back(), forward() o go(). Expone event.state con los datos clonados.

5.3 La Regla de Oro: pushState NO activa popstate

El error número 1 de los desarrolladores en enrutamiento

Invocar pushState() o replaceState() jamás dispara el evento popstate. Por tanto, tu aplicación debe actualizar la vista de forma inmediata en el mismo manejador que llama a pushState().

Estándares de la Industria

Buenas Prácticas y Errores Comunes con la History API

Evita los errores típicos de seguridad y recargas accidentales al construir enrutadores Frontend:

❌ ERROR: CROSS-ORIGIN

Intentar Cambiar de Dominio

Pasar una URL con protocolo o dominio distinto a pushState() lanza un error de seguridad fatal (SecurityError: Blocked cross-origin navigation).

history.pushState({}, "", "https://google.com"); // ❌ SecurityError
❌ ERROR: 404 EN RECARGA

Servidor sin Fallback SPA

Si el usuario recarga la página en /usuario/perfil, el servidor web debe servir siempre el archivo index.html para que la SPA tome el control.

GET /usuario/perfil ➔ 404 Not Found // ❌ Falta fallback
✅ BUENA PRÁCTICA: MANEJAR NULL

Validar event.state === null

En la visita inicial, history.state es null. Prevé siempre una vista por defecto leyendo location.pathname.

const vista = event.state ? event.state.seccion : "inicio"; // ✅
✅ BUENA PRÁCTICA: REPLACESTATE

Filtros y Búsquedas sin Inflar Pila

Usa replaceState() para paginaciones o filtros de búsqueda para no obligar al usuario a pulsar "Atrás" diez veces consecutivas.

history.replaceState({ cat }, "", \`?cat=\${cat}\`); // ✅

Proyecto Integrador: Enrutador SPA con Historial y popstate

Navegación dinámica entre pestañas actualizando la URL visible y restaurando vistas sin recargas:

1. Enrutador SPA Nativo

Interceptamos los clics de la barra de navegación, ejecutamos pushState y escuchamos popstate: 

const navegar = (ruta, datos) => {
  history.pushState(datos, "", ruta);
  renderizarVista(datos.seccion);
};

window.addEventListener("popstate", (e) => {
  const seccion = e.state ? e.state.seccion : "inicio";
  renderizarVista(seccion);
});

Cheat Sheet & Solucionario

Resumen Maestro y Retos Prácticos Paso a Paso

Consolida tu dominio de la History API con estos 3 retos progresivos:

Nivel 1 — Junior

Navegación Relativa con go()

Escribe una función que verifique si history.length > 2. Si es verdadero, debe retroceder 2 páginas de golpe con history.go(); si no, debe usar history.back(). 

const retrocederSeguro = () => {
    if (history.length > 2) {
        history.go(-2);
    } else {
        history.back();
    }
};
Nivel 2 — Semi Senior

Filtro sin Inflar Pila con replaceState

Crea una función actualizarFiltro(categoria, pagina) que guarde ambos valores en el objeto de estado y actualice la URL visible con replaceState() sin aumentar history.length. 

const actualizarFiltro = (categoria, pagina) => {
    const estado = { categoria, pagina };
    history.replaceState(estado, "", `?cat=${categoria}&p=${pagina}`);
    console.log("Filtro actualizado:", history.state);
};
Nivel 3 — Producción

Enrutador con pushState y popstate

Implementa la función navegarA(ruta, seccion) que agregue una entrada con pushState y registre el listener de popstate para sincronizar la interfaz ante las flechas del navegador. 

const navegarA = (ruta, seccion) => {
    history.pushState({ seccion }, "", ruta);
    renderizar(seccion);
};

window.addEventListener("popstate", (e) => {
    const sec = e.state ? e.state.seccion : "inicio";
    renderizar(sec);
});
