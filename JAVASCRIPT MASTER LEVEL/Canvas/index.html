DIAPOSITIVA 2 · FUNDAMENTOS

¿Qué es <canvas> y su Contexto 2D?

Lienzo de mapa de bits

  • <canvas> es un contenedor gráfico controlado 100% mediante JavaScript.
  • A diferencia de SVG (nodos DOM vectoriales), Canvas pinta píxeles directamente: una vez dibujado, el navegador no recuerda objetos individuales.
  • El origen (0, 0) está en la esquina superior izquierda; x crece a la derecha e y hacia abajo.

Inicialización básica

<canvas id="miLienzo" width="600" height="300"></canvas>

<script>
  const canvas = document.getElementById("miLienzo");
  const ctx = canvas.getContext("2d");
</script>
DIAPOSITIVA 3 · PRIMITIVAS DIRECTAS

Rectángulos y Propiedades de Estilo

Métodos de rectángulo

  • fillRect(x, y, w, h): dibuja un rectángulo relleno al instante.
  • strokeRect(x, y, w, h): dibuja solo el contorno del rectángulo.
  • clearRect(x, y, w, h): borra píxeles dejándolos transparentes.

Configurar estilo antes de dibujar

ctx.fillStyle = "#00f0ff";
ctx.fillRect(20, 20, 140, 80);

ctx.strokeStyle = "#a855f7";
ctx.lineWidth = 4;
ctx.strokeRect(180, 20, 140, 80);
DIAPOSITIVA 4 · PATHS Y ARCOS

Rutas Personalizadas: Triángulos, Líneas y Círculos

Flujo de un trazado

  • ctx.beginPath(): reinicia la lista de trazos para no mezclar figuras anteriores.
  • ctx.moveTo(x, y): mueve el lápiz sin pintar.
  • ctx.lineTo(x, y): traza una línea recta hasta el nuevo punto.
  • ctx.closePath(): conecta el último punto con el inicial.
  • ctx.stroke() o ctx.fill(): renderiza la ruta en pantalla.

Triángulo + Círculo con arc()

// Triángulo
ctx.beginPath();
ctx.moveTo(100, 30);
ctx.lineTo(170, 140);
ctx.lineTo(30, 140);
ctx.closePath();
ctx.fillStyle = "#10b981";
ctx.fill();

// Círculo completo (2 * Math.PI)
ctx.beginPath();
ctx.arc(280, 90, 45, 0, Math.PI * 2);
ctx.strokeStyle = "#f59e0b";
ctx.stroke();

DIAPOSITIVA 6 · CALIDAD PROFESIONAL

Errores Comunes y Pantallas Retina (HiDPI)

Errores frecuentes

  • Olvidar beginPath(): provoca que las rutas anteriores se vuelvan a pintar con el nuevo color.
  • Escalar con CSS sin atributos HTML: si cambias width solo en CSS, el lienzo se pixela o estira; usa atributos canvas.width y canvas.height.
  • Cambiar fillStyle después de dibujar: el estilo debe asignarse siempre antes del trazo.

Nitidez en pantallas Retina (devicePixelRatio)

const dpr = window.devicePixelRatio || 1;
const rect = canvas.getBoundingClientRect();
canvas.width = rect.width * dpr;
canvas.height = rect.height * dpr;
ctx.scale(dpr, dpr);
DIAPOSITIVA 7 · BUCLE DE JUEGO

Animación Fluida con requestAnimationFrame

Ciclo de cada fotograma

  • 1. Limpiar: ctx.clearRect(0, 0, canvas.width, canvas.height).
  • 2. Actualizar estado: mover coordenadas x += vx, detectar colisiones.
  • 3. Dibujar: renderizar las figuras en su nueva posición.
  • 4. Repetir: programar el siguiente cuadro con requestAnimationFrame(loop).

Bucle clásico

let x = 30;
function animar() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.beginPath();
  ctx.arc(x, 120, 20, 0, Math.PI * 2);
  ctx.fill();
  x = (x + 3) % canvas.width;
  requestAnimationFrame(animar);
}
requestAnimationFrame(animar);
