Fundamento 01

¿Qué es el Objeto Date y cómo se instancia?

El objeto nativo Date almacena internamente los milisegundos transcurridos desde el 1 de enero de 1970 a las 00:00:00 UTC (conocido como Unix Epoch):

Instanciación Obligatoria

No es un primitivo: Para utilizar Date y acceder a sus métodos de extracción (getters), es obligatorio instanciarlo usando el operador new Date().

Marca Temporal: Al ejecutar new Date() sin argumentos, JavaScript captura el milisegundo exacto del reloj del sistema en ese preciso instante.

💡 Cuidado: Si olvidas la palabra new y escribes solo Date(), obtendrás un simple string de texto sin acceso a .getDate() ni .getFullYear().

Sin 'new' ➔ Date()

  • Devuelve una cadena de texto estática (string).
  • Ignora cualquier argumento que le pases.
  • No posee métodos (getDate es undefined).

Con 'new' ➔ new Date()

  • Crea una instancia real de objeto (object).
  • Almacena el timestamp numérico desde 1970.
  • Habilita todos los métodos getters de lectura.
extraccion_practica_date.js 
const fechaActual = new Date();

const diaMes = fechaActual.getDate();
const mes = fechaActual.getMonth() + 1; // Enero es 0
const anio = fechaActual.getFullYear();

console.log(`Fecha: \${diaMes}/\${mes}/\${anio}`);

Calidad de Software

Buenas Prácticas y Errores Comunes con el Objeto Date

Domina las 4 reglas esenciales para evitar errores de calendario en entrevistas técnicas y proyectos de producción:

❌ ERROR #1 EN ENTREVISTAS

Confundir getDate() con getDay()

getDate() devuelve el día del mes (1-31), mientras que getDay() devuelve el día de la semana (0-6). Además, getDays() con "s" no existe y lanza TypeError.

hoy.getDay(); // ❌ Da 0-6 (no el día del mes)
❌ ERROR DE DESFASE: MES 0

Olvidar que getMonth() inicia en 0

En JavaScript los meses van del 0 (Enero) al 11 (Diciembre). Mostrar getMonth() directamente en una fecha numérica mostrará diciembre como mes 11.

new Date(2026, 11, 25).getMonth(); // ⚠️ Da 11
✅ BUENA PRÁCTICA: 4 DÍGITOS

Usar siempre getFullYear()

Nunca uses el obsoleto getYear() (que resta 1900 y devuelve 126 para 2026). Usa siempre getFullYear() para obtener 2026.

const anio = hoy.getFullYear(); // ✅ 2026
✅ BUENA PRÁCTICA: FORMATEO

Usar padStart(2, "0") y Arreglos

Aplica String(min).padStart(2, "0") para relojes digitales uniformes (08:05:09) y arreglos con Domingo en posición 0 para nombres de días.

String(hoy.getMinutes()).padStart(2, "0"); // ✅

Nivel 1 — Junior

Fecha en Formato "DD/MM/YYYY"

Crea una instancia de la fecha actual en una constante hoy. Extrae el día del mes, el mes (ajustado del 1 al 12) y el año completo de 4 dígitos, e imprime una cadena con el formato "DD/MM/YYYY". 

const hoy = new Date();

const dia = hoy.getDate();
const mes = hoy.getMonth() + 1; // Sumamos 1 porque enero es 0
const anio = hoy.getFullYear(); // Evitamos getYear() para obtener 4 dígitos

const fechaFormateada = `${dia}/${mes}/${anio}`;
console.log(fechaFormateada);
Nivel 2 — Semi Senior

Función obtenerNombreDia(fecha)

Escribe una función obtenerNombreDia que reciba un objeto Date. Usando getDay() y un arreglo con los días de la semana, retorna el nombre del día en español (0 es "Domingo"). 

function obtenerNombreDia(fecha) {
    const diasSemana = [
        "Domingo", "Lunes", "Martes", "Miércoles",
        "Jueves", "Viernes", "Sábado"
    ];
    const indiceDia = fecha.getDay();
    return diasSemana[indiceDia];
}

console.log("Hoy es:", obtenerNombreDia(new Date()));
