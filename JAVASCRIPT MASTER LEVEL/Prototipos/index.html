Fundamento 01

¿Qué es realmente un Prototipo?

A diferencia de Java o C# donde una clase es un plano intangible, en JavaScript los objetos se vinculan directamente con otros objetos vivos.

Definición Formal

Un prototipo es un mecanismo mediante el cual los objetos en JavaScript heredan características entre sí. Cada objeto tiene un enlace interno oculto (referenciado como [[Prototype]]) que apunta a otro objeto.

💡 Delegación, no copia: Cuando pides una propiedad, tu objeto no la tiene clonada; le pide el favor a su prototipo de prestarle el valor o ejecutar su método.

Clases Tradicionales (Java/C++)

  • Las clases son moldes estáticos en papel.
  • Al instanciar, se copian todas las funciones.
  • No puedes modificar la estructura en caliente.

Prototipos de JavaScript

  • Los prototipos son objetos reales en RAM.
  • No se copian métodos; existe delegación viva.
  • Son mutables en cualquier instante de ejecución.
prototipo_basico.js 
// Creamos un objeto simple
const usuario = {
    nombre: "Carlos"
};

// ¿De dónde sale .toString() si nunca lo escribimos?
console.log(usuario.toString()); 
// Resultado: "[object Object]"

// Inspeccionamos su prototipo con el estándar moderno:
const proto = Object.getPrototypeOf(usuario);
console.log(proto === Object.prototype); // true!

Anatomía Profunda

Las 6 Características Fundamentales de los Prototipos

Los prototipos no son planos rígidos. Son entidades dinámicas y vivas con estas 6 propiedades:

4.1 Mutabilidad en Tiempo de Ejecución

Se puede alterar el prototipo y todos los hijos se actualizan al instante

Si agregas o modificas un método en el prototipo después de haber creado miles de objetos, ¡todos los objetos ya existentes adquieren la nueva habilidad automáticamente! No tienen copias, tienen un enlace vivo.

Instancia: bot1 = new Robot("R2-D2")
Estado actual de bot1: Aún no tiene el método .saludar(). ¡Presiona el botón para inyectarlo en caliente!
4.2 Es en sí mismo un objeto, así como otros

No es una abstracción mística: es un objeto ordinario

El prototipo responde a typeof === 'object', tiene llaves, valores y su propio prototipo (que por defecto es Object.prototype). Puedes usar Object.keys() o inspeccionarlo libremente.

4.3 Tiene una existencia física en la memoria (Heap RAM)

Ahorro masivo de recursos en aplicaciones de alto rendimiento

En Java o C++, los planos no son instancias. En JS, el Prototype Object ocupa una dirección real en el Heap desde el primer milisegundo. Si creas 10,000 enemigos en un videojuego, el método atacar() solo consume memoria una sola vez.

2,500 instancias
Sin Prototipos (Método clonado en cada instancia):
~2,500 funciones duplicadas en RAM
Con Prototipo (Compartido por referencia viva):
¡Solo 1 función única en toda la RAM! (99.9% de ahorro)
4.4 Puede ser modificado y llamado directamente

Puedes invocar métodos del prototipo sin instanciar ningún hijo

Al ser un objeto existente, puedes llamar PrototipoCalculadora.sumar(5, 3) directamente o editar sus propiedades con delete en caliente.

Código Profesional

Buenas Prácticas vs Errores Peligrosos

Dominar prototipos te hace inmune a los errores más difíciles de depurar en producción.

✅ BUENA PRÁCTICA

Usa Object.getPrototypeOf() y Object.create()

Evita __proto__ en producción. Object.getPrototypeOf() y Object.create() están altamente optimizados por el motor V8.

const hijo = Object.create(padre);
❌ ERROR GRAVE

Monkey Patching en Prototipos Globales

Jamás modifiques Array.prototype o Object.prototype. Provoca colisiones y rompe librerías externas.

// ❌ NUNCA HAGAS ESTO:
Array.prototype.miMetodo = fn;
✅ BUENA PRÁCTICA

Filtra con Object.hasOwn() en bucles

Los bucles for...in leen también propiedades heredadas del prototipo. Filtra siempre con Object.hasOwn(obj, key).

if (Object.hasOwn(auto, prop)) { ... }
❌ ERROR FRECUENTE

Arrays Mutables en el Prototipo

Si colocas un Array en el prototipo, ¡todas las instancias compartirán la misma lista en RAM!

Ejercicios & Retos de Evaluación

Pon a prueba tu comprensión de la herencia prototípica resolviendo estos 3 retos graduales.

Nivel 1 — Junior

El Vehículo Base con Object.create()

Crea un prototipo vehiculoPrototipo con propiedad ruedas: 4 y método arrancar(). Instancia miCoche con Object.create, asígnale marca y comprueba que hereda ruedas. 

const vehiculoPrototipo = {
    ruedas: 4,
    arrancar() { return `El vehículo de ${this.ruedas} ruedas ha arrancado.`; }
};

const miCoche = Object.create(vehiculoPrototipo);
miCoche.marca = "Tesla";

console.log(miCoche.marca);    // "Tesla" (Propiedad propia)
console.log(miCoche.ruedas);   // 4 (Heredada del prototipo)
console.log(miCoche.arrancar());
Nivel 2 — Semi Senior

Mutabilidad Compartida en Personajes

Declara function Personaje(nombre, vida) e instancia guerrero y mago. Posteriormente inyecta en caliente Personaje.prototype.curar y verifica que ambos comparten exactamente la misma función en memoria (===). 

function Personaje(nombre, vida) {
    this.nombre = nombre;
    this.vida = vida;
}

const guerrero = new Personaje("Thor", 100);
const mago = new Personaje("Gandalf", 80);

// Mutación en caliente del prototipo
Personaje.prototype.curar = function(pts) {
    this.vida += pts;
    return `${this.nombre} curado. Vida: ${this.vida}`;
};

console.log(guerrero.curar(20)); // "Thor curado. Vida: 120"
console.log(guerrero.curar === mago.curar); // true (Misma dirección RAM!)
Nivel 3 — Master

Cadena de 3 Niveles con Object.hasOwn()

Crea la cadena Entidad (respirar) → Empleado (empresa: "TechCorp", trabajar) → Desarrollador (programar). Demuestra la invocación en los 3 eslabones y comprueba con Object.hasOwn() cuáles propiedades le pertenecen a la instancia. 

const Entidad = {
    respirar() { return "Respirando oxígeno..."; }
};

const Empleado = Object.create(Entidad);
Empleado.empresa = "TechCorp";
Empleado.trabajar = function() { return `Trabajando en ${this.empresa}`; };

const dev = Object.create(Empleado);
dev.nombre = "Sofia";
dev.lenguaje = "JavaScript";
dev.programar = function() { return `${this.nombre} programa en ${this.lenguaje}`; };

// Invocación a través de los 3 niveles
console.log(dev.programar()); // Nivel 1 (Propio)
console.log(dev.trabajar());  // Nivel 2 (Empleado)
console.log(dev.respirar());  // Nivel 3 (Entidad)

// Comprobación de pertenencia directa
console.log(Object.hasOwn(dev, "nombre"));   // true
console.log(Object.hasOwn(dev, "empresa"));  // false (Heredada!)
Cheat Sheet & Conclusión

Resumen Maestro de Prototipos

Los 5 mandamientos de la orientación a objetos en JavaScript para recordar siempre:

1️⃣

Todo es Delegación

Los objetos no copian propiedades; las buscan en su enlace oculto [[Prototype]].

2️⃣

La Cadena Termina en null

El orden es: Objeto Propio → Constructor.prototype → Object.prototype → null.

3️⃣

Ahorro de Memoria Vital

Colocar métodos en el prototipo los mantiene como una sola referencia física compartida en RAM.

4️⃣

Mutabilidad Viva

Modificar el prototipo altera en caliente el comportamiento de todas las instancias pasadas y futuras.

5️⃣

Estándares Modernos

Usa Object.create(), Object.getPrototypeOf() y Object.hasOwn().
