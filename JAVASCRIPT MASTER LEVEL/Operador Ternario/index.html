Fundamento 01

¿Qué es el Operador Ternario? Expresión vs. Declaración

A diferencia de la instrucción if...else tradicional (que es una declaración), el operador ternario es una expresión evaluable que devuelve un valor inmediato:

Diferencia Fundamental

Declaración (Statement): Ejecuta una acción de control de flujo pero no produce un valor por sí misma. No puedes hacer: const x = if(cond) { 1 }; (SyntaxError).

Expresión (Expression): Se reduce a un valor concreto. Por ello, puedes asignarlo a una constante, pasarlo a funciones o meterlo en plantillas de texto.

💡 El Único Ternario: Recibe 3 operandos separados por los símbolos ? (interrogación) y : (dos puntos).

Declaración (if...else)

  • No devuelve ningún valor de retorno directo.
  • Requiere múltiples líneas y llaves {}.
  • Exige declarar variables con let mutable.

Expresión Ternaria (? :)

  • Devuelve el valor evaluado inmediatamente.
  • Sintaxis compacta en una sola línea.
  • Permite declarar variables con const inmutable.
expresion_vs_declaracion.js 
const edad = 20;

// El ternario produce el valor "Adulto" y lo asigna a 'estado':
const estado = edad >= 18 ? "Adulto" : "Menor de edad";

console.log("Resultado evaluado:", estado);

Fundamento 02

Anatomía de los 3 Operandos y Evaluación Truthy / Falsy

Aprende la función exacta de cada una de las 3 partes y cómo JavaScript evalúa condiciones booleanas o implícitas:

Sintaxis

Desglose de Operandos

condicion ? exp1 : exp2
  • 1. Condición: La pregunta lógica a evaluar (truthy o falsy).
  • 2. Signo '?': "¿Es verdadera la condición?".
  • 3. Expresión si es True: El valor que se devuelve si se cumple.
  • 4. Dos Puntos ':': "De lo contrario...".
  • 5. Expresión si es False: El valor que se devuelve si no se cumple.
🔍
Evaluación Cortocircuitada: Solo se evalúa una de las dos expresiones (la que coincida con el resultado de la condición).

Coerción Booleana

Valores Falsy en JS

false, 0, "", null, undefined, NaN

Cualquier valor distinto de los 6 Falsy históricos se evalúa automáticamente como true (Truthy), incluyendo cadenas con texto, números distintos de cero, arrays [] y objetos {}.

💡
Ejemplo práctico: nombre ? nombre : "Invitado" usa coerción natural de strings.
const resultado = valor ? "Es Truthy ✅" : "Es Falsy ❌";

Diagrama de Flujo de Decisión y Precedencia de Operadores

Conoce el orden exacto en que JavaScript evalúa las condiciones y por qué los paréntesis son el mejor aliado de la legibilidad:

5.1 Bifurcación Binaria Directa

Solo un camino se ejecuta (Evaluación en Cortocircuito)

Si la condición es true, se ejecuta y devuelve la Expresión 1. La Expresión 2 ni siquiera se evalúa, evitando llamadas a funciones o cálculos innecesarios.

5.2 Precedencia Menor que Operadores Aritméticos

Las comparaciones se resuelven antes que el signo '?'

Los operadores aritméticos (+, -) y relacionales (>, <, ===) tienen mayor prioridad que ? :. Por lo tanto, precio - desc > 50 ? A : B calcula primero la resta y la comparación antes de elegir el camino.

Código Limpio

Buenas Prácticas y Errores Comunes de la Industria

El operador ternario es elegante, pero su mal uso puede degradar la calidad del código. Conoce las 4 reglas maestras:

❌ ANTIPATRÓN: TERNARIO ANIDADO

Ternarios Encadenados

Anidar múltiples ternarios (a ? b : c ? d : e) destruye la legibilidad. Para 3 o más casos, usa switch u Object Lookup.

const t = esEst ? 5 : esMayor ? 7 : 10; // ❌ Difícil
❌ ANTIPATRÓN: EFECTOS MÚLTIPLES

Múltiples Instrucciones con Comas

El ternario espera expresiones que devuelvan valores. No lo uses para ejecutar múltiples métodos con efectos secundarios separados por comas. Usa if...else.

auth ? (login(), load(), go()) : err(); // ❌
❌ REDUNDANCIA: ? TRUE : FALSE

Retorno Booleano Innecesario

Escribir edad >= 18 ? true : false es redundante porque la comparación ya produce un booleano por sí misma.

const ok = edad >= 18; // ✅ Limpio y directo
✅ BUENA PRÁCTICA: ASIGNACIÓN

Asignaciones Inmutables Cortas

Ideal cuando la decisión cabe en una sola línea y define un valor atómico (string, número, booleano, objeto).

const tema = oscuro ? "bg-dark" : "bg-light"; // ✅
Integración Moderna ES6+

Uso en Funciones Flecha y Plantillas Literales (Template Strings)

Dos de las integraciones más potentes del operador ternario en el desarrollo diario con JavaScript moderno:

1. En Retornos Implícitos de Funciones Flecha

Como el ternario es una expresión, encaja a la perfección con el retorno implícito de las funciones flecha: 

const evaluarNota = nota => 
    nota >= 90 ? "Sobresaliente" : "Estándar";

console.log(evaluarNota(95)); // Sobresaliente

Resumen Maestro y Retos de Evaluación

Pon a prueba tus conocimientos con los 3 retos del curso extraídos de la guía oficial:

Nivel 1 — Junior

Número Par o Impar

Escribe un operador ternario que evalúe si un número guardado en numero es par o impar, y asigne "Par" o "Impar" a una constante llamada resultado. 

const numero = 7;
// Si el resto de dividir por 2 es 0, es Par:
const resultado = numero % 2 === 0 ? "Par" : "Impar";

console.log(`El número ${numero} es:`, resultado);
Nivel 2 — Semi Senior

Optimización de Rol de Usuario

Optimiza un bloque tradicional if (rol === "admin") { acceso = true; } else { acceso = false; } utilizando un único operador ternario dinámico e inmutable. 

const rol = "admin";

// Con operador ternario inmutable:
const acceso = rol === "admin" ? true : false;

console.log("Acceso concedido:", acceso);
Nivel 3 — Avanzado

obtenerMensajeEnvio con Retorno Implícito

Crea una función flecha obtenerMensajeEnvio(totalCompra, esPremium) que use un ternario en su retorno implícito para devolver "Envío Gratis" si total >= 50 o es premium; de lo contrario "Costo de envío: $5". 

const obtenerMensajeEnvio = (totalCompra, esPremium) => 
    (totalCompra >= 50 || esPremium) ? "Envío Gratis" : "Costo de envío: $5";

console.log("Compra $30 no premium:", obtenerMensajeEnvio(30, false));
console.log("Compra $60 no premium:", obtenerMensajeEnvio(60, false));
console.log("Compra $20 con premium:", obtenerMensajeEnvio(20, true));
