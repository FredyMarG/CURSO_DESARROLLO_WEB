DIAPOSITIVA 2 · CONCEPTO FUNDAMENTAL

Eje Principal (Main Axis) y Eje Cruzado (Cross Axis)

Todo en Flexbox gira alrededor de dos ejes perpendiculares que se definen con flex-direction.

➡️ En flex-direction: row (por defecto)

  • Main Axis: horizontal (izquierda → derecha).
  • Cross Axis: vertical (arriba → abajo).
  • justify-content mueve elementos en horizontal.
  • align-items alinea elementos en vertical.

⬇️ En flex-direction: column

  • Main Axis: vertical (arriba → abajo).
  • Cross Axis: horizontal (izquierda → derecha).
  • justify-content ahora mueve en vertical.
  • align-items ahora alinea en horizontal.
🧠 Analogía mental: Piensa en un riel de tren (Main Axis). justify-content desliza los vagones a lo largo del riel, mientras que align-items los centra respecto al ancho de la vía (Cross Axis). Si giras la vía 90° (column), ambos controles giran con ella.
DIAPOSITIVA 3 · DISTRIBUCIÓN DEL ESPACIO

justify-content, align-items y gap

Aprende a centrar elementos y repartir el espacio sobrante limpiamente.

📏 Valores clave de justify-content

  • flex-start / flex-end: agrupa al inicio o final del eje.
  • center: centra todos los ítems en el eje principal.
  • space-between: pega extremos y reparte espacio en medio.
  • space-around / space-evenly: espacio uniforme alrededor o entre todos.

🎯 Centrado perfecto + gap

.contenedor {
  display: flex;
  justify-content: center; /* Eje principal */
  align-items: center;     /* Eje cruzado */
  gap: 16px;               /* Separación limpia */
}

Usa gap en lugar de márgenes manuales para evitar espacios sobrantes en los bordes.

⚠️ Error común: Aplicar align-items: center en un contenedor que no tiene altura suficiente (solo mide lo que miden sus hijos). Si no hay espacio vertical sobrante, ¡parecerá que no hace nada!
DIAPOSITIVA 4 · PROPIEDADES DE LOS HIJOS

flex-grow, flex-shrink y flex-basis

Mientras el padre define la dirección, los hijos deciden cómo repartirse el espacio disponible.

PropiedadPor defectoQué haceEjemplo típico
flex-grow0Factor de crecimiento si sobra espacioflex-grow: 1 (ocupa el resto)
flex-shrink1Factor de encogimiento si falta espacioflex-shrink: 0 (no se aplasta)
flex-basisautoTamaño base ideal antes de repartirflex-basis: 240px
💡 Regla de oro: Usa el shorthand flex: 1 (equivale a 1 1 0%) para columnas iguales, o flex: 1 1 250px junto con flex-wrap: wrap para crear grillas responsivas sin Media Queries.
DIAPOSITIVA 5 · CONTROL FINO

flex-wrap, order y align-self

Permite saltos de línea, reordenamiento visual y excepciones individuales.

↩️ flex-wrap: wrap

Por defecto los ítems intentan caber en una sola línea (nowrap). Con wrap bajan a la siguiente fila automáticamente.

🔢 order: N

Cambia el orden visual sin tocar el HTML (por defecto todos valen 0). Útil para móviles, pero cuida la accesibilidad del teclado.

🧍 align-self

Sobrescribe el align-items del padre para un solo hijo (ej. align-self: flex-end en un chatbox).

DIAPOSITIVA 6 · RECETAS DE PRODUCCIÓN

3 Patrones que Usarás Todos los Días

Combina margin-left: auto, flex: 1 y min-height: 100dvh.

🧭 Navbar con logo a la izquierda y botón a la derecha

.navbar { display: flex; align-items: center; gap: 16px; }
.navbar .cta { margin-left: auto; }

En Flexbox, margin: auto absorbe todo el espacio libre en esa dirección.

🦶 Sticky Footer (pie siempre abajo)

body { display: flex; flex-direction: column; min-height: 100dvh; }
main { flex: 1; } /* Empuja el footer al fondo */

Incluso si la página tiene poco contenido, el footer queda pegado abajo.

DOCUMENTACIÓN OFICIAL · FLEXBOX.md

1. Idea central de Flexbox

Conceptos clave

  • display: flex convierte el contenedor en un bloque flexible y a sus hijos directos en flex items.
  • display: inline-flex hace lo mismo, pero el contenedor se comporta externamente como un elemento en línea.
  • Controla una dimensión a la vez (fila o columna) con alineación precisa, crecimiento, encogimiento y reordenamiento visual sin modificar el HTML.

Ejemplo mínimo funcional

<div class="fila">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>

/* CSS */
.fila {
  display: flex;
  gap: 12px;
  align-items: center;
}

10. Profundización: flex Shorthand, Alineación y a11y

flex Shorthand (Valores Clave)

Atajo Equivale a Comportamiento
flex: 1flex: 1 1 0%Crece y encoge por igual ignorando el tamaño del contenido.
flex: autoflex: 1 1 autoCrece y encoge partiendo del tamaño intrínseco del contenido.
flex: noneflex: 0 0 autoNi crece ni encoge; mantiene su tamaño natural.
flex: 0 0 240px0 0 240pxColumna o sidebar fija de exactamente 240px.

align-items vs align-content

  • align-items: alinea los ítems dentro de cada línea en el eje cruzado. Funciona siempre (con 1 o más líneas).
  • align-content: distribuye el bloque completo de líneas en el eje cruzado. No tiene efecto si flex-wrap: nowrap o si solo hay una línea.

order y Accesibilidad (a11y)

  • Cambiar order (o usar row-reverse / column-reverse) solo altera el orden visual; el foco con Tab y los lectores de pantalla siguen el DOM HTML.
  • Regla: si el orden lógico importa para navegación o formularios, reordena el HTML en lugar de depender de order.

11. Errores Comunes en Flexbox

1. align-content sin flex-wrap: wrap

No hace absolutamente nada porque solo existe una única línea. Activa primero flex-wrap: wrap cuando necesites distribuir varias filas.

2. Olvidar min-width: 0

Por defecto los flex items tienen min-width: auto y se niegan a encogerse por debajo de un texto largo o una URL, rompiendo overflow: ellipsis.

3. Confundir flex: 1 con width: 100%

En una fila con varios ítems, flex: 1 reparte el espacio disponible equitativamente; width: 100% intenta acaparar todo el contenedor.

4. Márgenes con :last-child en vez de gap

Usa gap directamente en el contenedor: funciona de forma limpia en row, column y wrap sin dejar márgenes residuales.
