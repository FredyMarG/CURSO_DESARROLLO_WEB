Contenido Principal Fluido

El Holy Grail Layout resuelve el patrón clásico de 3 columnas: barra lateral izquierda fija (220px), contenido central elástico (1fr) y barra lateral derecha fija (220px), con cabecera arriba y pie abajo.

Redimensiona la ventana por debajo de 820px para comprobar cómo grid-template-areas reordena automáticamente las 5 regiones en una sola columna.

Header & FooterOcupan las 3 columnas completas.
Main (1fr)Crece o se encoge ocupando el espacio libre.
Mobile-ReadySe apila limpio con un solo media query.

Sidebar Derecha
