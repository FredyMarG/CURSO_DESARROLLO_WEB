DIAPOSITIVA 2 · TOKENS DE DISEÑO

Variables CSS (--nombre y var())

A diferencia de Sass, las variables nativas viven en tiempo de ejecución y pueden cambiar dinámicamente con media queries o JavaScript.

🌐 Definición global en :root

:root {
  --bg: #070a13;
  --accent: #38bdf8;
  --radius: 14px;
}
.boton {
  background: var(--accent, #0284c7);
  border-radius: var(--radius);
}

🌗 Cambio de tema instantáneo

body.light-theme {
  --bg: #f8fafc;
  --accent: #4f46e5;
}

El segundo parámetro de var(--accent, #0284c7) es un valor de respaldo (fallback) si la variable no existe.

DIAPOSITIVA 3 · MATEMÁTICAS EN CSS

calc(), min(), max() y clamp()

Combina unidades distintas (como 100% - 2rem) y establece límites seguros para que nada se rompa.

FunciónQué devuelveEjemplo práctico
calc(a + b)Suma/resta/multiplica unidades mixtaswidth: calc(100% - 240px);
min(a, b)El valor más pequeño (tope máximo)width: min(92%, 1100px);
max(a, b)El valor más grande (tope mínimo)padding: max(16px, 4vw);
clamp(min, ideal, max)Escala fluido entre un piso y un techofont-size: clamp(1.4rem, 3vw, 2.8rem);
💡 Tip profesional: En calc(100% - 20px), los espacios alrededor del + y - son obligatorios. Sin espacios, CSS lo interpreta como un número negativo inválido.
DIAPOSITIVA 4 · MÓVILES SIN BUGS

Unidades del Viewport: vh vs dvh, svh, lvh

En móviles, la barra de direcciones del navegador cambia de altura al hacer scroll. 100vh clásico suele cortar el contenido.

📱 100dvh (Dynamic)

Se recalcula dinámicamente según si la barra de direcciones está visible u oculta. Ideal para pantallas completas.

📐 100svh (Small)

La altura mínima garantizada (con barra visible). Evita saltos bruscos de layout al desplazarse.

🖥️ 100lvh (Large)

La altura máxima posible cuando la barra del navegador se oculta por completo.

DIAPOSITIVA 5 · EFECTOS MODERNOS

backdrop-filter, filter y clip-path

Consigue efectos de vidrio esmerilado (glassmorphism) y formas poligonales sin Photoshop.

🪟 Glassmorphism real

.panel-vidrio {
  background: rgba(15, 23, 42, 0.65);
  backdrop-filter: blur(14px) saturate(160%);
  border: 1px solid rgba(255, 255, 255, 0.14);
}

✂️ Recortes con clip-path

.diagonal {
  clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%);
}

También acepta circle(50%) y inset(10px round 12px).

DIAPOSITIVA 6 · COLORES Y GEOMETRÍA

color-mix(), transform y initial-letter

Mezcla colores nativamente en CSS y crea variaciones de hover sin declarar decenas de códigos HEX.

🧪 color-mix()

.btn:hover {
  background: color-mix(in srgb, var(--accent) 80%, white);
}

Aclara u oscurece cualquier color base automáticamente.

📰 initial-letter

p::first-letter {
  initial-letter: 3; /* Letra capital de 3 líneas */
  margin-right: 10px;
}

1. filter y backdrop-filter en CSS

Efectos visuales en GPU

  • filter aplica desenfoque, brillo, contraste o sombras sobre el elemento completo.
  • backdrop-filter aplica el efecto solo al fondo detrás de un contenedor translúcido (efecto cristal / glassmorphism).
  • drop-shadow() respeta la silueta transparente de PNG/SVG, a diferencia de box-shadow.

Ejemplo Glassmorphism

.tarjeta-cristal {
          background: rgba(15, 23, 42, 0.55);
          backdrop-filter: blur(14px) saturate(140%);
        }
        .icono-png {
          filter: drop-shadow(0 6px 12px rgba(0, 240, 255, 0.4));
        }

3. clip-path: Recorte Geométrico

Formas geométricas nativas

  • circle(50% at center): recorte circular perfecto.
  • ellipse(45% 30% at 50% 50%): elipse adaptable.
  • polygon(x1 y1, x2 y2, ...): triángulos, hexágonos o cortes diagonales.
  • inset(10px round 16px): recorte rectangular con esquinas redondeadas.

Ejemplo animable

.banner-diagonal {
          clip-path: polygon(0 0, 100% 0, 100% 82%, 0 100%);
        }
        .avatar-hex {
          clip-path: polygon(50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25%);
        }

4. Funciones Matemáticas y Custom Properties

Matemáticas fluidas

  • calc(100% - 2rem): mezcla unidades relativas y fijas (deja espacios alrededor de + y -).
  • clamp(1.2rem, 3vw, 2.5rem): tipografía fluida con límite mínimo y máximo sin media queries.
  • min() y max(): eligen el menor o mayor valor dinámicamente.

Variables CSS (var())

:root {
          --accent: #00f0ff;
          --space: clamp(1rem, 2vw, 2rem);
        }
        .panel {
          padding: var(--space);
          border: 1px solid var(--accent, #38bdf8);
        }
