DIAPOSITIVA 2 · COMPONENTES REUTILIZABLES

Componentes UI con CSS Puro

Antes de usar JavaScript, HTML5 y CSS3 permiten crear acordeones, tarjetas 3D, chats y menús laterales.

📂 Accordion Menu (2 Enfoques)

  • Nativo (<details> + <summary>): accesible por teclado sin una sola línea de JS.
  • Con input[type="checkbox"] + :checked: permite animar max-height o grid-template-rows.
Ver Summary/Details → Ver Divs + CSS →

🃏 Flipper Card 3D

  • Usa perspective: 1000px en el contenedor padre.
  • Aplica transform-style: preserve-3d y backface-visibility: hidden en ambas caras.
  • Al hacer :hover, rota rotateY(180deg) suavemente.
Abrir Flipper Card →

💬 Chatbox UI

  • Maquetación con Flexbox en columna (mensajes enviados vs recibidos con align-self).
  • Burbujas con border-radius asimétrico y scroll interno.
Abrir Chatbox →

📑 Sidebar Menu

  • Barra lateral fija o colapsable usando el truco del checkbox oculto (#menu:checked ~ .sidebar).
  • Transiciones suaves en width, transform y opacidad de etiquetas.
Abrir Sidebar Menu →
