DIAPOSITIVA 2 · CUÁNDO USAR CADA UNO

Grid (2D) vs Flexbox (1D)

No compiten entre sí: se complementan. Grid estructura la página; Flexbox alinea el contenido dentro de cada componente.

CaracterísticaFlexbox (1D)CSS Grid (2D)
DimensiónUna fila o una columna a la vezFilas y columnas al mismo tiempo
EnfoqueContenido hacia afuera (Content-first)Contenedor hacia adentro (Layout-first)
Caso idealNavbars, botones, grupos de iconos, chatLayouts completos, dashboards, galerías
🧠 Analogía mental: Grid es el plano arquitectónico de un edificio (define habitaciones en filas y columnas). Flexbox es cómo acomodas los muebles dentro de una habitación.
DIAPOSITIVA 3 · COLUMNAS INTELIGENTES

La magia de fr, repeat() y minmax()

Olvídate de calcular width: 33.33% menos el gap. La unidad fr (fracción) lo hace automáticamente.

📊 fr (Espacio disponible)

.layout {
  display: grid;
  grid-template-columns: 240px 1fr 2fr;
  gap: 16px;
}

La 1ª columna mide 240px fijos; del espacio sobrante, la 2ª toma 1 parte y la 3ª el doble.

📱 Grilla Responsiva en 1 línea

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

Crea tantas columnas de mínimo 220px como quepan, sin escribir una sola Media Query.

DIAPOSITIVA 4 · POSICIONAMIENTO 2D

grid-column, span y grid-template-areas

Haz que cualquier elemento ocupe múltiples celdas o dibuja tu interfaz con nombres legibles.

🗺️ grid-template-areas

.pagina {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "header header"
    "aside  main"
    "footer footer";
}
.header { grid-area: header; }

↔️ Expansión con span

.destacado {
  grid-column: span 2; /* Ocupa 2 columnas */
  grid-row: span 2;    /* Ocupa 2 filas */
}

Si agregas grid-auto-flow: dense; al padre, Grid rellena los huecos vacíos automáticamente.

DIAPOSITIVA 5 · ARQUITECTURA AVANZADA

Grid Explícito vs Implícito y Subgrid

¿Qué ocurre cuando llegan más elementos de los que definiste en tu plantilla?

🧱 Explícito vs Implícito

  • Explícito: las filas/columnas que defines con grid-template-columns / rows.
  • Implícito: las filas extra que Grid crea solo cuando hay más ítems. Contrólalas con grid-auto-rows: 160px;.

🧬 subgrid (CSS Moderno)

.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
}

Permite que los hijos internos de una tarjeta se alineen con las pistas del Grid padre.

DIAPOSITIVA 6 · ALINEACIÓN

place-items y place-content

Centra cualquier elemento dentro de su celda con una sola propiedad.

🎯 El truco del centrado en 2 líneas

.centro {
  display: grid;
  place-items: center; /* align-items + justify-items */
}

🔎 Diferencia clave

  • *-items: alinea el contenido dentro de cada celda.
  • *-content: mueve toda la cuadrícula completa cuando sobra espacio en el contenedor.
DOCUMENTACIÓN OFICIAL · GRID.md

1. ¿Qué es CSS Grid?

CSS Grid Layout es un sistema de diseño bidimensional para la web que permite trabajar con filas y columnas al mismo tiempo. Fue creado para resolver maquetaciones complejas que antes se hacían con floats, posicionamiento absoluto o hacks.

DOCUMENTACIÓN OFICIAL · GRID.md

2. Conceptos básicos: contenedor e ítems

2.1 Grid container

.container {
  display: grid;
}

2.2 Grid items

Los hijos directos se convierten en grid items y pueden posicionarse con grid-column, grid-row o grid-area.

DOCUMENTACIÓN OFICIAL · GRID.md

3. Creando una cuadrícula básica

.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  gap: 1rem;
}
DOCUMENTACIÓN OFICIAL · GRID.md

4. Unidades clave: auto y fr

auto

Se ajusta al contenido.

fr

Representa fracciones del espacio disponible.
