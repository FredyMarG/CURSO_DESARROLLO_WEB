DIAPOSITIVA 2 · EL ESQUELETO WEB

Estructura Base de un Documento HTML5

Todo archivo HTML moderno comienza con el mismo esqueleto estándar (puedes generarlo en VS Code escribiendo ! + Tab).

📄 Plantilla HTML5

<!doctype html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi Página</title>
</head>
<body>
  <h1>Hola Mundo</h1>
</body>
</html>

🔎 Qué hace cada parte

  • <!doctype html>: activa el modo estándar moderno del navegador.
  • <head>: metadatos invisibles (codificación UTF-8, título de pestaña, CSS).
  • <body>: todo el contenido visible para el usuario.
DIAPOSITIVA 3 · JERARQUÍA DE CONTENIDO

Encabezados (h1–h6), Párrafos y Listas

Usa los encabezados por su jerarquía semántica (como el índice de un libro), no solo por su tamaño visual.

📚 Jerarquía correcta

  • Un solo <h1> principal por página (título del documento).
  • <h2> para secciones principales y <h3> para subsecciones.
  • <strong> indica importancia; <em> indica énfasis.

📋 Listas ordenadas y desordenadas

<ul> <!-- Sin orden (viñetas) -->
  <li>HTML5</li>
  <li>CSS3</li>
</ul>
<ol> <!-- Pasos numerados -->
  <li>Estructurar</li>
  <li>Estilizar</li>
</ol>
DIAPOSITIVA 4 · NAVEGACIÓN Y MULTIMEDIA

Enlaces (<a>) e Imágenes (<img>)

Conecta páginas con hipervínculos y muestra imágenes accesibles con texto alternativo.

🔗 Rutas y seguridad en enlaces

<!-- Ruta relativa -->
<a href="contacto.html">Ir a Contacto</a>

<!-- Enlace externo seguro -->
<a href="https://mdn.io" target="_blank" rel="noopener noreferrer">MDN</a>

🖼️ Imágenes con alt

<img src="img/perfil.jpg" alt="Retrato de Ana sonriendo" loading="lazy">

El atributo alt describe la imagen para lectores de pantalla y se muestra si la imagen falla al cargar.

DIAPOSITIVA 5 · INTERACCIÓN CON EL USUARIO

Formularios: <form>, <label> e <input>

Captura datos del usuario usando los tipos nativos de HTML5 para obtener validación y teclados móviles adecuados.

📝 Asociar label con input

<form>
  <label for="correo">Email:</label>
  <input id="correo" type="email" required placeholder="tu@email.com">
  <button type="submit">Enviar</button>
</form>

⌨️ Tipos útiles de input

  • type="email": valida formato de correo.
  • type="password": oculta los caracteres.
  • type="number", type="date", type="checkbox".
DIAPOSITIVA 6 · CALIDAD DE CÓDIGO

Errores Comunes que Debes Evitar

Escribir HTML limpio desde el inicio te ahorra horas de depuración en CSS y JavaScript.

⚠️ 3 errores clásicos:
1. Usar <br> repetidos para crear espacios (eso se hace con margin o padding en CSS).
2. Saltar de <h1> directo a <h4> solo porque "se veía muy grande".
3. Olvidar el atributo alt en imágenes o el for en etiquetas <label>.
🧠 Analogía mental: HTML es la estructura y las instalaciones de una casa (paredes, puertas, ventanas). CSS es la pintura y decoración. JavaScript es la electricidad y automatización.
DOCUMENTACIÓN OFICIAL · HTML.md

1. Estructura Raíz: <!DOCTYPE>, <html> y <head>

Elementos esenciales

  • <!DOCTYPE html> activa el modo estándar moderno en todos los navegadores.
  • <html lang="es"> define el idioma raíz para SEO y lectores de pantalla.
  • <head> contiene metadatos invisibles (charset, viewport, título y CSS).

Esqueleto mínimo válido

<!doctype html>
        <html lang="es">
          <head>
            <meta charset="UTF-8" />
            <meta name="viewport" content="width=device-width, initial-scale=1.0" />
            <title>Mi Página</title>
          </head>
          <body>...</body>
        </html>
DOCUMENTACIÓN OFICIAL · HTML.md

2. Metadatos del Documento (<meta>, <link>, <base>)

EtiquetaPropósito principalEjemplo clave
<meta charset="UTF-8">Soporta tildes, ñ y emojis sin errores de codificación.<meta charset="UTF-8">
<meta name="viewport">Ajusta el ancho al dispositivo móvil (clave para Responsive).content="width=device-width, initial-scale=1.0"
<link>Conecta hojas de estilos CSS, favicons o fuentes externas.<link rel="stylesheet" href="style.css">
<base>Define la URL base para enlaces relativos del documento.<base href="https://miweb.com/">
DOCUMENTACIÓN OFICIAL · HTML.md

3. Seccionamiento Semántico (<header>, <main>, <section>)

Bloques estructurales

  • <header>: cabecera introductoria o barra superior.
  • <nav>: bloque principal de enlaces de navegación.
  • <main>: contenido principal único del documento.
  • <section> y <article>: secciones temáticas y contenido independiente.
  • <aside> y <footer>: barra lateral y pie de página.

Jerarquía limpia

<body>
          <header><nav>...</nav></header>
          <main>
            <section>
              <article>Contenido</article>
            </section>
          </main>
          <footer>© 2026</footer>
        </body>
DOCUMENTACIÓN OFICIAL · HTML.md

4. Texto, Listas y Agrupación Semántica

Etiquetas de contenido

  • <h1> a <h6>: jerarquía de encabezados (un solo <h1> principal por vista).
  • <p>, <strong> y <em>: párrafos y énfasis semántico real.
  • <ul> / <ol> / <li>: listas desordenadas y ordenadas.
  • <figure> + <figcaption>: imagen o gráfico con pie descriptivo.

Contacto y código

  • <address>: información de contacto del autor o empresa.
  • <pre> + <code>: bloques de código conservando saltos de línea y espacios.
  • Regla de oro: usa <div> solo cuando no exista una etiqueta semántica adecuada.
