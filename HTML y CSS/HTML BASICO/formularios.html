DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Formularios HTML y para qué sirve?

🎯 Propósito en proyectos reales

Recoge datos de usuarios de forma accesible, usa los tipos nativos de <input> para mostrar el teclado correcto en móviles y valida sin escribir JavaScript. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · ESTRUCTURA BASE

Anatomía de <form>, <label> e <input>

Cada campo necesita un <label> accesible y un atributo name para identificar el dato al enviarse.

📝 Formulario limpio

<form action="/registro" method="POST">
  <label for="usuario">Usuario:</label>
  <input id="usuario" name="usuario" type="text" required>
  <button type="submit">Crear cuenta</button>
</form>

🔎 Atributos clave

  • for + id: al hacer clic en la etiqueta, enfoca el campo.
  • name: clave con la que viaja el valor al servidor.
  • placeholder: pista visual (no reemplaza al <label>).
DIAPOSITIVA 3 · VALIDACIÓN SIN JAVASCRIPT

Tipos de <input> y Reglas HTML5

El navegador valida formatos y longitudes antes de permitir el envío del formulario.

Tipo / AtributoQué hace
type="email"Exige formato válido con @ y dominio
type="password"Oculta caracteres sensibles
type="checkbox" / radioSelección múltiple o única
required / minlength="6"Impide enviar vacío o con menos de 6 caracteres
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Formularios HTML

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
