DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Enlaces (&lt;a&gt;) y para qué sirve?

🎯 Propósito en proyectos reales

Conecta páginas internas, sitios externos seguros, secciones dentro de un mismo documento, descargas, correos y llamadas telefónicas. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · EL ATRIBUTO HREF

Anatomía de <a> y Tipos de Rutas

La etiqueta <a> (Anchor) requiere el atributo obligatorio href para funcionar como enlace navegable.

Tipo de enlaceEjemploPara qué sirve
Absolutahref="https://www.google.com"Ir a otro sitio web externo
Relativahref="listas.html" / ../index.htmlNavegar entre páginas de tu proyecto
Ancla internahref="#contacto"Saltar a una sección con id="contacto"
Acciones especialesmailto:hola@web.com / tel:+57...Abrir cliente de correo o marcar teléfono
DIAPOSITIVA 3 · SEGURIDAD Y BUENAS PRÁCTICAS

Abrir en Nueva Pestaña de Forma Segura

Al abrir un sitio externo en otra pestaña, protege el rendimiento y la seguridad de tu página.

🔐 Enlace externo seguro

<a href="https://www.google.com"
   target="_blank"
   rel="noopener noreferrer">
  Ir a Google
</a>

📥 Descargas directas

<a href="guia.pdf" download="Guia-HTML5.pdf">
  Descargar Guía PDF
</a>

El atributo download indica al navegador que descargue el archivo en lugar de abrirlo.

💡 ¿Por qué rel="noopener noreferrer"? Evita que la pestaña externa pueda manipular tu página original vía window.opener y mejora el aislamiento de procesos del navegador.
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Enlaces (&lt;a&gt;)

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
