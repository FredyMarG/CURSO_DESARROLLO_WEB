DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Imágenes (&lt;img&gt;) y para qué sirve?

🎯 Propósito en proyectos reales

Inserta gráficos accesibles y optimizados usando texto alternativo alt, dimensiones explícitas para evitar saltos de diseño y carga diferida. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · SINTAXIS Y ACCESIBILIDAD

La Etiqueta <img> (Sin Cierre)

<img> es un elemento vacío (no lleva </img>) y requiere dos atributos fundamentales: src y alt.

📝 Ejemplo correcto

<img
  src="img/paisaje.webp"
  alt="Montañas nevadas al amanecer"
  width="600"
  height="400"
  loading="lazy">

🔎 Qué aporta cada atributo

  • src: ruta relativa o URL de la imagen.
  • alt: texto leído por lectores de pantalla y mostrado si falla la carga.
  • width / height: reserva el espacio antes de descargarla.
DIAPOSITIVA 3 · SEMÁNTICA Y FORMATOS WEB

<figure> y Formatos Modernos (WebP / SVG)

Agrupa una imagen con su pie de foto usando <figure> y elige el formato más ligero.

🖼️ Pie de foto semántico

<figure>
  <img src="diagrama.svg" alt="Arquitectura Web">
  <figcaption>Fig 1. Flujo Cliente-Servidor</figcaption>
</figure>

📦 ¿Qué formato elegir?

  • WebP / AVIF: fotos con máxima compresión y calidad.
  • SVG: logotipos e iconos vectoriales (nítidos a cualquier zoom).
  • PNG: gráficos con transparencia cuando no se usa WebP.
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Imágenes (&lt;img&gt;)

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
