DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Listas en HTML y para qué sirve?

🎯 Propósito en proyectos reales

Organiza pasos secuenciales, colecciones de elementos, menús de navegación y glosarios con la estructura semántica correcta. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · ORDEN SECUENCIAL

Listas Ordenadas: <ol> + <li>

Se utilizan cuando el orden de los elementos es importante (pasos de una receta, instrucciones o un ranking). El navegador añade la numeración automáticamente.

📝 Ejemplo base

<ol>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ol>

🎛️ Atributos útiles de <ol>

  • type="A" o type="I": cambia números por letras o números romanos.
  • start="5": inicia la numeración en el número 5.
  • reversed: numera en orden descendente (3, 2, 1).
DIAPOSITIVA 3 · COLECCIONES Y MENÚS

Listas Desordenadas (<ul>) y Listas Anidadas

Se usan cuando el orden NO importa. Además, son la base técnica para construir barras de navegación.

• Lista simple y anidada

<ul>
  <li>Frontend
    <ul>
      <li>HTML5</li>
      <li>CSS3</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>

📖 Listas de definición (<dl>)

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado para la web.</dd>
</dl>

Perfectas para glosarios, preguntas frecuentes o fichas técnicas.

⚠️ Regla de oro: Dentro de <ul> o <ol>, los hijos directos siempre deben ser <li>. Si anidas otra lista, métela dentro de un <li>.
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Listas en HTML

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
