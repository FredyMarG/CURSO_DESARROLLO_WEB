DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Propiedad Display y para qué sirve?

🎯 Propósito en proyectos reales

Entiende por qué un <div> ocupa todo el ancho, por qué un <span> ignora width y cómo ocultar elementos sin romper el diseño. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.

DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Propiedad Display

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
