DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Transition CSS y para qué sirve?

🎯 Propósito en proyectos reales

Suaviza el paso entre dos estados (normal y :hover o :focus) con control de duración, curva de aceleración y retardo. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · SINTAXIS

Cómo declarar una transición

📝 En el estado base (no en :hover)

.btn {
  background: #0284c7;
  transition: transform 0.25s ease,
              background-color 0.25s ease;
}
.btn:hover {
  transform: translateY(-3px);
  background: #38bdf8;
}

💡 Por qué va en el estado base

Si pones transition en el estado base .btn, la animación será suave tanto al entrar como al salir del :hover.

DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Transition CSS

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
