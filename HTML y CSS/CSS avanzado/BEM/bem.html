DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Metodología BEM y para qué sirve?

🎯 Propósito en proyectos reales

Aprende a nombrar clases CSS de forma predecible y modular (Block, Element, Modifier) para evitar colisiones de estilos y mantener la especificidad plana. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · CONVENCIÓN

Block, Element y Modifier

🧱 Estructura

  • Block (.card): componente independiente y reutilizable.
  • Element (.card__title): parte interna que depende del bloque (usa doble guion bajo __).
  • Modifier (.card--featured): variante visual o de estado (usa doble guion medio --).

💻 Ejemplo limpio

<article class="card card--featured">
  <h3 class="card__title">Plan Pro</h3>
  <button class="card__btn card__btn--primary">Elegir</button>
</article>
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Metodología BEM

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
