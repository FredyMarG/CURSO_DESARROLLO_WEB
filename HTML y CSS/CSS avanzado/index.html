DIAPOSITIVA 2 · REGLAS DE PRIORIDAD

Especificidad, Cascada y Herencia

Cuando múltiples reglas aplican al mismo elemento, CSS decide el ganador usando un sistema de puntos.

SelectorPeso (A, B, C)Ejemplo
Etiqueta / Pseudoelemento(0, 0, 1)p, div::before
Clase / Pseudoclase / Atributo(0, 1, 0).btn, :hover, [type="text"]
ID(1, 0, 0)#header
Estilo en línea (style="")Gana a los anteriores<p style="color:red">
⚠️ Evita !important: Rompe la cascada natural y vuelve imposible sobrescribir estilos después. Solo úsalo en clases de utilidad puntuales o accesibilidad.
DIAPOSITIVA 3 · COMPORTAMIENTO DE CAJAS

Display, Overflow y Object-Fit

Controla cómo fluyen los elementos, qué pasa cuando el contenido se desborda y cómo se recortan las imágenes.

🧱 Tipos de display

  • block: ocupa todo el ancho disponible y hace salto de línea.
  • inline: ocupa solo su contenido (ignora width/height y margin-top/bottom).
  • inline-block: fluye en línea pero sí acepta width y height.

🖼️ object-fit: cover

.avatar {
  width: 120px;
  height: 120px;
  object-fit: cover; /* Recorta sin deformar */
  object-position: center top;
}

Con overflow: hidden ocultas lo que sobresale; con overflow: auto muestras scroll solo si hace falta.

DIAPOSITIVA 4 · SACAR ELEMENTOS DEL FLUJO

Position: Relative, Absolute, Fixed y Sticky

Coloca badges, modales, barras fijas y encabezados pegajosos exactamente donde los necesitas.

📍 Los 4 modos clave

  • relative: se mueve respecto a su posición original y sirve de ancla para hijos absolutos.
  • absolute: sale del flujo y se posiciona respecto al ancestro posicionado más cercano.
  • fixed: fijo respecto a la ventana del navegador (viewport).
  • sticky: se comporta normal hasta alcanzar un umbral de scroll (top: 0).

📚 Capas con z-index

.padre { position: relative; }
.badge {
  position: absolute;
  top: -10px;
  right: -10px;
  z-index: 10; /* Solo funciona si position != static */
}
DIAPOSITIVA 5 · ESTADOS Y DECORACIÓN

Pseudoclases (:) vs Pseudoelementos (::)

Reacciona a estados del usuario e inserta elementos decorativos sin ensuciar el HTML.

🎭 Pseudoclases (:) — Estados

  • :hover, :focus-visible, :active
  • :nth-child(odd) / :first-child
  • :not(.deshabilitado)

✨ Pseudoelementos (::) — Partes virtuales

.titulo::after {
  content: ""; /* Obligatorio */
  display: block;
  width: 48px;
  height: 3px;
  background: #38bdf8;
}
DIAPOSITIVA 6 · CÓDIGO ESCALABLE

Metodología BEM (Block, Element, Modifier)

Evita colisiones de nombres y mantén la especificidad plana (siempre 1 clase) en proyectos grandes.

🧱 Convención de nombres

  • Bloque: .card (componente independiente)
  • Elemento: .card__title (parte interna, doble guion bajo)
  • Modificador: .card--featured (variante, doble guion medio)

💻 Ejemplo limpio

<article class="card card--featured">
  <h3 class="card__title">Plan Pro</h3>
  <button class="card__btn">Elegir</button>
</article>

|-----------------|----------------------------------|-----------------------------------------------------------------------------------|

| display | display: block; | Tipo de caja (block, inline, flex, grid, etc.). |

| visibility | visibility: hidden; | Oculta manteniendo el espacio. |

| overflow | overflow: auto; | Comportamiento del contenido que se desborda. |

| overflow-x | overflow-x: scroll; | Desbordamiento horizontal. |

| overflow-y | overflow-y: hidden; | Desbordamiento vertical. |

| position | position: absolute; | Modelo de posicionamiento (static, relative, absolute, fixed, sticky). |

| top / left / right / bottom | top: 0; left: 0; | Offset cuando position ≠ static. |

| z-index | z-index: 10; | Orden de apilamiento. |

| float | float: left; | Flotado (layout clásico). |

| clear | clear: both; | Cancelación de flotados. |
