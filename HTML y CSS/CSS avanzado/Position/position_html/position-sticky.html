DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Position Sticky y para qué sirve?

🎯 Propósito en proyectos reales

Un híbrido inteligente: fluye normalmente hasta que el scroll alcanza el umbral definido (como top: 0), y entonces se queda pegado dentro de su contenedor. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · REGLAS

Por qué a veces sticky "no funciona"

.encabezado-sticky {
  position: sticky;
  top: 0; /* ¡Obligatorio! */
  background: #0f172a;
}

⚠️ 2 motivos de fallo

  • Olvidar definir un umbral (top: 0 o bottom: 0).
  • Que un ancestro tenga overflow: hidden (usa overflow: clip en su lugar).
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Position Sticky

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
