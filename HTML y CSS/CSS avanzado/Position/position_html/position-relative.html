DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Position Relative y para qué sirve?

🎯 Propósito en proyectos reales

Desplaza un elemento desde su posición original sin quitarle el hueco en el flujo normal, y conviértelo en el marco de referencia para hijos absolute. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · COMPORTAMIENTO

Conserva el espacio y sirve de ancla

📍 Regla básica

.caja {
  position: relative;
  top: 12px;
  left: 20px;
}

🔑 Puntos clave

  • Su espacio original sigue reservado (los hermanos no se mueven).
  • Habilita z-index.
  • Es el contenedor ideal para hijos con position: absolute.
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Position Relative

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
