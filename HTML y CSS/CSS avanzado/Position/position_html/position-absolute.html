DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Position Absolute y para qué sirve?

🎯 Propósito en proyectos reales

Saca un elemento del flujo normal para colocarlo exactamente en una esquina, encima de una imagen o centrado respecto a su ancestro posicionado más cercano. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · REGLA DE ORO

Padre Relative + Hijo Absolute

.card { position: relative; }
.badge {
  position: absolute;
  top: -10px;
  right: 14px;
}

⚡ Shorthand inset

inset: 0; equivale a top: 0; right: 0; bottom: 0; left: 0; — ideal para crear overlays que cubren toda una imagen.

DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Position Absolute

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
