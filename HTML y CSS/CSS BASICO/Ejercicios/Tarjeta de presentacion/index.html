DIAPOSITIVA 2 · ESTRUCTURA DEL EJERCICIO

Clase base + Variantes de color

🧱 HTML del componente

<div class="card">
  <img class="card_img" src="..." alt="Avatar">
  <h1 class="card_title">Alex Rivera</h1>
  <h2 class="card_subtitle">PROGRAMADOR WEB</h2>
  <p class="card_content">...</p>
</div>

🎨 Reutilización inteligente

La clase .card define ancho, padding, centrado y sombra. Luego agregas .red-card o .green-card para cambiar solo el color de fondo sin repetir código.

DIAPOSITIVA 3 · ESTILOS DEL ARCHIVO style.css

Box Model, Sombras y Tipografía

  • width: 300px; margin: auto; centra horizontalmente una caja con ancho definido.
  • box-shadow: 0 0 30px #0006; añade una sombra suave con transparencia alfa hexadecimal.
  • border-radius: 50%; convierte cualquier imagen cuadrada en un avatar circular perfecto.
  • letter-spacing: 2px; aporta aire tipográfico al subtítulo del cargo.
