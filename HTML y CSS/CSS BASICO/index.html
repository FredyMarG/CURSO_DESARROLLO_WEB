DIAPOSITIVA 2 · SINTAXIS Y SELECTORES

¿Cómo funciona una regla CSS?

CSS selecciona elementos del HTML y les aplica pares de propiedad: valor;.

🧩 Anatomía básica

/* Selector de clase (reutilizable) */
.tarjeta {
  background-color: #0f172a;
  color: #f8fafc;
  padding: 20px;
}

🎯 Selectores esenciales

  • Etiqueta: p { } — aplica a todos los párrafos.
  • Clase: .boton { } — la forma recomendada para estilizar.
  • ID: #menu { } — único por página; mejor reservarlo para JS o anclas.
💡 Buena práctica: Enlaza tu CSS externo en el <head> con <link rel="stylesheet" href="style.css"> para mantener HTML y estilos separados y fáciles de mantener.
DIAPOSITIVA 3 · CONCEPTO REY DE CSS

El Modelo de Caja (Box Model)

Cada elemento HTML es una caja compuesta por cuatro capas concéntricas de adentro hacia afuera.

🧅 Las 4 capas

  • 1. Content: el texto o imagen (width / height).
  • 2. Padding: relleno interno entre el contenido y el borde (hereda el fondo).
  • 3. Border: el contorno visible de la caja.
  • 4. Margin: espacio externo transparente que separa la caja de sus vecinas.

🛡️ El reset obligatorio: border-box

*, *::before, *::after {
  box-sizing: border-box;
}

Con border-box, si dices width: 300px, la caja mide exactamente 300px aunque agregues padding y borde.

🧠 Analogía mental: Imagina un cuadro enmarcado en una galería: la pintura es el Content, el paspartú blanco es el Padding, el marco de madera es el Border y la distancia hasta el siguiente cuadro en la pared es el Margin.
DIAPOSITIVA 4 · TAMAÑOS Y ESCALADO

Unidades Absolutas vs Relativas

Elegir la unidad correcta hace que tu diseño sea legible y accesible en cualquier pantalla.

UnidadTipoReferenciaCuándo usarla
pxAbsolutaPíxeles CSSBordes (1px), sombras, radios pequeños
remRelativaTamaño de fuente del <html> (16px)Tipografías, paddings y márgenes consistentes
emRelativaTamaño de fuente del padre/elementoEspaciados que escalan con el botón o texto
%RelativaContenedor padreAnchos fluidos (width: 100%)
DIAPOSITIVA 5 · ESTÉTICA Y LEGIBILIDAD

Propiedades de Texto y Sistemas de Color

La buena tipografía y el contraste adecuado definen el 80% de la calidad visual de una web.

✍️ Tipografía legible

body {
  font-family: 'Outfit', system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.6; /* Aire entre líneas */
}

🌈 Formatos de color

  • HEX: #38bdf8 (compacto y universal).
  • RGB / RGBA: rgba(56, 189, 248, 0.2) (ideal para transparencias).
  • HSL: hsl(199, 89%, 60%) (tono, saturación, brillo: muy intuitivo).
DIAPOSITIVA 6 · PROFUNDIDAD VISUAL

Gradientes, Border-Radius y Box-Shadow

Crea tarjetas modernas con profundidad sutil sin recurrir a imágenes pesadas.

🌅 Gradientes CSS

.hero {
  background: linear-gradient(135deg, #0284c7, #6366f1);
}

☁️ Sombras realistas

.card {
  border-radius: 16px;
  box-shadow: 0 12px 28px rgba(0, 0, 0, 0.25);
}

Orden de valores: offset-x offset-y blur spread color.
