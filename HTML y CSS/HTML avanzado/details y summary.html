DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Details y Summary y para qué sirve?

🎯 Propósito en proyectos reales

Crea secciones desplegables, FAQs y paneles expandibles 100% accesibles por teclado sin escribir una sola línea de JavaScript. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · FUNCIONAMIENTO NATIVO

<details>, <summary> y [open]

El navegador agrega automáticamente el atributo open cuando el usuario expande el elemento.

📝 Acordeón exclusivo con name

<details name="faq" open>
  <summary>¿Necesita JavaScript?</summary>
  <p>No, es 100% nativo en HTML5.</p>
</details>
<details name="faq">
  <summary>¿Es accesible?</summary>
  <p>Sí, funciona con Tab y Enter.</p>
</details>

🎨 Estilizado en CSS

details[open] {
  border-color: #38bdf8;
}
summary::marker {
  color: #38bdf8;
}
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en Details y Summary

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
