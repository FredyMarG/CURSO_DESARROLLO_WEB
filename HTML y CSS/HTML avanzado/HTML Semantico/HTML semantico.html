DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es HTML Semántico y para qué sirve?

🎯 Propósito en proyectos reales

Reemplaza los <div> genéricos por etiquetas que comunican exactamente qué rol cumple cada sección de tu página a navegadores, Google y lectores de pantalla. Entender la intención de cada etiqueta o propiedad te ayuda a escribir código más limpio, accesible y fácil de mantener.

🧠 Modelo mental: Piensa siempre primero en la estructura y el significado (qué rol cumple este elemento para el usuario y los lectores de pantalla) y luego en su apariencia visual con CSS.
DIAPOSITIVA 2 · ROLES

¿Cuándo usar cada etiqueta?

EtiquetaPropósito
<header>Cabecera de la página o de un artículo
<nav>Bloque principal de enlaces de navegación
<main>Contenido central único (solo 1 visible por página)
<article>Contenido independiente reutilizable (post, noticia, producto)
<section>Agrupación temática con encabezado propio
<aside> / <footer>Barra lateral complementaria y pie de página
DIAPOSITIVA 4 · BUENAS PRÁCTICAS

Buenas prácticas y errores comunes en HTML Semántico

✅ Buena práctica: Verifica siempre tu código en el navegador con DevTools (F12), prueba la navegación con teclado (Tab) y mantén una estructura semántica clara.
⚠️ Error frecuente: Usar etiquetas o propiedades únicamente por su aspecto visual por defecto, olvidando atributos clave de accesibilidad, contraste o validación.
