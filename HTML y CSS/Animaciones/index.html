DIAPOSITIVA 2 · CUÁNDO USAR CADA UNA

Transiciones vs Animaciones (@keyframes)

Las transiciones requieren un cambio de estado (como :hover); las animaciones corren solas y en bucle.

🔄 transition

  • Solo tiene dos estados: inicio (A) y fin (B).
  • Ideal para hover de botones, menús desplegables y foco de inputs.
  • transition: transform 0.25s ease, opacity 0.25s ease;

🎞️ @keyframes + animation

  • Múltiples pasos intermedios (0%, 50%, 100%).
  • Puede repetirse infinitamente (infinite) y alternar dirección (alternate).
  • Ideal para loaders, pulsos, entradas y efectos continuos.
💡 Buena práctica: Nunca escribas transition: all 0.3s; en producción; especifica las propiedades exactas (ej. transform, background-color) para evitar animar propiedades costosas sin querer.
DIAPOSITIVA 3 · SINTAXIS COMPLETA

Anatomía de @keyframes y animation

Controla duración, curva de aceleración, retardo, iteraciones y estado final.

📝 Línea de tiempo

@keyframes flotar {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-12px); }
}
.icono {
  animation: flotar 2.4s ease-in-out infinite;
}

🎛️ Propiedades clave

  • animation-fill-mode: forwards → conserva el estilo del último keyframe al terminar.
  • animation-direction: alternate → va de 0%→100% y regresa 100%→0%.
  • animation-play-state: paused → pausa la animación al hacer hover.
DIAPOSITIVA 4 · RENDIMIENTO WEB

Rendimiento a 60 FPS (GPU Compositing)

El navegador tiene ~16.6 ms por fotograma. Animar propiedades equivocadas provoca tirones (jank).

Propiedad animadaFase del navegadorRendimientoAlternativa recomendada
top / left / width / heightLayout + Paint + Composite🔴 Lento (recalcula toda la página)transform: translate() / scale()
background / box-shadowPaint + Composite🟡 MedioAnimar opacity de un pseudo-elemento
transform / opacitySolo Composite (GPU)🟢 60 FPS fluidos¡Úsalas siempre que puedas!
🧠 Analogía mental: Mover una caja con left es como derribar y reconstruir una pared cada milisegundo. Moverla con transform: translateX() es como deslizar un acetato ya dibujado encima de la mesa.
DIAPOSITIVA 5 · FÍSICA NATURAL

Timing Functions y cubic-bezier()

En la vida real nada arranca ni frena de golpe: las curvas dan peso, elasticidad y naturalidad.

📈 Curvas estándar

  • linear: velocidad constante (ideal para rotaciones continuas/loaders).
  • ease-out: arranca rápido y frena suave (ideal para elementos que entran).
  • ease-in: arranca lento y acelera (ideal para elementos que salen).
  • ease-in-out: suave al inicio y al final (ideal para bucles).

🏀 Efecto rebote con cubic-bezier()

.boton {
  transition: transform 0.35s cubic-bezier(0.34, 1.56, 0.64, 1);
}
.boton:hover {
  transform: scale(1.08);
}

Cuando el segundo o cuarto valor supera 1, la animación hace un ligero sobreimpulso elástico.

DIAPOSITIVA 6 · CSS MODERNO Y ACCESIBLE

Scroll-Driven Animations y prefers-reduced-motion

Sincroniza animaciones con el desplazamiento sin JavaScript y respeta a usuarios sensibles al movimiento.

📜 Scroll-Driven Animations

.barra-progreso {
  animation: crecer linear both;
  animation-timeline: scroll();
}

Con view() puedes animar tarjetas justo cuando entran en pantalla.

♿ Respetar preferencia del sistema

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

🔹 ¿Qué hace realmente una transición?

Una transición le dice al navegador:

"Cuando esta propiedad cambie de valor, no la cambies
instantáneamente. Interpólala en el tiempo."

El navegador calcula los valores intermedios automáticamente.

DOCUMENTACIÓN OFICIAL · ANIMACIONES.md

🔹 transition: propiedad duración timing delay;

Ejemplo:

transition: background-color 0.3s ease 0.1s;

1. Propiedad

Es la propiedad que será animada.

2. duration

Tiempo total de interpolación.

3. timing-function

Curva de velocidad (Bézier cúbica).

4. delay

Tiempo antes de comenzar.

DOCUMENTACIÓN OFICIAL · ANIMACIONES.md

🔹 ¿Por qué NO animar width o height?

Porque causan:

  • - Reflow
  • - Repaint
  • - Impacto en performance

Mientras que:

  • - transform
  • - opacity

Se ejecutan en la GPU → más eficientes.
