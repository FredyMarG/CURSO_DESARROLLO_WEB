DIAPOSITIVA 2 · FUNDAMENTOS Y ANALOGÍA

¿Qué es Manejo de Errores (Try-Catch)?

🎯 Propósito en JavaScript moderno

Captura errores en tiempo de ejecución para evitar que tu aplicación se rompa y muestra mensajes útiles al usuario.

🧠 Modelo mental: try es la red de seguridad de un trapecista: si algo falla adentro, catch lo atrapa sin caer al vacío.
DIAPOSITIVA 3 · SINTAXIS Y USO

Bloque try / catch / finally

try {
  const data = JSON.parse(textoInvalido);
} catch (err) {
  console.error("JSON inválido:", err.message);
} finally {
  ocultarLoader();
}

# DEFINICIÓN

Los errores pueden viajar entre funciones.

# EJEMPLO

function c(){

    throw new Error(
        "Error"
    );

}

function b(){

    c();

}

function a(){

    b();

# RE-THROWING

# ¿QUÉ ES?

Volver a lanzar una excepción.

# EJEMPLO

try{

    ejecutar();

}
catch(error){

    console.log(
        "Registrando..."
    );

    throw error;

}

# ¿PARA QUÉ SIRVE?

Permite registrar el error y seguir propagándolo.
