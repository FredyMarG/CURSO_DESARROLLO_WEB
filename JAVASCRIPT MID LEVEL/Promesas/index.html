¿Qué es una Promesa?

Es un objeto que representa la terminación o el fracaso de una operación asíncrona. Puede estar en uno de tres estados: Pendiente (Pending), Resuelta (Fulfilled) o Rechazada (Rejected).

💡

Abre la consola del navegador (F12 o Ctrl + Shift + I) para ver la ejecución del encadenamiento de Promesas en segundo plano.

Sintaxis de la Promesa simulada:
// Creación de la promesa
const miPromesa = new Promise((resolve, reject) => {
    // Estado: PENDING (Pendiente)
    setTimeout(() => {
        if (exito) {
            resolve("¡Operación exitosa!"); // FULFILLED (Resuelta)
        } else {
            reject("Hubo un error."); // REJECTED (Rechazada)
        }
    }, retraso);
});
