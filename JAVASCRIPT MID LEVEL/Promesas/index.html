¿Qué es una Promesa?

Es un objeto que representa la terminación o el fracaso de una operación asíncrona. Puede estar en uno de tres estados: Pendiente (Pending), Resuelta (Fulfilled) o Rechazada (Rejected).

💡

Abre la consola del navegador (F12 o Ctrl + Shift + I) para ver la ejecución en segundo plano y el flujo de logs.

Sintaxis de la Promesa simulada:
// Creación de la promesa
const miPromesa = new Promise((resolve, reject) => {
    // Estado: PENDING (Pendiente)
    setTimeout(() => {
        if (exito) {
            resolve("¡Operación exitosa!"); // FULFILLED (Resuelta)
        } else {
            reject("Hubo un error."); // REJECTED (Rechazada)
        }
    }, retraso);
});

Encadenamiento de Promesas

Consiste en encadenar múltiples llamadas a funciones asíncronas secuenciales con .then(). El retorno de cada paso sirve de entrada para el siguiente, capturando cualquier error con un único .catch() al final.

Código del encadenamiento en ejecución:
obtenerPersona(id)
    .then((persona) => {
        console.log(persona.nombre);
        return obtenerInstagram(id); // Retorna otra Promesa
    })
    .then((instagram) => {
        console.log(instagram);
    })
    .catch((err) => {
        console.error(err); // Captura errores del Paso 1 o 2
    });
