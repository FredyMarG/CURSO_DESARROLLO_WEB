¿Qué es AJAX y cómo funciona XMLHttpRequest?

AJAX (Asynchronous JavaScript And XML) es un conjunto de técnicas de desarrollo web que permite a las aplicaciones solicitar o enviar datos a un servidor en segundo plano y actualizar secciones específicas del DOM sin necesidad de recargar la página completa.

El corazón tradicional de AJAX es el objeto XMLHttpRequest (XHR). Al instanciarlo, este objeto pasa por 5 estados progresivos representados por la propiedad readyState (desde 0 hasta 4). En los inicios de la web se capturaba el evento onreadystatechange evaluando si se alcanzaba el estado final 4 (DONE), mientras que los estándares modernos permiten usar el evento directo onload.

📬

La Analogía del Mensajero de Oficina

Creas al mensajero (new XMLHttpRequest()), le indicas a dónde ir y qué traer (xhr.open()), dejas una nota en tu puerta con instrucciones para cuando él vuelva (xhr.onload), y le ordenas salir a la calle (xhr.send()). Mientras él viaja tú sigues trabajando en tu computadora sin pausar tu actividad (Asincronía).

⚠️

Requisito de Servidor Local: Las peticiones AJAX fallarán por políticas de seguridad (CORS) si abres este archivo con doble clic directo (file:///C:/...). Debes utilizar un servidor local como Live Server en VS Code o http-server en Node.js.

Comparativa técnica: onreadystatechange (Clásica) vs onload (Moderna):
// 1. FORMA CLÁSICA (Histórica con readyState):
const xhrAntiguo = new XMLHttpRequest();
xhrAntiguo.open("GET", "/api/usuarios", true);
xhrAntiguo.onreadystatechange = function() {
    // Es obligatorio evaluar manualmente si se alcanzó el estado final 4
    if (xhrAntiguo.readyState === 4 && xhrAntiguo.status === 200) {
        const datos = JSON.parse(xhrAntiguo.responseText);
        console.log("Datos recibidos:", datos);
    }
};
xhrAntiguo.send();

// 2. FORMA MODERNA (XHR Nivel 2 con onload):
const xhrModerno = new XMLHttpRequest();
xhrModerno.open("GET", "/api/usuarios");
// onload solo se dispara automáticamente cuando la operación ya culminó (estado DONE)
xhrModerno.onload = function() {
    if (xhrModerno.status === 200) {
        console.log("Respuesta lista:", JSON.parse(xhrModerno.responseText));
    }
};
xhrModerno.send();

Compatibilidad Histórica (ActiveXObject) y Formularios (FormData)

En los inicios de los años 2000, la técnica AJAX fue inventada por Microsoft e introducida en Internet Explorer 5 a través de un control propietario llamado ActiveXObject("Microsoft.XMLHTTP"). Para que una página funcionara en cualquier navegador antiguo, era obligatorio usar una condición de detección cruzada:

Detección universal de compatibilidad histórica:
// Patrón canónico de compatibilidad multiplataforma de principios de los 2000:
var xhr;
if (window.XMLHttpRequest) {
    xhr = new XMLHttpRequest(); // Navegadores estándar (Mozilla, Safari, Chrome, IE7+)
} else {
    xhr = new ActiveXObject("Microsoft.XMLHTTP"); // Internet Explorer 5 y 6
}

Envío de Formularios Dinámicos con FormData

Construir cadenas JSON manualmente al enviar formularios con muchos campos puede ser propenso a errores. El objeto nativo FormData compila automáticamente los campos en pares clave-valor (formato multipart/form-data).

⭐

Regla de Oro: Al enviar un objeto FormData con xhr.send(formData), NUNCA debes configurar manualmente la cabecera Content-Type. El navegador la calcula automáticamente junto con el delimitador (boundary) del paquete.
