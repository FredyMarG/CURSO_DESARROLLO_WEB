Ejercicio 4

Los datos de cofla y de otros alumnos fueron recibidos y ya están almacenados ahora hay que crear un sistema que muestre esa información y se pueda asignar cuando rinde.

  1. La interfaz debe ser agradable y atractiva.
  2. Debe contener todos los datos de manera estructurada.
  3. El profesor puede seleccionar en cual de las 2 semanas rinde el usuario.
  4. Si el profesor confirma, los datos se deben actualizar y reemplazar el espacio de seleccion de semana por la semana seleccionada.

Realizaremos una tabla con los datos que nos estan pidiendo y la semana que le corresponde a cada alumno.
