Ejercicio 7

Cofla ya esta cursando su último semestre en la universidad. Efectivamente tuvo todo lo necesario para pasar de año, pero el tiene una duda, quiere saber cuantas personas que cursan el último semestre, se reciben y cuantas no, esta información la tiene una API de su universidad a la que el tiene fácil acceso.

  1. Crear un sistema para obtener esa información
  2. Mostrarla ordenadamente en un sitio web
Para ejecutar este proyecto en XAMPP:

Coloca la carpeta 7 Compañeros de Cofla Htdocs dentro de C:\xampp\htdocs\, inicia Apache y abre http://localhost/7 Compañeros de Cofla Htdocs/ en el navegador.

Realizaremos el sistema con la informacion del API
