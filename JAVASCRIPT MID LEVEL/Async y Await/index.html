¿Qué es una función asíncrona?

La palabra clave async convierte una función en asíncrona, haciendo que retorne automáticamente una Promesa. Dentro de ella, podemos usar await para pausar la ejecución del código de forma lineal hasta que la Promesa se complete.

💡

Abre la consola del navegador (F12 o Ctrl + Shift + I) para observar cómo se ejecutan las llamadas asíncronas en segundo plano.

Sintaxis de la función asíncrona:
// Función asíncrona declarada con async
const mostrarData = async () => {
    try {
        // await pausa la ejecución hasta resolver la promesa
        const resultado = await obtenerInformacion(retraso);
        console.log(resultado); // Operación completada
    } catch (error) {
        console.error(error); // Atrapa el rechazo de la promesa
    }
};

Secuencialidad de Await

Cuando colocamos múltiples expresiones await consecutivas, JavaScript detiene la ejecución en cada una de ellas de forma secuencial. El siguiente paso no se ejecuta hasta que el paso anterior ha terminado exitosamente.

Código del flujo secuencial ejecutado:
const consultarPerfil = async (id) => {
    try {
        const persona = await obtenerPersona(id);
        console.log(persona.nombre);
        
        const instagram = await obtenerInstagram(id); // Espera al paso anterior
        console.log(instagram);
    } catch (err) {
        console.error(err); // Captura el error si cualquiera falla
    }
};
