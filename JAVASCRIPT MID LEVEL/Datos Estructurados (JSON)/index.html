¿Qué es JSON y por qué lo usamos?

JSON (JavaScript Object Notation) es un formato ligero de intercambio de datos basado en texto. Aunque proviene de la sintaxis de objetos de JavaScript, es un formato independiente de cualquier lenguaje de programación. Esto significa que clientes y servidores desarrollados en Python, Java, PHP, C# o Node.js pueden comunicarse e intercambiar datos estructurados usando exactamente el mismo estándar de texto plano.

En JavaScript contamos con el objeto nativo JSON que provee dos métodos estáticos esenciales: JSON.stringify() para serializar (transformar objetos de la memoria en cadenas de texto para enviarlos o guardarlos) y JSON.parse() para deserializar (reconstruir un objeto JavaScript vivo a partir de un texto JSON recibido).

Sintaxis canónica de JSON en JavaScript:
// 1. Serializar: Objeto en memoria ➡️ Cadena de texto JSON
const usuario = { id: 1, nombre: "Fredy", premium: true };
const cadenaJSON = JSON.stringify(usuario, null, 2); // Indentado a 2 espacios
console.log(typeof cadenaJSON); // "string"

// 2. Deserializar: Cadena de texto JSON ➡️ Objeto JavaScript vivo
try {
    const objetoRecuperado = JSON.parse(cadenaJSON);
    console.log(typeof objetoRecuperado); // "object"
    console.log(objetoRecuperado.nombre); // "Fredy"
} catch (error) {
    // Si la cadena JSON no cumple la sintaxis estricta, lanza un SyntaxError
    console.error("Error al parsear JSON:", error.message);
}

Estructura, Tipos de Datos y Reglas Estrictas

A diferencia de los objetos literales de JavaScript, JSON impone reglas sintácticas estrictas: las propiedades/claves deben estar obligatoriamente entre comillas dobles ("clave"), no se permiten comas al final del último elemento (trailing commas), y ciertos tipos de JavaScript (como funciones, undefined o Symbol) no existen en el estándar JSON y serán ignorados o descartados durante la serialización.

Matriz de Compatibilidad de Tipos de Datos en JSON
Tipo de Dato ¿Soportado en JSON? Ejemplo en JavaScript Comportamiento en JSON
String / Number ✅ Sí (Nativo) "Hola", 42, 3.14 Siempre comillas dobles en strings
Boolean / Null ✅ Sí (Nativo) true, false, null Preserva el valor literal exacto
Object / Array ✅ Sí (Nativo) { a: 1 }, [1, 2, 3] Soporta anidamiento multidimensional
Function / Undefined ❌ NO Soportado () => {}, undefined Se omiten en objetos; se convierten en null en arrays

Patrones profesionales con JSON (Deep Clone y Almacenamiento Local):
// 1. Clonación profunda (Deep Copy) tradicional en JavaScript
const original = { usuario: "Fredy", config: { tema: "oscuro", zoom: 100 } };
const clonProfundo = JSON.parse(JSON.stringify(original));
clonProfundo.config.tema = "claro"; // No muta al objeto original

// 2. Almacenamiento estructurado en el navegador con localStorage
const guardarSesion = (datosUsuario) => {
    // localStorage solo admite texto plano, por lo que serializamos a JSON
    localStorage.setItem("sesion_usuario", JSON.stringify(datosUsuario));
};

const recuperarSesion = () => {
    const textoGuardado = localStorage.getItem("sesion_usuario");
    if (!textoGuardado) return null;
    try {
        return JSON.parse(textoGuardado); // Reconstruye el objeto original
    } catch (e) {
        console.error("Corrupción de datos en localStorage:", e);
        return null;
    }
};
