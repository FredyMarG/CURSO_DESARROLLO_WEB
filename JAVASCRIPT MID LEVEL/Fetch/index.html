La Era Moderna: Fetch API y Arquitectura de Promesas

La API Fetch es el estándar nativo moderno de JavaScript para realizar peticiones HTTP. A diferencia del antiguo XMLHttpRequest, Fetch está completamente basado en Promesas nativas, lo que permite un código limpio, lineal y libre de Callback Hell mediante async/await o .then()/.catch().

Fetch opera en dos fases consecutivas: primero resuelve una promesa con el objeto Response (donde verificamos response.ok y las cabeceras), y en una segunda fase asíncrona debemos invocar al método lector del cuerpo adecuado para procesar los bytes descargados.

🍽️

La Analogía del Restaurante Gourmet

Usar Fetch es como ir a un restaurante donde pides un platillo y el mesero te trae el plato cubierto a la mesa rápidamente (llegaron las cabeceras). Tú sabes que el pedido llegó bien, pero para poder comértelo tienes que destaparlo y prepararlo tú mismo (invocar a .json() o .text()).

Sintaxis canónica con Fetch API y Async / Await:
// Petición moderna con Fetch API usando async/await
const consultarDatos = async () => {
    try {
        // Fase 1: Se envían cabeceras y se recibe el objeto Response
        const response = await fetch("/api/usuarios");

        // Regla clave: Los errores 404 o 500 NO van al catch directo en Fetch;
        // debemos evaluar manualmente la propiedad lógica response.ok (status 200-299)
        if (!response.ok) {
            throw new Error(`Error HTTP: ${response.status} - ${response.statusText}`);
        }

        // Fase 2: Se invoca al lector adecuado del cuerpo (.json(), .text(), .blob())
        const datos = await response.json();
        console.log("Datos recibidos y parseados:", datos);
        return datos;
    } catch (error) {
        // Solo captura fallos críticos de red o excepciones lanzadas manualmente
        console.error("Fallo capturado en catch:", error.message);
    }
};

¿Por qué usar Axios? La Evolución Profesional

Aunque Fetch es nativo y excelente, en aplicaciones profesionales del mundo real se suele preferir Axios debido a que automatiza las tareas más repetitivas de red:

🚀

Las 4 Ventajas de Oro de Axios sobre Fetch

1. Transformación automática de JSON: Los datos llegan listos y parseados en response.data.
2. Manejo automático de errores: Los códigos 4xx y 5xx se arrojan directamente al bloque catch.
3. Peticiones POST simplificadas: Serializa objetos a JSON automáticamente sin configurar cabeceras a mano.
4. Interceptores globales: Permite inyectar tokens JWT y auditar peticiones en una sola línea de configuración.

Matriz Comparativa: Fetch API (Nativo) vs. Axios (Librería)

// 1. CON FETCH (Nativo de JavaScript):
const datosFetch = await fetch("/api/usuarios");
if (!datosFetch.ok) throw new Error("Fallo: " + datosFetch.status);
const usuarios = await datosFetch.json(); // Segundo await obligatorio
console.log(usuarios);

// 2. CON AXIOS (Biblioteca Externa):
const respuesta = await axios.get("/api/usuarios");
console.log(respuesta.data); // Ya transformado a JSON directo en .data
// Si el servidor responde 404 o 500, Axios lo arroja al catch automáticamente!
