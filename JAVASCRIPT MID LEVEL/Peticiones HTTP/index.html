¿Qué es una Petición HTTP?

Una petición HTTP (HyperText Transfer Protocol) es el mensaje que envía el cliente (el navegador web) a un servidor para solicitar recursos o realizar acciones. El servidor procesa la solicitud y devuelve una respuesta HTTP compuesta por un código de estado (Status Code), cabeceras (Headers) y el cuerpo (Body/Payload) generalmente estructurado en formato JSON.

Los métodos HTTP principales definen la intención de la operación: GET (consultar información), POST (enviar datos para crear un nuevo recurso), PUT (actualizar un recurso existente) y DELETE (eliminar información del servidor).

Sintaxis moderna con Fetch API y Async / Await:
// Petición HTTP asíncrona moderna mediante Fetch API
const realizarPeticion = async (url, metodo = 'GET', datos = null) => {
    try {
        const opciones = {
            method: metodo, // Define el verbo HTTP (GET, POST, PUT, DELETE)
            headers: { 'Content-Type': 'application/json' }, // Cabecera para contenido JSON
            body: datos ? JSON.stringify(datos) : null // Serializa el objeto a JSON si hay datos
        };

        // fetch retorna una Promesa con el objeto Response del servidor
        const respuesta = await fetch(url, opciones);

        // response.ok verifica si el código de estado está en el rango exitoso (200 - 299)
        if (!respuesta.ok) {
            throw new Error(`Error HTTP: ${respuesta.status} - ${respuesta.statusText}`);
        }

        // response.json() parsea el flujo de bytes del cuerpo a objeto JavaScript
        const datosServidor = await respuesta.json();
        console.log("Datos recibidos del servidor:", datosServidor);
        return datosServidor;
    } catch (error) {
        console.error("Fallo en la comunicación de red:", error.message);
    }
};

Ciclo de Vida de una Petición y XMLHttpRequest

Antes del estándar fetch(), las aplicaciones web utilizaban el objeto XMLHttpRequest para realizar peticiones asíncronas (AJAX) sin necesidad de recargar la página. Este objeto pasa por 5 fases o estados representados por la propiedad readyState (desde 0 hasta 4), emitiendo el evento readystatechange en cada transición.

Código de implementación con XMLHttpRequest tradicional:
// Creación de una petición HTTP asíncrona con el objeto XMLHttpRequest (AJAX tradicional)
const solicitarConXHR = (url) => {
    const xhr = new XMLHttpRequest(); // 1. Se crea la instancia del objeto de comunicación

    // 2. Se inicializa la petición indicando el método HTTP y la ruta del recurso (readyState 1: OPENED)
    xhr.open("GET", url, true);

    // 3. Se registra el escuchador del evento readystatechange para monitorear el ciclo de vida
    xhr.addEventListener("readystatechange", () => {
        // readyState 4 (DONE) indica que toda la operación de transferencia ha terminado
        if (xhr.readyState === 4) {
            // Se valida si el servidor respondió con un código de éxito 200 (OK)
            if (xhr.status === 200) {
                // Deserializa el texto recibido en formato JSON convirtiéndolo a objeto JavaScript
                const datos = JSON.parse(xhr.responseText);
                console.log("Respuesta exitosa recibida del servidor:", datos);
            } else {
                console.error(`Error HTTP: ${xhr.status} - No se pudo recuperar el recurso solicitado.`);
            }
        }
    });

    // 4. Se envía la solicitud por la red hacia el servidor destino
    xhr.send();
};
