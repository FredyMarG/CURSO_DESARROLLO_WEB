¿Qué es Screen y Scroll?

🎯 Propósito en JavaScript moderno

Obtén la resolución física del monitor con screen y controla el desplazamiento suave de la página.

🧠 Modelo mental: screen mide el monitor físico; window.scrollY mide cuántos píxeles has bajado en la página.

🖥️ ¿QUÉ ES screen?

El objeto screen contiene información sobre la pantalla física del usuario.

Permite conocer:

✅ resolución

✅ profundidad de color

✅ tamaño disponible

✅ dimensiones del monitor

📜 ¿QUÉ ES EL SCROLL?

El scroll representa el desplazamiento vertical u horizontal de una página.

Cuando el usuario baja o sube:

scrollY cambia

Cuando se mueve horizontalmente:

scrollX cambia
