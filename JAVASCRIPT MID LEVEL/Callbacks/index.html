Funciones de orden superior

Los callbacks hacen que JavaScript responda en el momento correcto

Una callback es una función que se pasa como argumento y se ejecuta cuando termina otra acción.

Explorar ejemplo Entender concepto
Ejemplo 
function saludar(nombre, callback) {
    callback(nombre);
}

¿Qué es un callback?

1

Se pasa como argumento

La función recibe otra función para ejecutarla más tarde.

2

Se ejecuta después

Permite controlar el orden de las acciones en el programa.

3

Es muy usado

Se emplea en eventos, peticiones, temporizadores y arreglos.

Ejemplo práctico

Haz clic en el botón para ejecutar una función que recibe otra como callback.

Esperando acción...

Estado: la callback aún no se ha ejecutado.

Patrón típico

function procesar(datos, callback) {
    callback(datos);
}

Aplicaciones comunes

Eventos del DOM

Cuando haces clic, el navegador dispara una función callback.

setTimeout

Ejecuta una acción después de cierto tiempo.

.forEach() y .map()

Procesan cada elemento con una función callback.

Comprender callbacks es clave para dominar JavaScript

Son la base para manejar eventos, asincronía y lógica más avanzada.
