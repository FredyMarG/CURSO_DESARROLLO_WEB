DOS CLIENTES, UN MISMO OBJETIVO

¿Qué cambia entre Fetch y Axios?

1

Fetch

Es una API nativa del navegador. Convierte la respuesta con response.json() y no rechaza automáticamente los errores HTTP.

2

Axios

Es una biblioteca externa. Interpreta JSON automáticamente y rechaza la promesa cuando recibe un estado HTTP de error.

3

La petición

Ambos envían el mismo POST con los mismos datos. Cambia el cliente, no el resultado que buscamos.
