🎯 Propósito en JavaScript moderno

Simplifica peticiones HTTP con parseo automático a JSON, manejo automático de errores 4xx/5xx e interceptores.

🧠 Modelo mental: Axios envuelve las peticiones en una interfaz cómoda: entrega los datos directamente en response.data.

# Resumen

  • * Axios es un cliente HTTP isomórfico y moderno basado íntegramente en el ecosistema de Promesas de JavaScript.
  • * Automatiza la serialización y deserialización de datos, abstrayendo al desarrollador del uso de procesos manuales como JSON.stringify() o .json().
  • * El método get() acepta la propiedad params para formatear de manera segura parámetros de búsqueda en la URL.
  • * El método post() inyecta objetos complejos directamente como segundo parámetro para ser transmitidos en el cuerpo del mensaje.
  • * Posee un sistema automático de control de errores que desvía de forma inmediata cualquier respuesta de estado HTTP fuera del rango exitoso (2xx) hacia el bloque catch.

# Hoja de Trucos (Cheatsheet)

API / PatrónPropósitoEjemplo
axios.create(config)Crea una instancia aislada con baseURL, timeout y headers.const api = axios.create({ baseURL: "/api" })
api.get(url, { params })Envía GET con query params serializados automáticamente.await api.get("/users", { params: { page: 2 } })
api.post(url, data)Envía POST serializando data a JSON automáticamente.await api.post("/users", { name: "Ana" })
api.put / patch / deleteMétodos abreviados para actualizar o eliminar recursos.await api.delete("/users/5")
interceptors.request.useIntercepta peticiones antes de salir (ej. inyectar JWT).api.interceptors.request.use(cfg => ...)
interceptors.response.useIntercepta respuestas/errores globales (ej. 401).api.interceptors.response.use(res => res, err => ...)
signal: controller.signalCancela peticiones con AbortController (estándar actual).api.get("/search", { signal: controller.signal })
axios.isAxiosError(err)Verifica de forma segura si el error proviene de Axios.if (axios.isAxiosError(err)) { ... }
axios.isCancel(err)Comprueba si el error se debe a una cancelación con AbortController.if (axios.isCancel(err)) return;
err.response / err.requestDistingue error HTTP del servidor vs. fallo de red sin respuesta.err.response?.status
