DIAPOSITIVA 2 · DEFINICIÓN Y USO INICIAL

¿Qué es REPL? Iniciar y Salir

REPL significa Read–Eval–Print–Loop (Leer–Evaluar–Imprimir–Repetir). Es una consola interactiva integrada en Node.js para probar expresiones JavaScript sin guardar archivos .js y sin necesidad de conexión a Internet. 

# 1. En PowerShell o terminal integrada de VS Code, escribe:
node

# 2. Aparece el indicador interactivo (>):
> 2 + 3
5
> "Hola desde Node.js"
'Hola desde Node.js'

# 3. Para salir del REPL:
> .exit
# (También puedes pulsar Ctrl+C dos veces o Ctrl+D)
DIAPOSITIVA 3 · MECÁNICA INTERNA

Las 4 Fases del Ciclo R-E-P-L

FaseNombreAcción
RReadLee la expresión o instrucción que escribes.
EEvalEvalúa el código como JavaScript en el motor V8.
PPrintImprime el resultado devuelto en pantalla.
LLoopVuelve al indicador > esperando la siguiente entrada.
🧮 Analogía: REPL es como una calculadora de bolsillo o una mesa de pruebas en un taller: pruebas una operación al instante antes de llevarla a un archivo .js del proyecto.
DIAPOSITIVA 4 · PRUEBAS RÁPIDAS

Variables, Funciones, Arreglos y Objetos

// Variables y funciones flecha
const calcularAvance = (completados, total) =>
  total === 0 ? 0 : (completados / total) * 100;
calcularAvance(3, 5); // 60

// Arreglos y filtrado en tiempo real
const lecciones = [
  { titulo: "REPL", completada: true },
  { titulo: "npm", completada: false },
  { titulo: "Módulos", completada: true }
];
lecciones.filter(l => l.completada);
⚠️ Nota sobre undefined: Declaraciones como const precio = 12000 imprimen undefined porque no retornan un valor; eso es normal y no indica error.
DIAPOSITIVA 5 · COMANDOS CON PUNTO

Comandos Especiales del REPL

Los comandos que comienzan con punto (.) no son JavaScript: son órdenes de control del entorno REPL.

ComandoFunción
.helpMuestra la lista de comandos disponibles.
.exitCierra la sesión del REPL.
.clearReinicia el contexto de evaluación de la sesión.
.breakCancela una expresión multilínea incompleta.
.save archivo.jsGuarda el historial de la sesión en un archivo.
.load archivo.jsCarga y evalúa un archivo JavaScript dentro del REPL.
.editorAbre modo edición multilínea (Ctrl+D ejecuta, Ctrl+C cancela).
DIAPOSITIVA 6 · PRODUCTIVIDAD EN TERMINAL

Historial, Autocompletado y Multilínea

  • Flecha ↑ / ↓: navega por las instrucciones ejecutadas anteriormente.
  • Tecla Tab: sugiere y autocompleta nombres de variables, propiedades y métodos.
  • Expresiones multilínea: si dejas una llave { o paréntesis ( abierto, el REPL espera a que lo cierres.
  • .break: abandona al instante una entrada multilínea que quedó mal escrita.
> function doble(numero) {
...   return numero * 2;
... }
undefined
> doble(21)
42

DIAPOSITIVA 9 · PRECAUCIONES

Buenas Prácticas y Errores Comunes

  • ❌ Escribir node app.js dentro del REPL: es un comando de terminal, no JS; sal primero con .exit.
  • ❌ Redeclarar const: volver a usar el mismo nombre con const lanza error de identificador duplicado; usa .clear o un nombre nuevo.
  • ❌ Creer que document existe: pertenece al navegador, no al REPL de Node.js.
  • ❌ Introducir contraseñas o tokens reales: el historial del REPL puede guardarse localmente.
  • ✅ Traslada lo útil a archivos: usa .save o crea módulos con pruebas automatizadas.
