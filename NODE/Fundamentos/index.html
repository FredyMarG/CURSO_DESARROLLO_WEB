DIAPOSITIVA 2 · DEFINICIÓN

¿Qué es Node.js? (y qué NO es)

🎯 Entorno de ejecución de JavaScript

Node.js es un entorno de ejecución que permite correr código JavaScript fuera del navegador. Se utiliza para construir servidores web, APIs, herramientas de consola (CLI), automatizaciones y apps en tiempo real.

  • NO es un lenguaje de programación: el lenguaje sigue siendo JavaScript.
  • NO es un framework: Express o Fastify se construyen encima de Node.js.
  • SÍ aporta capacidades del sistema: archivos, red, puertos, procesos y variables de entorno.
// archivo: saludo.js
console.log('¡Hola desde Node.js!');

// Ejecutar en PowerShell / terminal:
// node saludo.js

DIAPOSITIVA 5 · COMUNICACIÓN WEB

Ciclo de una Petición HTTP

El cliente envía una petición (Método + Ruta + Cabeceras + Cuerpo opcional) a localhost:3000, y el servidor responde con un código de estado (200, 404, 500), cabeceras (Content-Type) y cuerpo (JSON, HTML o texto). 

┌──────────────────────────┐       GET /api/bienvenida       ┌──────────────────────────┐
│  Cliente (Navegador)     │ ──────────────────────────────▶ │  Servidor Node.js        │
│  o PowerShell / Postman  │ ◀────────────────────────────── │  Comprueba método y ruta │
└──────────────────────────┘    200 OK + JSON / 404 JSON     └──────────────────────────┘
🍽️ Analogía del restaurante y biblioteca: El cliente hace el pedido (petición HTTP), el backend verifica las reglas (como el bibliotecario) y la cocina/catálogo entrega el plato o libro con su estado correspondiente.
DIAPOSITIVA 6 · ARQUITECTURA INTERNA

Motor V8, APIs Nativas, libuv y Event Loop

  • 1. Motor V8: Compila y ejecuta JavaScript a código máquina (el mismo motor de Chromium).
  • 2. APIs nativas: Módulos integrados como node:http, node:fs, node:path y node:os.
  • 3. Event Loop: Coordina callbacks para atender múltiples operaciones de entrada/salida sin bloquear el hilo principal.
  • 4. libuv: Biblioteca en C que gestiona E/S asíncrona y el bucle de eventos entre el sistema operativo y Node.js.
  • 5. Objeto global process: Expone información del proceso activo (process.version, process.cwd()).
⚠️ Importante: La espera no bloqueante de E/S no significa que todo tu código JavaScript corra en paralelo en múltiples hilos.

DIAPOSITIVA 9 · SERVIDOR HTTP NATIVO

API de Bienvenida (servidor.js)

const http = require('node:http');
const PUERTO = 3000;

const servidor = http.createServer((req, res) => {
  const url = new URL(req.url, `http://${req.headers.host || 'localhost'}`);
  res.setHeader('Content-Type', 'application/json; charset=utf-8');

  if (req.method === 'GET' && url.pathname === '/api/bienvenida') {
    res.writeHead(200);
    return res.end(JSON.stringify({
      mensaje: 'Bienvenido a CURSO_DESARROLLO_WEB',
      moduloActual: 'Fundamentos de Node.js'
    }));
  }

  res.writeHead(404);
  res.end(JSON.stringify({ error: 'Ruta no encontrada' }));
});

servidor.listen(PUERTO, () => console.log(`API en http://localhost:${PUERTO}`));
DIAPOSITIVA 10 · CALIDAD DE CÓDIGO

Buenas Prácticas y Errores Comunes

  • ✅ Prefijo node:: usa require('node:http') para distinguir módulos nativos.
  • ✅ Cabecera JSON: configura application/json; charset=utf-8 antes de responder.
  • ✅ Cierra con return res.end(...): evita enviar dos respuestas en la misma petición.
  • ✅ Protege secretos: nunca subas contraseñas, tokens ni archivos .env al navegador o Git.
  • ❌ Error común: confundir ruta HTTP (/api/bienvenida) con un archivo físico en disco.
  • ❌ Puerto ocupado: si el puerto 3000 está en uso, detén el proceso anterior con Ctrl + C.
