DIAPOSITIVA 5 · COMUNICACIÓN WEB

Ciclo de una Petición HTTP

El cliente envía una petición (Método + Ruta + Cabeceras + Cuerpo opcional) a localhost:3000, y el servidor responde con un código de estado (200, 404, 500), cabeceras (Content-Type) y cuerpo (JSON, HTML o texto). 

┌──────────────────────────┐       GET /api/bienvenida       ┌──────────────────────────┐
│  Cliente (Navegador)     │ ──────────────────────────────▶ │  Servidor Node.js        │
│  o PowerShell / Postman  │ ◀────────────────────────────── │  Comprueba método y ruta │
└──────────────────────────┘    200 OK + JSON / 404 JSON     └──────────────────────────┘
🍽️ Analogía del restaurante y biblioteca: El cliente hace el pedido (petición HTTP), el backend verifica las reglas (como el bibliotecario) y la cocina/catálogo entrega el plato o libro con su estado correspondiente.

DIAPOSITIVA 8 · PRÁCTICA CLI

Tu Primer Programa (index.js)

const nombreCurso = 'Fundamentos de Node.js';
const totalModulos = 26;

function presentarCurso(nombre, cantidad) {
  return `Bienvenido a ${nombre}. El programa tiene ${cantidad} módulos.`;
}

function saludar(nombre) {
  return `hola ${nombre}`;
}

console.log(presentarCurso(nombreCurso, totalModulos));
console.log('Node.js:', process.version);
console.log(saludar('Fredy'));
  • const declara identificadores que no se reasignarán.
  • saludar(nombre) recibe un argumento y devuelve un saludo personalizado.
  • Las comillas invertidas (`...`) permiten interpolar variables con ${...}.
  • Ejecuta en terminal con node index.js dentro de NODE/Fundamentos/.
DIAPOSITIVA 9 · SERVIDOR HTTP NATIVO

API de Bienvenida (servidor.js)

const http = require('node:http');
const PUERTO = 3000;

const servidor = http.createServer((req, res) => {
  const url = new URL(req.url, `http://${req.headers.host || 'localhost'}`);
  res.setHeader('Content-Type', 'application/json; charset=utf-8');

  if (req.method === 'GET' && url.pathname === '/api/bienvenida') {
    res.writeHead(200);
    return res.end(JSON.stringify({
      mensaje: 'Bienvenido al curso de Node.js',
      moduloActual: 'Fundamentos de Node.js'
    }));
  }

  res.writeHead(404);
  res.end(JSON.stringify({ error: 'Ruta no encontrada' }));
});

servidor.listen(PUERTO, () => console.log(`API en http://localhost:${PUERTO}`));
DIAPOSITIVA 10 · CALIDAD DE CÓDIGO

Buenas Prácticas y Errores Comunes

Error frecuenteCausa probableSolución
node no reconocidoInstalación o PATH incompletoInstala LTS y reinicia la terminal
Unexpected tokenError de sintaxis JSEjecuta node --check archivo.js
ENOENT / Cannot find moduleRuta o archivo inexistenteVerifica la ruta usando node:path
EADDRINUSE (puerto ocupado)Otro servidor activo en 3000Detén el proceso con Ctrl + C
  • ✅ Prefijo node: y cabecera JSON: usa require('node:http') y application/json; charset=utf-8.
  • ✅ Cierra con return res.end(...): evita enviar dos respuestas en la misma petición.
  • ✅ Protege secretos: nunca subas node_modules/ ni .env al navegador o Git.
