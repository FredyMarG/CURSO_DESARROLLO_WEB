DIAPOSITIVA 2 · MANIFIESTO DEL PROYECTO

¿Qué es npm y Cómo se Estructura package.json?

npm administra dependencias externas, versiones y scripts de automatización. Su corazón es package.json: 

{
  "name": "mi-api-node",
  "version": "1.2.0",
  "private": true,
  "type": "module",
  "scripts": {
    "start": "node src/index.js",
    "dev": "node --watch src/index.js",
    "test": "node --test"
  },
  "dependencies": { "express": "^4.21.0" },
  "devDependencies": { "eslint": "^9.0.0" }
}
DIAPOSITIVA 3 · VERSIONADO SEMÁNTICO

SemVer: MAJOR.MINOR.PATCH, ^ y ~

NotaciónQué permite actualizarEjemplo desde 1.4.2
^1.4.2 (caret)Sube MINOR y PATCH (mantiene MAJOR)>=1.4.2 <2.0.0
~1.4.2 (tilde)Sube solo PATCH (mantiene MAJOR.MINOR)>=1.4.2 <1.5.0
1.4.2 (exacta)Ninguna actualización automáticaSolo 1.4.2
💡 Regla SemVer: MAJOR rompe compatibilidad, MINOR añade funciones compatibles y PATCH corrige errores.
DIAPOSITIVA 4 · INSTALACIÓN DE PAQUETES

Cómo Instalar Dependencias (npm install, -D, @versión y npm ci)

# 0) Iniciar proyecto (crea package.json si aún no existe)
npm init -y

# 1) Instalar dependencia de producción (se guarda en "dependencies")
npm install express          # atajo: npm i express
npm i zod cors               # instalar varios paquetes en un solo comando

# 2) Instalar una versión específica o exacta
npm i express@4.21.0         # versión concreta (con ^ por defecto)
npm i express@4.21.0 -E      # --save-exact: fija "4.21.0" sin ^ ni ~

# 3) Instalar dependencia solo de desarrollo ("devDependencies")
npm i -D eslint prettier     # -D equivale a --save-dev

# 4) Restaurar todas las dependencias al clonar un repositorio
npm install                  # lee package.json / package-lock.json y crea node_modules/
Archivo / ComandoQué hace al instalar
node_modules/Carpeta donde se descargan los paquetes (se ignora en .gitignore)
package-lock.jsonCongela el árbol exacto de versiones; sí se sube a Git
npm ciBorra node_modules e instala exactamente lo del lockfile (CI/producción)

npx, Hooks pre/post y npm audit

ComandoPara qué sirve
npx <cli>Ejecuta una CLI sin instalarla globalmente
npm outdatedLista paquetes con nuevas versiones disponibles
npm audit / audit fixDetecta y corrige vulnerabilidades conocidas
npm uninstall <pkg>Elimina el paquete de node_modules y package.json

  "test": "node --test"
}
