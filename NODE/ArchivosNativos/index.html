DIAPOSITIVA 2 · LECTURA Y ESCRITURA

node:fs/promises: Archivos, Directorios y JSON

Usa el prefijo node: para importar módulos nativos explícitamente. Para E/S no bloqueante en aplicaciones modernas, prefiere node:fs/promises. 

import { mkdir, writeFile, readFile } from 'node:fs/promises';

await mkdir('datos', { recursive: true });
const cursos = [{ id: 1, titulo: 'Node.js' }];
await writeFile('datos/cursos.json', JSON.stringify(cursos, null, 2), 'utf8');

try {
  const texto = await readFile('datos/cursos.json', 'utf8');
  console.log(JSON.parse(texto)[0].titulo);
} catch (error) {
  if (error.code === 'ENOENT') console.log('El archivo no existe');
  else throw error;
}
DIAPOSITIVA 3 · RUTAS MULTIPLATAFORMA

node:path y import.meta.url en ESM

MétodoFunciónEjemplo
path.join()Une segmentos normalizando separadores (\ o /)path.join('datos', 'cursos.json')
path.resolve()Genera ruta absoluta desde el directorio actualpath.resolve('datos', 'cursos.json')
path.basename() / extname()Extrae el nombre final o la extensión.md, leccion.md
 
import { fileURLToPath } from 'node:url';
import path from 'node:path';

const archivoActual = fileURLToPath(import.meta.url);
const carpetaActual = path.dirname(archivoActual);
console.log(path.join(carpetaActual, 'datos', 'cursos.json'));
DIAPOSITIVA 4 · DIAGNÓSTICO DEL ENTORNO

node:os: Plataforma, Memoria y Carpetas Temporales

import os from 'node:os';

console.log('Sistema:', os.platform());           // 'win32', 'linux', 'darwin'
console.log('Arquitectura:', os.arch());          // 'x64', 'arm64'
console.log('Memoria libre (MB):', Math.round(os.freemem() / 1024 ** 2));
console.log('Directorio temporal:', os.tmpdir());
console.log('CPUs lógicas:', os.cpus().length);
💡 Aplicación práctica: Útil para diagnósticos del proceso o elegir una carpeta temporal segura (os.tmpdir()). Evita registrar información privada del equipo en logs públicos.
DIAPOSITIVA 5 · EVENTOS E IDENTIDAD

EventEmitter (node:events) y node:crypto

import { EventEmitter } from 'node:events';
import { randomUUID, createHash } from 'node:crypto';

const bus = new EventEmitter();
bus.once('inicio', () => console.log('Sistema iniciado'));
bus.on('apunte:creado', (apunte) => console.log('Nuevo apunte:', apunte.id));

bus.emit('inicio');
bus.emit('apunte:creado', {
  id: randomUUID(),
  huella: createHash('sha256').update('Contenido').digest('hex')
});
⚠️ Seguridad con crypto: SHA-256 sirve para verificar integridad, no para guardar contraseñas. Para contraseñas usa algoritmos de derivación como scrypt con sal única.
