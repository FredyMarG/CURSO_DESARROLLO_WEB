DIAPOSITIVA 2 · LECTURA, ESCRITURA Y GESTIÓN

node:fs/promises: CRUD Completo de Archivos

El módulo nativo node:fs permite crear, leer, modificar, renombrar y eliminar archivos y carpetas. En servidores y aplicaciones Node.js usa la variante basada en promesas (node:fs/promises) para no bloquear el Event Loop mientras el disco responde.

Método Acción
readFile() / writeFile() Leer o crear/sobrescribir un archivo completo
appendFile() Agregar contenido al final sin borrar lo existente
rename() / unlink() Renombrar o mover un archivo / eliminarlo
copyFile() / rm() Copiar un archivo / borrar archivos o carpetas ({ recursive: true })
mkdir() / readdir() / stat() Crear carpetas, listar contenido y consultar tamaño/tipo 
// 1. Asíncrono recomendado (node:fs/promises) — no bloquea el hilo
import { writeFile, appendFile, readFile, rename, unlink } from 'node:fs/promises';
await writeFile('nota.txt', 'Línea 1\n', 'utf8');
await appendFile('nota.txt', 'Línea 2\n', 'utf8'); // Añade sin sobrescribir
await rename('nota.txt', 'nota-final.txt');
console.log(await readFile('nota-final.txt', 'utf8'));
await unlink('nota-final.txt');

// 2. Síncrono (*Sync) — bloquea hasta terminar (solo scripts CLI o arranque)
const fs = require('node:fs');
fs.writeFileSync('sync.txt', 'Hola\n', 'utf8');
fs.appendFileSync('sync.txt', 'Mundo\n', 'utf8');
console.log(fs.readFileSync('sync.txt', 'utf8'));
fs.unlinkSync('sync.txt');
✅ Asíncrono (/promises) vs Síncrono (*Sync): node:fs/promises devuelve Promesas para usar async/await sin bloquear Node.js. Los métodos *Sync (readFileSync, writeFileSync) bloquean el hilo hasta terminar y solo convienen en scripts CLI cortos o al iniciar la app.
DIAPOSITIVA 3 · RUTAS MULTIPLATAFORMA

node:path, __dirname y import.meta.url

Windows usa \ y Linux/macOS usan /. Concatenar rutas a mano rompe tu app entre sistemas; node:path construye rutas portables automáticamente, y en ES Modules import.meta.url te da la ubicación exacta del archivo actual.

Método / Variable Función Ejemplo
path.join() Une segmentos normalizando separadores (\ o /) path.join('datos', 'cursos.json')
path.resolve() Genera ruta absoluta desde el directorio actual path.resolve('datos', 'cursos.json')
__dirname (CommonJS) Ruta absoluta de la carpeta del archivo actual path.join(__dirname, 'fs.html')
import.meta.url (ESM) Equivalente moderno en ESM con fileURLToPath() path.dirname(fileURLToPath(import.meta.url)) 
// En CommonJS: path.join(__dirname, 'fs.html')
// En ESM ("type": "module"):
import { fileURLToPath } from 'node:url';
import path from 'node:path';

const carpetaActual = path.dirname(fileURLToPath(import.meta.url));
console.log(path.join(carpetaActual, 'datos', 'cursos.json'));
DIAPOSITIVA 4 · DIAGNÓSTICO DEL ENTORNO

node:os: Plataforma, Memoria y Carpetas Temporales 

const os = require('node:os'); // También válido con import os from 'node:os'

console.log('SO y versión:', os.type(), os.release(), os.version());
console.log('Plataforma / Equipo:', os.platform(), os.hostname());
console.log('Usuario / Temporal:', os.homedir(), os.tmpdir());
console.log('RAM libre / total (MB):', Math.round(os.freemem() / 1024 ** 2), '/', Math.round(os.totalmem() / 1024 ** 2));
console.log('CPUs lógicas:', os.cpus().length);
💡 Aplicación práctica: Útil para diagnósticos del proceso o elegir una carpeta temporal segura (os.tmpdir()). Evita registrar información privada del equipo en logs públicos.
DIAPOSITIVA 5 · PROCESO, DEPURACIÓN Y TEMPORIZADORES

node:process, node:console y node:timers

Para leer variables de entorno (process.env), medir tiempos con precisión (console.time), inspeccionar tablas (console.table) o hacer pausas con async/await (timers/promises), Node.js incluye estas tres APIs globales y nativas.

Módulo Utilidades clave Uso habitual
node:process argv, env, cwd(), pid, ppid, title, version Leer configuración, rutas, PIDs y controlar el proceso
node:console table(), time() / timeEnd(), warn(), error() Medir rendimiento y visualizar arreglos en tablas limpias
node:timers setTimeout(fn, ms, ...args), setImmediate(), setInterval(), timers/promises Programar tareas diferidas, inmediatas o con await 
const process = require('node:process');
const { setTimeout, setImmediate } = require('node:timers');

console.log('PID / PPID:', process.pid, process.ppid, '| Título:', process.title);
console.table([{ modulo: 'process', ok: true }, { modulo: 'timers', ok: true }]);

// Pasar múltiples argumentos (2, 5) tras el retardo en milisegundos
const sumar = (a, b) => console.log('Suma diferida:', a + b);
setImmediate(() => console.log('Se ejecuta antes que el temporizador'));
setTimeout(sumar, 5000, 2, 5);

DIAPOSITIVA 7 · PATRÓN REAL EN BACKEND

Lectura Segura de JSON y Manejo de ENOENT

Al leer un archivo de configuración o datos por primera vez, puede no existir todavía (error.code === 'ENOENT') o estar corrupto (SyntaxError). Nunca devuelvas [] si el archivo está corrupto, o sobrescribirás datos valiosos: 

import { readFile } from 'node:fs/promises';

export async function leerListaSegura(ruta) {
  try {
    return JSON.parse(await readFile(ruta, 'utf8'));
  } catch (err) {
    if (err.code === 'ENOENT') return []; // Solo si aún no existe
    throw err; // Si es SyntaxError o EACCES, propaga el error
  }
}
DIAPOSITIVA 8 · SEGURIDAD EN RUTAS

Prevenir Path Traversal (../../) con path.resolve

Si un servidor lee archivos usando un nombre que viene del usuario sin validarlo, alguien podría enviar ../../etc/passwd o ../../.env. Resuelve la ruta base y verifica con startsWith(): 

import path from 'node:path';

const BASE = path.resolve('public');
function rutaSegura(archivoUsuario) {
  const destino = path.resolve(BASE, archivoUsuario);
  if (!destino.startsWith(BASE + path.sep)) {
    throw new Error('Acceso denegado fuera de public/');
  }
  return destino;
}

DIAPOSITIVA 10 · EXPLORACIÓN DEL DISCO

Listar Carpetas (readdir) y Medir Archivos (stat)

Con readdir(ruta, { withFileTypes: true }) sabes al instante qué elementos son archivos o subcarpetas sin hacer llamadas extra, y con stat() consultas su tamaño en bytes y fecha de modificación: 

import { readdir, stat } from 'node:fs/promises';

const entradas = await readdir('./data', { withFileTypes: true });
for (const e of entradas) {
  if (e.isFile()) {
    const info = await stat('./data/' + e.name);
    console.log(e.name, info.size, 'bytes');
  }
}
