DIAPOSITIVA 2 · ALEATORIEDAD CRIPTOGRÁFICA

randomUUID() y randomBytes()

  • randomUUID(): genera un UUID v4 único para identificar registros, pedidos o trazas (no es un secreto).
  • randomBytes(32): genera 32 bytes aleatorios criptográficamente seguros ideales para tokens de sesión, sales o API keys.
import { randomUUID, randomBytes } from 'node:crypto';

const idPedido = randomUUID();
const tokenSesion = randomBytes(32).toString('hex'); // 64 caracteres hex
console.log({ idPedido, tokenSesion });
⚠️ Nunca uses Math.random() para seguridad: Es predecible y no sirve para tokens, códigos de recuperación ni claves.
DIAPOSITIVA 3 · INTEGRIDAD Y AUTENTICIDAD

createHash('sha256') vs createHmac()

HerramientaQué garantizaUso típico
createHash('sha256')Integridad: detecta si el dato cambióHuellas de archivos o documentos
createHmac('sha256', secreto)Integridad + Autenticidad con clave secretaValidar webhooks y mensajes firmados
 
import { createHash, createHmac } from 'node:crypto';

const huella = createHash('sha256').update('Archivo oficial').digest('hex');
const firma = createHmac('sha256', 'mi-secreto').update('evento=pago').digest('hex');
DIAPOSITIVA 4 · ALMACENAMIENTO SEGURO

Derivación de Contraseñas con scrypt y Sal Única

import { scryptSync, randomBytes } from 'node:crypto';

function hashPassword(password) {
  const sal = randomBytes(16).toString('hex'); // Sal única por usuario
  const derivado = scryptSync(password, sal, 64).toString('hex');
  return `${sal}:${derivado}`;
}
⚠️ Regla de oro: Nunca guardes contraseñas con SHA-256 ni MD5. Son demasiado rápidos; usa scrypt con una sal aleatoria diferente para cada usuario.
DIAPOSITIVA 5 · PREVENCIÓN DE TIMING ATTACKS

Comparación en Tiempo Constante: timingSafeEqual()

El operador === se detiene en el primer byte distinto, lo que permite filtrar secretos midiendo tiempos. Usa timingSafeEqual() con dos Buffer de igual longitud: 

import { scryptSync, timingSafeEqual } from 'node:crypto';

function verificarPassword(password, guardado) {
  const [sal, hashHex] = guardado.split(':');
  const hashOriginal = Buffer.from(hashHex, 'hex');
  const hashIntento = scryptSync(password, sal, 64);

  if (hashOriginal.length !== hashIntento.length) return false;
  return timingSafeEqual(hashOriginal, hashIntento);
}
