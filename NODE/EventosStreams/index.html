DIAPOSITIVA 2 · PATRÓN PUB/SUB NATIVO

EventEmitter: on, once, off y emit

APIs centrales como http.Server, process y fs.ReadStream heredan de EventEmitter. Permite emitir avisos sin acoplar el emisor a quienes reaccionan. 

import { EventEmitter } from 'node:events';

const bus = new EventEmitter();
bus.once('sistema:listo', () => console.log('Inicializado una sola vez'));

const onPedido = (p) => console.log('Pedido recibido:', p.id);
bus.on('pedido:creado', onPedido);

bus.emit('sistema:listo');
bus.emit('pedido:creado', { id: 'ORD-101' });
bus.off('pedido:creado', onPedido); // Desuscribir listener
DIAPOSITIVA 3 · DOMINIO Y ESTABILIDAD

Extender EventEmitter y Manejar 'error'

import { EventEmitter } from 'node:events';

class GestorTareas extends EventEmitter {
  completar(nombre) {
    if (!nombre) return this.emit('error', new Error('Nombre requerido'));
    this.emit('tarea:completada', { nombre });
  }
}

const gestor = new GestorTareas();
gestor.on('error', (err) => console.error('Error controlado:', err.message));
gestor.on('tarea:completada', (t) => console.log('OK:', t.nombre));
⚠️ Regla crítica de Node.js: Si llamas a emit('error', err) y no hay ningún listener registrado para 'error', Node.js lanza la excepción y cierra el proceso.

Streams: Procesar Archivos Grandes por Chunks

TipoPropósitoEjemplo nativo
ReadableProduce fragmentos (chunks) bajo demandafs.createReadStream('grande.log')
WritableConsume y escribe fragmentosfs.createWriteStream('copia.log')
TransformTransforma datos al pasozlib.createGzip()
 
const lectura = fs.createReadStream('entrada.txt', { encoding: 'utf8', highWaterMark: 1024 });
lectura.on('data', (chunk) => console.log('Chunk:', chunk.length));
lectura.on('end', () => console.log('Lectura completada'));
DIAPOSITIVA 5 · PRODUCCIÓN SEGURA

pipeline() de node:stream/promises y Backpressure

import fs from 'node:fs';
import { pipeline } from 'node:stream/promises';
import { createGzip } from 'node:zlib';

try {
  await pipeline(
    fs.createReadStream('registros.log'),
    createGzip(),
    fs.createWriteStream('registros.log.gz')
  );
  console.log('Archivo comprimido con éxito');
} catch (error) {
  console.error('Fallo en pipeline:', error.message);
}
✅ Por qué usar pipeline() en lugar de .pipe(): Controla el backpressure (pausa la lectura si el disco escribe lento), cierra todos los streams si alguno falla y permite usar try/catch.
