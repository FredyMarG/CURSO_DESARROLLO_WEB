DIAPOSITIVA 2 · ALCANCE DE BLOQUE

const por defecto, let para reasignar, nunca var

  • var (obsoleto): tiene alcance de función (ignora bloques if o for), permite redeclaración silenciosa y sufre de hoisting en undefined.
  • const y let: tienen alcance de bloque y viven en la Temporal Dead Zone (TDZ) hasta ejecutarse su declaración.
  • Regla de const: impide reasignar el identificador, pero no congela el contenido de objetos o arrays.
const PUERTO = 3000;
let intentos = 0;
intentos += 1;

const usuario = { nombre: 'Ana', rol: 'dev' };
usuario.rol = 'tech-lead'; // ✅ Válido (muta propiedad interna)
// usuario = {};           // ❌ TypeError: Assignment to constant variable

const disponibles = productos.filter(p => p.stock > 0);
const etiquetas = disponibles.map(p => `${p.nombre} ($${p.precio})`);
const total = productos.reduce((acc, p) => acc + p.precio * p.stock, 0);
DIAPOSITIVA 5 · OPERADORES MODERNOS

Destructuring, ...rest / ...spread, ?. y ??

const config = { host: 'localhost', puerto: 0, db: { motor: 'postgres' } };

// Destructuring con alias, default y ...rest
const { host: servidor, timeout = 5000, ...resto } = config;

// Spread: copia superficial (shallow copy) + sobrescritura inmutable
const configProd = { ...config, host: 'api.miapp.com', ssl: true };

// Optional chaining (?.) + Nullish coalescing (??)
const motor = config.db?.motor ?? 'sqlite';
const puerto = config.puerto ?? 3000; // ✅ 0 (|| daría 3000 porque 0 es falsy)
⚠️ Shallow Copy: { ...config } solo clona el primer nivel. Si modificas configProd.db.motor, también cambia config.db.motor. Para copia profunda usa structuredClone().
DIAPOSITIVA 6 · CALIDAD ES6+

Inmutabilidad, structuredClone y Errores Comunes

const base = { app: 'API', db: { host: 'localhost' } };

// Copia profunda (Node.js 17+): no comparte referencias anidadas
const copiaSegura = structuredClone(base);
copiaSegura.db.host = '10.0.0.5'; // base.db.host sigue siendo 'localhost'

// Ordenar sin mutar el array original
const ordenados = [...productos].sort((a, b) => a.precio - b.precio);
  • Error con arrow: escribir x => { a: x } sin paréntesis devuelve undefined. Usa x => ({ a: x }).
  • Mutación accidental: sort() y reverse() mutan el array original; clona con [...arr] o usa toSorted().
  • Valores 0 o "": usa ?? en lugar de || cuando 0, false o "" sean válidos.
DIAPOSITIVA 7 · ASINCRONÍA MODERNA

async/await, try/catch y Top-Level Await

En Node.js casi todo (leer archivos, consultar bases de datos o llamar APIs) es asíncrono. Con async/await escribes código secuencial fácil de leer, y en ES Modules puedes usar await directo en la raíz del archivo: 

import { readFile } from 'node:fs/promises';

async function cargarConfig(ruta) {
  try {
    const raw = await readFile(ruta, 'utf8');
    return JSON.parse(raw);
  } catch (err) {
    return { puerto: 3000, error: err.code };
  }
}
DIAPOSITIVA 8 · COLECCIONES MODERNAS

Set, Map, Object.entries() y Object.fromEntries()

Set elimina duplicados al instante en O(1) promedio, Map admite cualquier tipo de clave, y Object.entries() junto a Object.fromEntries() permiten transformar objetos con map y filter sin mutarlos: 

const etiquetasUnicas = [...new Set(['node', 'js', 'node'])]; // ['node', 'js']

const precios = { cursoA: 20, cursoB: 50 };
const conDescuento = Object.fromEntries(
  Object.entries(precios).map(([k, v]) => [k, v * 0.8])
); // { cursoA: 16, cursoB: 40 }

DIAPOSITIVA 10 · MÉTODOS INMUTABLES ES2023

Arreglos Sin Mutación: toSorted(), toReversed() y .at(-1)

En Node.js 20+, ya no necesitas copiar un arreglo antes de ordenarlo o invertirlo: toSorted(), toReversed() y with() devuelven un arreglo nuevo sin alterar el original, y .at(-1) lee el último elemento limpiamente: 

const notas = [75, 98, 84];
const ordenadas = notas.toSorted((a, b) => b - a); // [98, 84, 75]
console.log(notas);          // [75, 98, 84] (intacto)
console.log(ordenadas.at(-1)); // 75 (último elemento)
