DIAPOSITIVA 2 · CONCEPTO BASE

¿Qué es Node.js? y Frontend vs Backend

Node.js es un entorno de ejecución de JavaScript fuera del navegador. No es un lenguaje de programación (el lenguaje es JavaScript) ni un framework (como Express o Fastify).

CaracterísticaFrontendBackend (Node.js)
Dónde se ejecutaNavegador del usuarioServidor / Terminal
ResponsabilidadInterfaz visual (HTML, CSS, DOM)Reglas de negocio, seguridad y datos
EjemploFormulario de registroValidar, guardar y responder JSON
Acceso a secretosNuncaMediante configuración segura

DIAPOSITIVA 5 · TU PRIMER SCRIPT

Primer Programa por Consola: hola.js

Todo archivo JavaScript puede ejecutarse directamente con node archivo.js. Los argumentos que pasas por terminal llegan en el arreglo process.argv. 

// archivo: hola.js
// process.argv[0] = ruta de node.exe
// process.argv[1] = ruta de hola.js
// process.argv[2] = primer argumento escrito por el usuario

const nombre = process.argv[2] ?? 'Estudiante';
console.log(`¡Hola, ${nombre}! Ejecutando Node ${process.version}`);

// En terminal:
// node hola.js Ana  -> ¡Hola, Ana!
// node hola.js      -> ¡Hola, Estudiante!

DIAPOSITIVA 7 · CÓMO FUNCIONA POR DENTRO

Anatomía de Node.js: Motor V8, libuv y Event Loop

Node.js no es un lenguaje nuevo ni un framework: es un entorno de ejecución que combina JavaScript con librerías del sistema operativo para atender miles de peticiones sin crear un hilo pesado por usuario.

ComponenteResponsabilidadEjemplo
Motor V8Compila y ejecuta tu código JavaScript a código máquinamap(), funciones, clases
libuv (C/C++)Gestiona el Event Loop y operaciones de E/S asíncronasLectura de archivos, sockets, DNS
APIs NativasExponen funciones del sistema operativo a JavaScriptnode:fs, node:http, node:crypto
DIAPOSITIVA 8 · DE LA CONSOLA A LA WEB

Tu Primer Servidor HTTP Nativo (node:http)

Sin instalar Express ni paquetes externos, Node.js puede levantar un servidor web escuchando en un puerto TCP, inspeccionar req.url y responder texto o JSON con códigos de estado HTTP (200, 404): 

import http from 'node:http';

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify({ ok: true, ruta: req.url }));
});

server.listen(3000, () => console.log('Servidor en http://localhost:3000'));

DIAPOSITIVA 10 · PRIMER CONTACTO CON PROYECTOS

¿Cómo Se Organiza un Proyecto Real con package.json?

Todo proyecto profesional en Node.js comienza con un archivo package.json en su raíz (creado con npm init -y). Allí se guardan el nombre del proyecto, los scripts de arranque y la lista de paquetes externos que usa: 

{
  "name": "mi-proyecto-node",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "start": "node src/index.js",
    "dev": "node --watch src/index.js"
  }
}
